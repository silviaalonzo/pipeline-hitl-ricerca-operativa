## 1. Insiemi, parametri e variabili decisionali

### Insiemi

\[
N=\{S,A,B,C,T\}
\]

\[
E=\{(S,A),(S,B),(A,B),(A,C),(B,C),(B,T),(C,T)\}
\]

Per ogni nodo \(i\), siano:

- \(\delta^+(i)=\{(i,j)\in E\}\), insieme degli archi uscenti;
- \(\delta^-(i)=\{(j,i)\in E\}\), insieme degli archi entranti.

### Parametri

Per ogni arco \((i,j)\in E\):

- \(f_{ij}\): costo fisso di attivazione;
- \(c_{ij}\): costo per unità trasportata;
- \(u_{ij}\): capacità.

| \((i,j)\) | \(f_{ij}\) | \(c_{ij}\) | \(u_{ij}\) |
|---|---:|---:|---:|
| \((S,A)\) | 40 | 2 | 30 |
| \((S,B)\) | 35 | 3 | 35 |

| \((B,C)\) | 18 | 2 | 20 |
| \((B,T)\) | 45 | 4 | 25 |
| \((C,T)\) | 38 | 2 | 35 |

\[
b_i=
\begin{cases}
40 & i=S,\\

\end{cases}

Per ogni \((i,j)\in E\):

## 2. Formulazione matematica completa

### Funzione obiettivo

\[
\min \quad
\sum_{(i,j)\in E}\left(f_{ij}y_{ij}+c_{ij}x_{ij}\right)
\]

Esplicitamente:

\[
\begin{aligned}
\min\quad
&40y_{SA}+2x_{SA}
+35y_{SB}+3x_{SB}
+15y_{AB}+x_{AB}\\
&+30y_{AC}+2x_{AC}
+18y_{BC}+2x_{BC}
+45y_{BT}+4x_{BT}
+38y_{CT}+2x_{CT}.
\end{aligned}
\]

### Conservazione del flusso

In forma generale:

\[
\sum_{(i,j)\in\delta^+(i)}x_{ij}
-
\sum_{(j,i)\in\delta^-(i)}x_{ji}
=b_i
\qquad \forall i\in N.
\]

Esplicitamente:

\[
x_{SA}+x_{SB}=40
\]

\[
x_{AB}+x_{AC}-x_{SA}=0
\]

\[
x_{BC}+x_{BT}-x_{SB}-x_{AB}=0
\]

\[
x_{CT}-x_{AC}-x_{BC}=0
\]

\[
-x_{BT}-x_{CT}=-40.
\]

### Capacità e attivazione degli archi

\[
x_{ij}\le u_{ij}y_{ij}
\qquad \forall (i,j)\in E.
\]

Esplicitamente:

\[
\begin{aligned}
x_{SA}&\le 30y_{SA}, & x_{SB}&\le 35y_{SB},\\
x_{AB}&\le 15y_{AB}, & x_{AC}&\le 25y_{AC},\\
x_{BC}&\le 20y_{BC}, & x_{BT}&\le 25y_{BT},\\
x_{CT}&\le 35y_{CT}. &&
\end{aligned}
\]

### Domini

\[

y_{ij}\in\{0,1\}
\qquad \forall(i,j)\in E.
\]

## 3. Codice Python con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

nodes = ["S", "A", "B", "C", "T"]

arcs = [
    ("S", "A"),
    ("S", "B"),
    ("A", "B"),
    ("A", "C"),
    ("B", "C"),
    ("B", "T"),
    ("C", "T"),
]

fixed_cost = {
    ("S", "A"): 40,
    ("S", "B"): 35,
    ("A", "B"): 15,
    ("A", "C"): 30,
    ("B", "C"): 18,
    ("B", "T"): 45,
    ("C", "T"): 38,
}

unit_cost = {
    ("S", "A"): 2,
    ("S", "B"): 3,
    ("A", "B"): 1,
    ("A", "C"): 2,
    ("B", "C"): 2,
    ("B", "T"): 4,
    ("C", "T"): 2,
}

capacity = {
    ("S", "A"): 30,
    ("S", "B"): 35,
    ("A", "B"): 15,
    ("A", "C"): 25,
    ("B", "C"): 20,
    ("B", "T"): 25,
    ("C", "T"): 35,
}

balance = {
    "S": 40,
    "A": 0,
    "B": 0,
    "C": 0,
    "T": -40,
}

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("M10_rete_distributiva", env=env)

x = {
    (i, j): model.addVar(
        lb=0,
        vtype=GRB.INTEGER,
        name=f"x_{i}_{j}"
    )
    for i, j in arcs
}

y = {
    (i, j): model.addVar(
        vtype=GRB.BINARY,
        name=f"y_{i}_{j}"
    )
    for i, j in arcs
}

model.setObjective(
    gp.quicksum(
        fixed_cost[i, j] * y[i, j] + unit_cost[i, j] * x[i, j]
        for i, j in arcs
    ),
    GRB.MINIMIZE
)

for node in nodes:
    outgoing = gp.quicksum(x[i, j] for i, j in arcs if i == node)
    incoming = gp.quicksum(x[i, j] for i, j in arcs if j == node)
    model.addConstr(
        outgoing - incoming == balance[node],
        name=f"balance_{node}"
    )

for i, j in arcs:
    model.addConstr(
        x[i, j] <= capacity[i, j] * y[i, j],
        name=f"activation_{i}_{j}"
    )

model.optimize()

status_map = {
    GRB.LOADED: "LOADED",
    GRB.OPTIMAL: "OPTIMAL",
    GRB.INFEASIBLE: "INFEASIBLE",
    GRB.INF_OR_UNBD: "INF_OR_UNBD",
    GRB.UNBOUNDED: "UNBOUNDED",
    GRB.CUTOFF: "CUTOFF",
    GRB.ITERATION_LIMIT: "ITERATION_LIMIT",
    GRB.NODE_LIMIT: "NODE_LIMIT",
    GRB.TIME_LIMIT: "TIME_LIMIT",
    GRB.SOLUTION_LIMIT: "SOLUTION_LIMIT",
    GRB.INTERRUPTED: "INTERRUPTED",
    GRB.NUMERIC: "NUMERIC",
    GRB.SUBOPTIMAL: "SUBOPTIMAL",
    GRB.INPROGRESS: "INPROGRESS",
    GRB.USER_OBJ_LIMIT: "USER_OBJ_LIMIT",
}

solver_status = status_map.get(model.Status, "STATUS_" + str(model.Status))

if model.Status == GRB.OPTIMAL:
    def numeric_value(value):
        result = round(float(value), 9)
        return 0.0 if abs(result) < 1e-9 else result

    variable_values = {}
    for i, j in arcs:
        variable_values[f"x_{i}_{j}"] = numeric_value(x[i, j].X)
    for i, j in arcs:
        variable_values[f"y_{i}_{j}"] = numeric_value(y[i, j].X)

    solution = {
        "status": solver_status,
        "objective": numeric_value(model.ObjVal),
        "variables": variable_values,
    }
else:
    solution = {
        "status": solver_status,
        "objective": None,
        "variables": {},
    }

model.dispose()
env.dispose()

print("SOLUTION_JSON=" + json.dumps(solution, separators=(",", ":")))
```
