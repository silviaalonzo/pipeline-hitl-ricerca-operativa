## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzare la somma dei costi variabili e dei costi fissi:

\[
\min \quad
\sum_{i\in I}\left(c_i x_i+f_i y_i\right).
\]

Esplicitamente:

\[
\min \quad
11x_A+10x_B+12x_C+9x_D
+80y_A+95y_B+60y_C+120y_D.
\]

### Vincolo di domanda

Devono essere acquistate esattamente 180 unità:

\[
\sum_{i\in I}x_i=180.
\]

### Attivazione, capacità e ordine minimo

Per ogni \(i\in I\):

\[
l_i y_i\le x_i\le u_i y_i.
\]

Quindi:

\[
20y_A\le x_A\le80y_A,
\]

\[
25y_B\le x_B\le100y_B,
\]

\[
15y_C\le x_C\le70y_C,
\]

\[
20y_D\le x_D\le90y_D.
\]

### Numero minimo di fornitori

\[
\sum_{i\in I}y_i\ge2.
\]

### Qualità media ponderata

Poiché la quantità totale è esattamente 180, il requisito

\[
\frac{\sum_{i\in I}q_i x_i}{180}\ge92
\]

è equivalente al vincolo lineare:

\[
\sum_{i\in I}q_i x_i\ge92\cdot180=16560.
\]

Esplicitamente:

\[
96x_A+90x_B+98x_C+88x_D\ge16560.
\]

### Emissioni totali

\[
\sum_{i\in I}e_i x_i\le650,
\]

ossia:

\[
3x_A+4x_B+2x_C+5x_D\le650.
\]

### Dominio

\[
x_i\in\mathbb{Z}_{\ge0},\qquad y_i\in\{0,1\}
\qquad \forall i\in I.
\]

## 3. Codice Python con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

I = ["A", "B", "C", "D"]

c = {"A": 11, "B": 10, "C": 12, "D": 9}
f = {"A": 80, "B": 95, "C": 60, "D": 120}
u = {"A": 80, "B": 100, "C": 70, "D": 90}
l = {"A": 20, "B": 25, "C": 15, "D": 20}
q = {"A": 96, "B": 90, "C": 98, "D": 88}
e = {"A": 3, "B": 4, "C": 2, "D": 5}

demand = 180
minimum_quality = 92
maximum_emissions = 650

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

def numeric_value(value):
    if abs(value) < 1e-9:
        return 0.0
    nearest_integer = round(value)
    if abs(value - nearest_integer) < 1e-6:
        return float(nearest_integer)
    return float(value)

with gp.Env(empty=True) as env:
    env.setParam("OutputFlag", 0)
    env.start()

    with gp.Model("M07_selezione_fornitori", env=env) as model:
        x = {
            i: model.addVar(
                lb=0,
                vtype=GRB.INTEGER,
                name=f"x_{i}"
            )
            for i in I
        }

        y = {
            i: model.addVar(
                vtype=GRB.BINARY,
                name=f"y_{i}"
            )
            for i in I
        }

        model.setObjective(
            gp.quicksum(c[i] * x[i] + f[i] * y[i] for i in I),
            GRB.MINIMIZE
        )

        model.addConstr(
            gp.quicksum(x[i] for i in I) == demand,
            name="domanda_esatta"
        )

        for i in I:
            model.addConstr(
                x[i] >= l[i] * y[i],
                name=f"ordine_minimo_{i}"
            )
            model.addConstr(
                x[i] <= u[i] * y[i],
                name=f"capacita_{i}"
            )

        model.addConstr(
            gp.quicksum(y[i] for i in I) >= 2,
            name="almeno_due_fornitori"
        )

        model.addConstr(
            gp.quicksum(q[i] * x[i] for i in I)
            >= minimum_quality * demand,
            name="qualita_minima"
        )

        model.addConstr(
            gp.quicksum(e[i] * x[i] for i in I)
            <= maximum_emissions,
            name="emissioni_massime"
        )

        model.optimize()

        status_code = model.Status
        status = status_names.get(status_code, f"STATUS_{status_code}")

        if status_code == GRB.OPTIMAL:
            variable_values = {}

            for i in I:
                variable_values[f"x_{i}"] = numeric_value(x[i].X)
            for i in I:
                variable_values[f"y_{i}"] = numeric_value(y[i].X)

            result = {
                "status": "OPTIMAL",
                "objective": numeric_value(model.ObjVal),
                "variables": variable_values
            }
        else:
            result = {
                "status": status,
                "objective": None,
                "variables": {}
            }

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```
