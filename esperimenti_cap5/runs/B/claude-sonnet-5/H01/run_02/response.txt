# H01 — Rete capacitata di centri distributivi

## 1. Insiemi, parametri e variabili decisionali

**Insiemi**
- $I = \{A,B,C,D,E,F\}$ : siti candidati
- $J = \{Z1,\dots,Z8\}$ : zone di domanda
- $N = \{A,B,C\} \subset I$ : gruppo Nord
- $S = \{D,E,F\} \subset I$ : gruppo Sud

**Parametri**
- $d_j$ : domanda della zona $j$
- $f_i$ : costo fisso di apertura del sito $i$
- $Q_i$ : capacità massima del sito $i$
- $c_{ij}$ : costo unitario di distribuzione da $i$ a $j$
- $e_{ij}$ : coefficiente di emissione da $i$ a $j$
- $m = 20$ : soglia minima di movimentazione per un sito aperto
- $E^{max} = 470$ : limite massimo di emissioni totali
- $p_{min}=3,\; p_{max}=4$ : numero minimo/massimo di siti aperti

**Variabili decisionali**
- $y_i \in \{0,1\}$ : 1 se il sito $i$ è aperto, 0 altrimenti
- $x_{ij} \ge 0$ : quantità distribuita dal sito $i$ alla zona $j$

## 2. Formulazione matematica

**Funzione obiettivo**
$$
\min \; \sum_{i\in I} f_i y_i \;+\; \sum_{i\in I}\sum_{j\in J} c_{ij} x_{ij}
$$

**Vincoli**

1. Soddisfacimento della domanda (ripartibile su più centri):
$$
\sum_{i\in I} x_{ij} = d_j \qquad \forall j\in J
$$

2. Capacità massima del sito (attiva solo se aperto):
$$
\sum_{j\in J} x_{ij} \le Q_i\, y_i \qquad \forall i\in I
$$

3. Movimentazione minima se aperto:
$$
\sum_{j\in J} x_{ij} \ge m\, y_i \qquad \forall i\in I
$$

4. Numero di centri aperti:
$$
p_{min} \le \sum_{i\in I} y_i \le p_{max}
$$

5. Resilienza territoriale:
$$
\sum_{i\in N} y_i \ge 1 \qquad\qquad \sum_{i\in S} y_i \ge 1
$$

6. Limite di emissioni:
$$
\sum_{i\in I}\sum_{j\in J} e_{ij} x_{ij} \le E^{max}
$$

7. Domini:
$$
y_i \in \{0,1\}\quad \forall i\in I, \qquad x_{ij}\ge 0 \quad \forall i\in I, j\in J
$$

## 3. Codice Python (gurobipy)

```python
import gurobipy as gp
from gurobipy import GRB
import json

# --- Dati ---
sites = ['A','B','C','D','E','F']
zones = ['Z1','Z2','Z3','Z4','Z5','Z6','Z7','Z8']

demand = {'Z1':30,'Z2':25,'Z3':35,'Z4':20,'Z5':28,'Z6':32,'Z7':24,'Z8':26}

fixed_cost = {'A':110,'B':95,'C':120,'D':90,'E':105,'F':100}
capacity   = {'A':90,'B':80,'C':110,'D':75,'E':95,'F':85}

unit_cost = {
    'Z1':{'A':4,'B':7,'C':6,'D':10,'E':9,'F':11},
    'Z2':{'A':5,'B':4,'C':8,'D':9,'E':7,'F':10},
    'Z3':{'A':7,'B':5,'C':4,'D':8,'E':9,'F':7},
    'Z4':{'A':9,'B':8,'C':7,'D':4,'E':5,'F':6},
    'Z5':{'A':8,'B':9,'C':6,'D':5,'E':4,'F':7},
    'Z6':{'A':10,'B':8,'C':7,'D':6,'E':5,'F':4},
    'Z7':{'A':6,'B':7,'C':5,'D':8,'E':6,'F':7},
    'Z8':{'A':7,'B':6,'C':8,'D':5,'E':7,'F':4},
}

emission = {
    'Z1':{'A':1,'B':2,'C':2,'D':4,'E':3,'F':4},
    'Z2':{'A':2,'B':1,'C':3,'D':3,'E':2,'F':4},
    'Z3':{'A':3,'B':2,'C':1,'D':3,'E':4,'F':3},
    'Z4':{'A':4,'B':3,'C':3,'D':1,'E':2,'F':2},
    'Z5':{'A':3,'B':4,'C':2,'D':2,'E':1,'F':3},
    'Z6':{'A':4,'B':3,'C':3,'D':2,'E':2,'F':1},
    'Z7':{'A':2,'B':3,'C':1,'D':3,'E':2,'F':3},
    'Z8':{'A':3,'B':2,'C':3,'D':1,'E':3,'F':1},
}

north = ['A','B','C']
south = ['D','E','F']

m_min = 20          # movimentazione minima se aperto
E_max = 470         # limite emissioni
p_min, p_max = 3, 4

# --- Modello ---
model = gp.Model("H01_rete_distributiva")

y = model.addVars(sites, vtype=GRB.BINARY, name="y")
x = model.addVars(sites, zones, lb=0.0, vtype=GRB.CONTINUOUS, name="x")

# Obiettivo
model.setObjective(
    gp.quicksum(fixed_cost[i]*y[i] for i in sites) +
    gp.quicksum(unit_cost[j][i]*x[i,j] for i in sites for j in zones),
    GRB.MINIMIZE
)

# Domanda soddisfatta
for j in zones:
    model.addConstr(gp.quicksum(x[i,j] for i in sites) == demand[j], name=f"dem_{j}")

# Capacità massima
for i in sites:
    model.addConstr(gp.quicksum(x[i,j] for j in zones) <= capacity[i]*y[i], name=f"cap_{i}")

# Movimentazione minima se aperto
for i in sites:
    model.addConstr(gp.quicksum(x[i,j] for j in zones) >= m_min*y[i], name=f"min_{i}")

# Numero centri aperti
model.addConstr(gp.quicksum(y[i] for i in sites) >= p_min, name="p_min")
model.addConstr(gp.quicksum(y[i] for i in sites) <= p_max, name="p_max")

# Resilienza Nord/Sud
model.addConstr(gp.quicksum(y[i] for i in north) >= 1, name="north_open")
model.addConstr(gp.quicksum(y[i] for i in south) >= 1, name="south_open")

# Limite emissioni
model.addConstr(
    gp.quicksum(emission[j][i]*x[i,j] for i in sites for j in zones) <= E_max,
    name="emission_cap"
)

model.optimize()

# --- Output ---
status_map = {
    GRB.OPTIMAL: "OPTIMAL",
    GRB.INFEASIBLE: "INFEASIBLE",
    GRB.UNBOUNDED: "UNBOUNDED",
    GRB.INF_OR_UNBD: "INF_OR_UNBD"
}

if model.status == GRB.OPTIMAL:
    variables = {}
    for i in sites:
        variables[f"y_{i}"] = float(round(y[i].X))
    for i in sites:
        for j in zones:
            variables[f"x_{i}_{j}"] = float(round(x[i,j].X, 4))
    result = {
        "status": "OPTIMAL",
        "objective": float(round(model.ObjVal, 4)),
        "variables": variables
    }
else:
    result = {
        "status": status_map.get(model.status, str(model.status)),
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result))
```

## 4. Sintesi della soluzione

Il modello MILP determina simultaneamente:
- **quali centri aprire** (3 o 4 tra i 6 siti candidati, con almeno uno nel gruppo Nord A–C e uno nel gruppo Sud D–F),
- **come ripartire la domanda** di ciascuna zona tra i centri aperti,

minimizzando la somma dei costi fissi di apertura e dei costi variabili di trasporto, nel rispetto dei vincoli di capacità massima, movimentazione minima (20 unità) per i centri aperti, e del tetto massimo di 470 unità di emissione complessiva.

Il codice risolve il problema con Gurobi e stampa in un'unica riga finale lo stato del solver (`OPTIMAL` se risolto), il valore ottimo della funzione obiettivo e tutti i valori delle variabili decisionali $y_i$ (apertura siti) e $x_{ij}$ (flussi di distribuzione), incluse quelle nulle, nel formato JSON richiesto.
