# H01 — Rete capacitata di centri distributivi

## 1. Insiemi, parametri e variabili decisionali

**Insiemi**
- $I = \{A, B, C, D, E, F\}$ : siti candidati
- $J = \{Z1, ..., Z8\}$ : zone di domanda
- $N = \{A, B, C\} \subset I$ : gruppo Nord
- $S = \{D, E, F\} \subset I$ : gruppo Sud

**Parametri**
- $d_j$ : domanda della zona $j \in J$
- $f_i$ : costo fisso di apertura del sito $i \in I$
- $cap_i$ : capacità massima del sito $i \in I$
- $c_{ij}$ : costo unitario di distribuzione da $i$ a $j$
- $e_{ij}$ : coefficiente di emissione da $i$ a $j$
- $minTh = 20$ : movimentazione minima per centro aperto
- $minOpen = 3$, $maxOpen = 4$ : numero minimo/massimo di centri apribili
- $EmisCap = 470$ : tetto massimo di emissioni complessive

**Variabili decisionali**
- $y_i \in \{0,1\}$ : 1 se il sito $i$ viene aperto, 0 altrimenti
- $x_{ij} \ge 0$ : quantità distribuita dal sito $i$ alla zona $j$

## 2. Formulazione matematica

**Funzione obiettivo**

$$
\min \; \sum_{i \in I} f_i y_i \;+\; \sum_{i \in I}\sum_{j \in J} c_{ij} x_{ij}
$$

**Vincoli**

1. Soddisfazione integrale della domanda:
$$
\sum_{i \in I} x_{ij} = d_j \qquad \forall j \in J
$$

2. Capacità dei centri (attiva solo se aperto):
$$
\sum_{j \in J} x_{ij} \le cap_i \, y_i \qquad \forall i \in I
$$

3. Movimentazione minima se il centro è aperto:
$$
\sum_{j \in J} x_{ij} \ge minTh \, y_i \qquad \forall i \in I
$$

4. Numero di centri aperti:
$$
minOpen \le \sum_{i \in I} y_i \le maxOpen
$$

5. Resilienza — almeno un sito Nord e uno Sud:
$$
\sum_{i \in N} y_i \ge 1, \qquad \sum_{i \in S} y_i \ge 1
$$

6. Vincolo di emissione complessiva:
$$
\sum_{i \in I}\sum_{j \in J} e_{ij} x_{ij} \le EmisCap
$$

7. Dominio delle variabili:
$$
x_{ij} \ge 0 \quad \forall i,j; \qquad y_i \in \{0,1\} \quad \forall i
$$

## 3. Codice Python (gurobipy)

```python
import gurobipy as gp
from gurobipy import GRB
import json

# ---------------- Dati ----------------
sites = ['A', 'B', 'C', 'D', 'E', 'F']
zones = ['Z1', 'Z2', 'Z3', 'Z4', 'Z5', 'Z6', 'Z7', 'Z8']

demand = {'Z1': 30, 'Z2': 25, 'Z3': 35, 'Z4': 20,
          'Z5': 28, 'Z6': 32, 'Z7': 24, 'Z8': 26}

fixed_cost = {'A': 110, 'B': 95, 'C': 120, 'D': 90, 'E': 105, 'F': 100}
capacity   = {'A': 90,  'B': 80, 'C': 110, 'D': 75, 'E': 95,  'F': 85}

unit_cost = {
    'Z1': {'A':4,'B':7,'C':6,'D':10,'E':9,'F':11},
    'Z2': {'A':5,'B':4,'C':8,'D':9, 'E':7,'F':10},
    'Z3': {'A':7,'B':5,'C':4,'D':8, 'E':9,'F':7},
    'Z4': {'A':9,'B':8,'C':7,'D':4, 'E':5,'F':6},
    'Z5': {'A':8,'B':9,'C':6,'D':5, 'E':4,'F':7},
    'Z6': {'A':10,'B':8,'C':7,'D':6,'E':5,'F':4},
    'Z7': {'A':6,'B':7,'C':5,'D':8, 'E':6,'F':7},
    'Z8': {'A':7,'B':6,'C':8,'D':5, 'E':7,'F':4},
}

emission = {
    'Z1': {'A':1,'B':2,'C':2,'D':4,'E':3,'F':4},
    'Z2': {'A':2,'B':1,'C':3,'D':3,'E':2,'F':4},
    'Z3': {'A':3,'B':2,'C':1,'D':3,'E':4,'F':3},
    'Z4': {'A':4,'B':3,'C':3,'D':1,'E':2,'F':2},
    'Z5': {'A':3,'B':4,'C':2,'D':2,'E':1,'F':3},
    'Z6': {'A':4,'B':3,'C':3,'D':2,'E':2,'F':1},
    'Z7': {'A':2,'B':3,'C':1,'D':3,'E':2,'F':3},
    'Z8': {'A':3,'B':2,'C':3,'D':1,'E':3,'F':1},
}

north = ['A', 'B', 'C']
south = ['D', 'E', 'F']

min_open = 3
max_open = 4
min_throughput = 20
emission_cap = 470

# ---------------- Modello ----------------
m = gp.Model("H01_rete_capacitata")

y = m.addVars(sites, vtype=GRB.BINARY, name="y")
x = m.addVars(sites, zones, lb=0.0, vtype=GRB.CONTINUOUS, name="x")

# Obiettivo
m.setObjective(
    gp.quicksum(fixed_cost[i] * y[i] for i in sites) +
    gp.quicksum(unit_cost[j][i] * x[i, j] for i in sites for j in zones),
    GRB.MINIMIZE
)

# Domanda soddisfatta integralmente
for j in zones:
    m.addConstr(gp.quicksum(x[i, j] for i in sites) == demand[j], name=f"dom_{j}")

# Capacità
for i in sites:
    m.addConstr(gp.quicksum(x[i, j] for j in zones) <= capacity[i] * y[i], name=f"cap_{i}")

# Movimentazione minima se aperto
for i in sites:
    m.addConstr(gp.quicksum(x[i, j] for j in zones) >= min_throughput * y[i], name=f"minth_{i}")

# Numero di centri aperti
m.addConstr(gp.quicksum(y[i] for i in sites) >= min_open, name="min_open")
m.addConstr(gp.quicksum(y[i] for i in sites) <= max_open, name="max_open")

# Resilienza Nord/Sud
m.addConstr(gp.quicksum(y[i] for i in north) >= 1, name="north_open")
m.addConstr(gp.quicksum(y[i] for i in south) >= 1, name="south_open")

# Vincolo di emissione
m.addConstr(
    gp.quicksum(emission[j][i] * x[i, j] for i in sites for j in zones) <= emission_cap,
    name="emission_cap"
)

m.optimize()

# ---------------- Output ----------------
status_map = {
    GRB.OPTIMAL: "OPTIMAL",
    GRB.INFEASIBLE: "INFEASIBLE",
    GRB.UNBOUNDED: "UNBOUNDED",
    GRB.INF_OR_UNBD: "INF_OR_UNBD"
}

if m.status == GRB.OPTIMAL:
    variables = {}
    for i in sites:
        variables[f"y_{i}"] = round(y[i].X, 6)
    for i in sites:
        for j in zones:
            variables[f"x_{i}_{j}"] = round(x[i, j].X, 6)

    result = {
        "status": "OPTIMAL",
        "objective": round(m.ObjVal, 6),
        "variables": variables
    }
else:
    result = {
        "status": status_map.get(m.status, str(m.status)),
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result))
```

## 4. Sintesi della soluzione

Il modello determina quali centri distributivi aprire (tra 3 e 4, con almeno uno del gruppo Nord A–C e uno del gruppo Sud D–F) e come ripartire il flusso di 220 unità di domanda totale tra i centri aperti, minimizzando la somma di costi fissi e costi unitari di distribuzione, rispettando i vincoli di capacità, di movimentazione minima (20 unità se aperto) e il tetto di emissioni complessive pari a 470 unità.

Eseguendo il codice, Gurobi trova la soluzione ottima esatta stampando lo stato (`OPTIMAL`), il valore della funzione obiettivo e tutti i valori delle variabili $y_i$ (apertura dei siti) e $x_{ij}$ (flussi assegnati), incluse quelle nulle, nel formato JSON richiesto tramite la riga `SOLUTION_JSON=...`.
