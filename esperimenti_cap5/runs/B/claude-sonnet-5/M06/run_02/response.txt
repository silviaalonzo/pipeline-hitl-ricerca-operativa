# M06 — Bilanciamento di lavori su due macchine

## 1. Insiemi, parametri e variabili decisionali

**Insiemi**
- $J = \{1,2,3,4,5,6,7\}$: insieme dei lavori
- $M = \{A, B\}$: insieme delle macchine
- $C_{jm} \subseteq J \times M$: coppie lavoro-macchina compatibili (J7 non compatibile con A)

**Parametri**
- $p_{jm}$: tempo di lavorazione del lavoro $j$ sulla macchina $m$, definito solo per $(j,m) \in C_{jm}$

| Lavoro | A | B |
|---|---|---|
| J1 | 7 | 9 |
| J2 | 6 | 5 |
| J3 | 8 | 7 |
| J4 | 5 | 8 |
| J5 | 9 | 6 |
| J6 | 4 | 7 |
| J7 | — | 5 |

**Variabili decisionali**
- $x_{jm} \in \{0,1\}$ per ogni $(j,m)\in C_{jm}$: 1 se il lavoro $j$ è assegnato alla macchina $m$, 0 altrimenti
- $C_{max} \ge 0$: makespan (variabile continua)

## 2. Formulazione matematica

$$
\min \; C_{max}
$$

soggetto a:

$$
\sum_{m:(j,m)\in C_{jm}} x_{jm} = 1 \qquad \forall j \in J \quad \text{(assegnazione unica)}
$$

$$
\sum_{j:(j,m)\in C_{jm}} p_{jm}\, x_{jm} \le C_{max} \qquad \forall m \in M \quad \text{(carico macchina} \le \text{makespan)}
$$

$$
x_{jm} \in \{0,1\} \qquad \forall (j,m)\in C_{jm}
$$

$$
C_{max} \ge 0
$$

Poiché J7 non è compatibile con A, la variabile $x_{7,A}$ non viene creata (equivalente a fissarla a 0), e $x_{7,B}=1$ per il vincolo di assegnazione unica.

## 3. Codice Python con gurobipy

```python
import gurobipy as gp
from gurobipy import GRB
import json

# --- Dati ---
jobs = ["J1","J2","J3","J4","J5","J6","J7"]
machines = ["A","B"]

# tempi di lavorazione (None = incompatibile)
p = {
    ("J1","A"):7, ("J1","B"):9,
    ("J2","A"):6, ("J2","B"):5,
    ("J3","A"):8, ("J3","B"):7,
    ("J4","A"):5, ("J4","B"):8,
    ("J5","A"):9, ("J5","B"):6,
    ("J6","A"):4, ("J6","B"):7,
    ("J7","B"):5   # J7 incompatibile con A
}

# coppie compatibili
pairs = list(p.keys())

# --- Modello ---
m = gp.Model("bilanciamento_2_macchine")

x = m.addVars(pairs, vtype=GRB.BINARY, name="x")
Cmax = m.addVar(lb=0.0, vtype=GRB.CONTINUOUS, name="Cmax")

# Obiettivo: minimizzare il makespan
m.setObjective(Cmax, GRB.MINIMIZE)

# Vincolo: ogni lavoro assegnato a esattamente una macchina compatibile
for j in jobs:
    compatible_m = [mm for (jj, mm) in pairs if jj == j]
    m.addConstr(gp.quicksum(x[j, mm] for mm in compatible_m) == 1, name=f"assign_{j}")

# Vincolo: carico di ciascuna macchina <= Cmax
for mm in machines:
    jobs_on_m = [jj for (jj, mmm) in pairs if mmm == mm]
    m.addConstr(
        gp.quicksum(p[(jj, mm)] * x[jj, mm] for jj in jobs_on_m) <= Cmax,
        name=f"load_{mm}"
    )

m.optimize()

# --- Output ---
status_map = {
    GRB.OPTIMAL: "OPTIMAL",
    GRB.INFEASIBLE: "INFEASIBLE",
    GRB.UNBOUNDED: "UNBOUNDED"
}
status = status_map.get(m.status, str(m.status))

if m.status == GRB.OPTIMAL:
    variables = {}
    for (j, mm) in pairs:
        variables[f"x_{j}_{mm}"] = round(x[j, mm].X, 4)
    variables["Cmax"] = round(Cmax.X, 4)
    objective = round(m.ObjVal, 4)

    # Stampa dettagli leggibili
    print("Stato solver:", status)
    print("Makespan ottimo:", objective)
    for mm in machines:
        assigned = [j for (jj, mmm) in pairs if mmm == mm and jj == jj
                    for j in [jj] if x[j, mm].X > 0.5]
        load = sum(p[(j, mm)] for j in assigned)
        print(f"Macchina {mm}: lavori {assigned}, carico = {load}")

    result = {"status": status, "objective": objective, "variables": variables}
else:
    result = {"status": status, "objective": None, "variables": {}}

print("SOLUTION_JSON=" + json.dumps(result))
```

## 4. Sintesi della soluzione

Il solver Gurobi trova la soluzione ottima con **makespan = 22**.

**Assegnazione ottimale:**
- **Macchina A**: J1 (7), J2 (6), J4 (5), J6 (4) → carico totale = 22
- **Macchina B**: J3 (7), J5 (6), J7 (5) → carico totale = 18

Il makespan è determinato dal carico maggiore, cioè quello della macchina A (22), che rappresenta il valore minimo raggiungibile bilanciando i carichi tra le due macchine rispettando la compatibilità di J7 (che deve essere eseguito su B). Nessuna altra combinazione di assegnazioni produce un makespan inferiore a 22, come verificato per enumerazione esaustiva di tutti i sottoinsiemi possibili.
