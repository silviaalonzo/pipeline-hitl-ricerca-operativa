# H02 — Produzione multi-periodo con setup e scorte

## 1. Insiemi, parametri e variabili decisionali

**Insiemi**
- $I = \{A, B, C\}$ : prodotti
- $T = \{1,2,3,4\}$ : periodi

**Parametri**
- $d_{i,t}$ : domanda del prodotto $i$ nel periodo $t$
- $c_{i,t}$ : costo unitario di produzione
- $s_i$ : costo di setup del prodotto $i$
- $h_i$ : costo unitario di mantenimento a scorta
- $a_i$ : ore richieste per unità prodotta
- $L_i$ : lotto minimo di produzione (se attivato il setup)
- $Cap_t$ : capacità in ore del periodo $t$
- $I^0_i$ : scorta iniziale ($I^0_A=0,\ I^0_B=0,\ I^0_C=6$)
- $MaxSetup = 2$ : massimo numero di articoli attivabili per periodo
- $MaxInv = 20$ : massima scorta totale per periodo
- $M_i = \sum_{t\in T} d_{i,t} - I^0_i$ : bound superiore (big-M) sulla produzione, valido perché la produzione totale sull'orizzonte deve coprire esattamente la domanda totale meno la scorta iniziale (scorta finale nulla)

**Variabili decisionali**
- $x_{i,t}\ge 0,\ \text{intero}$ : quantità prodotta di $i$ nel periodo $t$
- $I_{i,t}\ge 0,\ \text{intero}$ : scorta finale di $i$ al termine del periodo $t$
- $y_{i,t}\in\{0,1\}$ : indicatore di setup (1 se si produce $i$ in $t$)

## 2. Formulazione matematica

**Funzione obiettivo**
$$
\min \sum_{i\in I}\sum_{t\in T} c_{i,t}\,x_{i,t} \;+\; \sum_{i\in I}\sum_{t\in T} s_i\,y_{i,t} \;+\; \sum_{i\in I}\sum_{t\in T} h_i\,I_{i,t}
$$

**Vincoli**

1. Bilancio di magazzino:
$$
I_{i,t-1} + x_{i,t} - d_{i,t} = I_{i,t} \qquad \forall i\in I,\ \forall t\in T \quad (I_{i,0}=I^0_i)
$$

2. Collegamento produzione–setup (big-M):
$$
x_{i,t} \le M_i\, y_{i,t} \qquad \forall i\in I,\ \forall t\in T
$$

3. Lotto minimo:
$$
x_{i,t} \ge L_i\, y_{i,t} \qquad \forall i\in I,\ \forall t\in T
$$

4. Capacità produttiva:
$$
\sum_{i\in I} a_i\, x_{i,t} \le Cap_t \qquad \forall t\in T
$$

5. Numero massimo di setup per periodo:
$$
\sum_{i\in I} y_{i,t} \le MaxSetup \qquad \forall t\in T
$$

6. Scorta totale massima per periodo:
$$
\sum_{i\in I} I_{i,t} \le MaxInv \qquad \forall t\in T
$$

7. Scorta finale nulla:
$$
I_{i,4} = 0 \qquad \forall i\in I
$$

8. Dominio:
$$
x_{i,t}\in\mathbb{Z}_{\ge 0},\quad I_{i,t}\in\mathbb{Z}_{\ge 0},\quad y_{i,t}\in\{0,1\}
$$

## 3. Codice Python (gurobipy)

```python
import json
from gurobipy import Model, GRB, quicksum

# ---------------- DATI ----------------
products = ['A', 'B', 'C']
periods = [1, 2, 3, 4]

demand = {
    ('A',1):8, ('A',2):12, ('A',3):10, ('A',4):14,
    ('B',1):10, ('B',2):8, ('B',3):14, ('B',4):12,
    ('C',1):6, ('C',2):9, ('C',3):7, ('C',4):11,
}

prod_cost = {
    ('A',1):9, ('A',2):11, ('A',3):10, ('A',4):12,
    ('B',1):8, ('B',2):9, ('B',3):11, ('B',4):10,
    ('C',1):13, ('C',2):12, ('C',3):14, ('C',4):11,
}

setup_cost = {'A':45, 'B':40, 'C':50}
holding_cost = {'A':2, 'B':3, 'C':2}
hours_per_unit = {'A':2, 'B':3, 'C':4}
min_lot = {'A':4, 'B':4, 'C':3}

init_inv = {'A':0, 'B':0, 'C':6}

capacity = {1:90, 2:95, 3:90, 4:100}

MAX_SETUPS = 2
MAX_INV_TOTAL = 20

# Big-M: produzione totale sull'orizzonte = domanda totale - scorta iniziale
total_demand = {i: sum(demand[i,t] for t in periods) for i in products}
bigM = {i: total_demand[i] - init_inv[i] for i in products}

# ---------------- MODELLO ----------------
m = Model("H02_multiperiodo")

x = m.addVars(products, periods, vtype=GRB.INTEGER, lb=0, name="x")
I = m.addVars(products, periods, vtype=GRB.INTEGER, lb=0, name="I")
y = m.addVars(products, periods, vtype=GRB.BINARY, name="y")

# Funzione obiettivo
obj = quicksum(prod_cost[i,t]*x[i,t] for i in products for t in periods) \
    + quicksum(setup_cost[i]*y[i,t] for i in products for t in periods) \
    + quicksum(holding_cost[i]*I[i,t] for i in products for t in periods)
m.setObjective(obj, GRB.MINIMIZE)

# Bilancio di magazzino
for i in products:
    prev = init_inv[i]
    for t in periods:
        m.addConstr(prev + x[i,t] - demand[i,t] == I[i,t], name=f"bal_{i}_{t}")
        prev = I[i,t]

# Collegamento setup - produzione (big-M) e lotto minimo
for i in products:
    for t in periods:
        m.addConstr(x[i,t] <= bigM[i]*y[i,t], name=f"bigM_{i}_{t}")
        m.addConstr(x[i,t] >= min_lot[i]*y[i,t], name=f"minlot_{i}_{t}")

# Capacità produttiva
for t in periods:
    m.addConstr(quicksum(hours_per_unit[i]*x[i,t] for i in products) <= capacity[t],
                name=f"cap_{t}")

# Massimo numero di setup per periodo
for t in periods:
    m.addConstr(quicksum(y[i,t] for i in products) <= MAX_SETUPS, name=f"maxsetup_{t}")

# Scorta totale massima per periodo
for t in periods:
    m.addConstr(quicksum(I[i,t] for i in products) <= MAX_INV_TOTAL, name=f"maxinv_{t}")

# Scorta finale nulla
for i in products:
    m.addConstr(I[i,periods[-1]] == 0, name=f"finalinv_{i}")

m.optimize()

# ---------------- OUTPUT ----------------
status_map = {
    GRB.OPTIMAL: "OPTIMAL",
    GRB.INFEASIBLE: "INFEASIBLE",
    GRB.UNBOUNDED: "UNBOUNDED",
}
status = status_map.get(m.status, str(m.status))

variables = {}
objective = None

if m.status == GRB.OPTIMAL:
    objective = m.objVal
    for i in products:
        for t in periods:
            variables[f"x_{i}_{t}"] = round(x[i,t].X)
            variables[f"I_{i}_{t}"] = round(I[i,t].X)
            variables[f"y_{i}_{t}"] = round(y[i,t].X)

    print("\n--- Riepilogo decisioni non nulle ---")
    for i in products:
        for t in periods:
            if x[i,t].X > 1e-6:
                print(f"x[{i},{t}] = {x[i,t].X:.0f}")
    for i in products:
        for t in periods:
            if I[i,t].X > 1e-6:
                print(f"I[{i},{t}] = {I[i,t].X:.0f}")
    for i in products:
        for t in periods:
            if y[i,t].X > 0.5:
                print(f"y[{i},{t}] = 1")
    print(f"Costo totale ottimo = {objective:.2f}")

result = {
    "status": status,
    "objective": objective,
    "variables": variables
}
print("SOLUTION_JSON=" + json.dumps(result))
```

## 4. Sintesi della soluzione

Il modello determina il piano di produzione a costo minimo sui 4 periodi per i tre articoli A, B, C, rispettando:
- il bilancio di magazzino con scorte iniziali (0, 0, 6) e finali nulle;
- il vincolo di lotto minimo legato al setup (big-M coerente con la domanda totale residua);
- il limite di 2 setup attivi per periodo;
- il limite di 20 unità di scorta totale per periodo;
- la capacità produttiva (in ore) per ciascun periodo.

Il solver Gurobi risolve il MILP intero risultante (variabili di produzione e scorta intere, setup binari) e riporta lo stato ottimale, il costo totale (somma di produzione, setup e mantenimento) e il dettaglio di tutte le variabili non nulle, secondo il formato `SOLUTION_JSON` richiesto.
