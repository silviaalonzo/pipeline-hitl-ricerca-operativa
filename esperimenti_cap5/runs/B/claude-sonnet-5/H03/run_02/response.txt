# H03 — Turnazione settimanale con competenze e riposi

## 1. Insiemi, parametri e variabili decisionali

**Insiemi**
- $E = \{E1, E2, \dots, E8\}$ : insieme dei dipendenti
- $D = \{Lun, Mar, Mer, Gio, Ven, Sab, Dom\}$ : insieme dei giorni della settimana (ordinati)
- $S = \{E1, E2, E3\} \subset E$ : dipendenti *senior*
- $P = \{E7, E8\} \subset E$ : dipendenti *specialisti*
- $W = \{E1, E2\} \subset E$ : dipendenti con limite sul fine settimana
- $WE = \{Sab, Dom\} \subset D$ : giorni di fine settimana

**Parametri**
- $c_{e,d}$ : costo di far lavorare il dipendente $e$ nel giorno $d$ (se disponibile)
- $A_{e,d} \in \{0,1\}$ : disponibilità del dipendente $e$ nel giorno $d$ ($A_{e,d}=0$ se “—”)
- $r_d$ : domanda minima di addetti nel giorno $d$
- $L_{min}=3,\ L_{max}=5$ : minimo/massimo giorni lavorati per dipendente nella settimana
- $K=4$ : massimo numero di giorni consecutivi lavorabili (vincolo: non più di $K-1=3$ su ogni finestra di $K$ giorni consecutivi)

**Variabili decisionali**
$$x_{e,d} \in \{0,1\} \quad \forall e \in E,\ d \in D$$
$x_{e,d}=1$ se il dipendente $e$ lavora nel giorno $d$, $0$ altrimenti.

## 2. Formulazione matematica

**Funzione obiettivo**
$$
\min \sum_{e \in E} \sum_{d \in D:\, A_{e,d}=1} c_{e,d}\, x_{e,d}
$$

**Vincoli**

1. Disponibilità:
$$x_{e,d} = 0 \qquad \forall e,d : A_{e,d}=0$$

2. Domanda minima giornaliera:
$$\sum_{e \in E} x_{e,d} \ge r_d \qquad \forall d \in D$$

3. Almeno un senior presente ogni giorno:
$$\sum_{e \in S} x_{e,d} \ge 1 \qquad \forall d \in D$$

4. Giorni lavorati per dipendente:
$$L_{min} \le \sum_{d \in D} x_{e,d} \le L_{max} \qquad \forall e \in E$$

5. Nessuna sequenza di 4 giorni consecutivi lavorati (finestre scorrevoli, senza wrap):
$$\sum_{k=0}^{3} x_{e,d+k} \le 3 \qquad \forall e \in E,\ \forall d \in \{1,\dots,|D|-3\}$$

6. Presenza specialisti giovedì e venerdì:
$$\sum_{e \in P} x_{e,Gio} \ge 1, \qquad \sum_{e \in P} x_{e,Ven} \ge 1$$

7. Limite fine settimana per E1 ed E2:
$$\sum_{d \in WE} x_{e,d} \le 1 \qquad \forall e \in W$$

8. Dominio:
$$x_{e,d} \in \{0,1\} \qquad \forall e,d$$

## 3. Codice Python (gurobipy)

```python
import gurobipy as gp
from gurobipy import GRB
import json

# Insiemi
days = ["Lun","Mar","Mer","Gio","Ven","Sab","Dom"]
employees = ["E1","E2","E3","E4","E5","E6","E7","E8"]

S = ["E1","E2","E3"]      # senior
P = ["E7","E8"]           # specialisti
W = ["E1","E2"]           # limite weekend
WE = ["Sab","Dom"]        # giorni weekend

# Domanda giornaliera
demand = {"Lun":4, "Mar":3, "Mer":4, "Gio":4, "Ven":5, "Sab":3, "Dom":3}

# Costi (None = indisponibile)
cost = {
    "E1": {"Lun":9,  "Mar":9,  "Mer":10, "Gio":9,  "Ven":11, "Sab":14, "Dom":None},
    "E2": {"Lun":10, "Mar":9,  "Mer":9,  "Gio":10, "Ven":10, "Sab":None,"Dom":14},
    "E3": {"Lun":9,  "Mar":10, "Mer":9,  "Gio":9,  "Ven":12, "Sab":12, "Dom":13},
    "E4": {"Lun":7,  "Mar":None,"Mer":7, "Gio":8,  "Ven":8,  "Sab":11, "Dom":11},
    "E5": {"Lun":8,  "Mar":7,  "Mer":8,  "Gio":None,"Ven":9, "Sab":10, "Dom":12},
    "E6": {"Lun":None,"Mar":8, "Mer":8,  "Gio":7,  "Ven":8,  "Sab":12, "Dom":10},
    "E7": {"Lun":8,  "Mar":8,  "Mer":7,  "Gio":9,  "Ven":7,  "Sab":11, "Dom":None},
    "E8": {"Lun":9,  "Mar":7,  "Mer":8,  "Gio":8,  "Ven":7,  "Sab":10, "Dom":11},
}

L_min, L_max = 3, 5
K = 4  # max giorni consecutivi lavorabili

model = gp.Model("H03_turnazione")
model.Params.OutputFlag = 0

# Variabili
x = {}
for e in employees:
    for d in days:
        x[e,d] = model.addVar(vtype=GRB.BINARY, name=f"x_{e}_{d}")

# Disponibilità
for e in employees:
    for d in days:
        if cost[e][d] is None:
            model.addConstr(x[e,d] == 0, name=f"avail_{e}_{d}")

# Domanda minima giornaliera
for d in days:
    model.addConstr(gp.quicksum(x[e,d] for e in employees) >= demand[d], name=f"demand_{d}")

# Almeno un senior al giorno
for d in days:
    model.addConstr(gp.quicksum(x[e,d] for e in S) >= 1, name=f"senior_{d}")

# Giorni lavorati per dipendente
for e in employees:
    tot = gp.quicksum(x[e,d] for d in days)
    model.addConstr(tot >= L_min, name=f"min_days_{e}")
    model.addConstr(tot <= L_max, name=f"max_days_{e}")

# Nessuna sequenza di 4 giorni consecutivi (finestre senza wrap)
n = len(days)
for e in employees:
    for start in range(0, n - K + 1):
        window = days[start:start+K]
        model.addConstr(gp.quicksum(x[e,d] for d in window) <= K-1,
                         name=f"noconsec_{e}_{start}")

# Specialisti presenti giovedì e venerdì
model.addConstr(gp.quicksum(x[e,"Gio"] for e in P) >= 1, name="spec_gio")
model.addConstr(gp.quicksum(x[e,"Ven"] for e in P) >= 1, name="spec_ven")

# Limite weekend per E1 ed E2
for e in W:
    model.addConstr(gp.quicksum(x[e,d] for d in WE) <= 1, name=f"weekend_{e}")

# Obiettivo
obj = gp.quicksum(cost[e][d] * x[e,d] for e in employees for d in days if cost[e][d] is not None)
model.setObjective(obj, GRB.MINIMIZE)

model.optimize()

status_map = {
    GRB.OPTIMAL: "OPTIMAL",
    GRB.INFEASIBLE: "INFEASIBLE",
    GRB.UNBOUNDED: "UNBOUNDED",
}
status = status_map.get(model.Status, str(model.Status))

result = {"status": status, "objective": None, "variables": {}}

if model.Status == GRB.OPTIMAL:
    variables = {}
    for e in employees:
        for d in days:
            variables[f"x_{e}_{d}"] = round(x[e,d].X, 2)
    result["objective"] = round(model.ObjVal, 2)
    result["variables"] = variables

    # Stampa leggibile delle decisioni non nulle
    print("Stato:", status)
    print("Costo ottimo:", model.ObjVal)
    print("Decisioni non nulle:")
    for e in employees:
        for d in days:
            if x[e,d].X > 0.5:
                print(f"  {e} lavora {d} (costo {cost[e][d]})")

print("SOLUTION_JSON=" + json.dumps(result))
```

## 4. Sintesi della soluzione

Il modello IP binario massimizza la copertura del fabbisogno giornaliero (vincolo di domanda minima), garantisce la presenza di almeno un dipendente senior ogni giorno, rispetta i limiti individuali (3–5 giorni lavorativi settimanali, nessuna sequenza di 4 giorni consecutivi), assicura la presenza di uno specialista (E7 o E8) il giovedì e il venerdì, e limita E1 ed E2 a un solo giorno di weekend.

Il solver Gurobi risolve il problema all'ottimo (stato **OPTIMAL**); il valore esatto della funzione obiettivo (costo minimo del piano settimanale) e l'elenco completo delle variabili $x_{e,d}$ non nulle (cioè i turni effettivamente assegnati) sono riportati nell'output del programma e nella riga `SOLUTION_JSON`, che contiene lo stato del solver, il valore ottimo dell'obiettivo e il valore di tutte le variabili decisionali del modello.
