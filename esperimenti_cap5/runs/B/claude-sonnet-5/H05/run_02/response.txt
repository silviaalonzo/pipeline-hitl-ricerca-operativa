# H05 — Portafoglio pluriennale con sinergie

## 1. Insiemi, parametri e variabili decisionali

**Insiemi**
- $P = \{A,B,C,D,E,F,G,H,I,J,K,L\}$ = insieme dei progetti
- $T = \{1,2,3\}$ = anni dell'orizzonte triennale
- $Dig = \{A,C,G,J\}$ = progetti digitali
- $Sos = \{E,H,K\}$ = progetti sostenibili

**Parametri**
- $v_i$ = VAN del progetto $i \in P$
- $c_{i,t}$ = costo del progetto $i$ nell'anno $t \in T$
- $p_i$ = personale richiesto dal progetto $i$
- $r_i$ = rischio del progetto $i$
- $Bud_t$ = budget disponibile nell'anno $t$ (110, 100, 90)
- $Pmax = 28$ = limite di personale complessivo
- $Rmax = 32$ = limite di rischio complessivo
- $Nmax = 8$ = numero massimo di progetti selezionabili
- $s^{AC} = 12$, $s^{EK} = 10$ = valori delle sinergie

**Variabili decisionali**
- $x_i \in \{0,1\}\quad \forall i \in P$: 1 se il progetto $i$ è selezionato
- $y_{AC} \in \{0,1\}$: 1 se sia $A$ che $C$ sono selezionati (sinergia attiva)
- $y_{EK} \in \{0,1\}$: 1 se sia $E$ che $K$ sono selezionati (sinergia attiva)

## 2. Formulazione matematica

**Funzione obiettivo**

$$\max \; Z = \sum_{i \in P} v_i x_i \;+\; s^{AC} y_{AC} \;+\; s^{EK} y_{EK}$$

**Vincoli**

Budget annuali:
$$\sum_{i \in P} c_{i,t}\, x_i \le Bud_t \qquad \forall t \in T$$

Personale:
$$\sum_{i \in P} p_i\, x_i \le Pmax$$

Rischio:
$$\sum_{i \in P} r_i\, x_i \le Rmax$$

Dipendenze:
$$x_G \le x_B,\qquad x_J \le x_E,\qquad x_K \le x_C$$

Incompatibilità:
$$x_D + x_H \le 1,\qquad x_F + x_L \le 1$$

Requisiti minimi:
$$\sum_{i \in Dig} x_i \ge 2,\qquad \sum_{i \in Sos} x_i \ge 1$$

Numero massimo di progetti:
$$\sum_{i \in P} x_i \le Nmax$$

Linearizzazione esplicita delle sinergie (AND logico):
$$y_{AC} \le x_A,\quad y_{AC} \le x_C,\quad y_{AC} \ge x_A + x_C - 1$$
$$y_{EK} \le x_E,\quad y_{EK} \le x_K,\quad y_{EK} \ge x_E + x_K - 1$$

Dominio:
$$x_i \in \{0,1\}\ \forall i \in P,\qquad y_{AC}, y_{EK} \in \{0,1\}$$

## 3. Codice Python (gurobipy)

```python
import gurobipy as gp
from gurobipy import GRB
import json

# --- Dati ---
projects = ["A","B","C","D","E","F","G","H","I","J","K","L"]

van   = {"A":42,"B":35,"C":48,"D":31,"E":40,"F":28,
         "G":55,"H":37,"I":33,"J":50,"K":46,"L":29}

cost1 = {"A":18,"B":20,"C":25,"D":15,"E":22,"F":14,
         "G":30,"H":20,"I":17,"J":27,"K":24,"L":16}

cost2 = {"A":12,"B":18,"C":20,"D":14,"E":16,"F":12,
         "G":25,"H":18,"I":15,"J":21,"K":19,"L":13}

cost3 = {"A":10,"B":14,"C":18,"D":12,"E":15,"F":10,
         "G":22,"H":16,"I":12,"J":18,"K":17,"L":11}

personnel = {"A":4,"B":4,"C":5,"D":3,"E":4,"F":3,
             "G":6,"H":4,"I":3,"J":5,"K":5,"L":3}

risk = {"A":5,"B":4,"C":6,"D":3,"E":4,"F":2,
        "G":7,"H":5,"I":3,"J":6,"K":5,"L":3}

budget = {1:110, 2:100, 3:90}
Pmax = 28
Rmax = 32
Nmax = 8
digital = ["A","C","G","J"]
sustainable = ["E","H","K"]
s_AC = 12
s_EK = 10

# --- Modello ---
m = gp.Model("H05_portafoglio")

x = m.addVars(projects, vtype=GRB.BINARY, name="x")
y_AC = m.addVar(vtype=GRB.BINARY, name="y_AC")
y_EK = m.addVar(vtype=GRB.BINARY, name="y_EK")

# Funzione obiettivo
m.setObjective(
    gp.quicksum(van[i]*x[i] for i in projects) + s_AC*y_AC + s_EK*y_EK,
    GRB.MAXIMIZE
)

# Budget annuali
m.addConstr(gp.quicksum(cost1[i]*x[i] for i in projects) <= budget[1], name="budget_y1")
m.addConstr(gp.quicksum(cost2[i]*x[i] for i in projects) <= budget[2], name="budget_y2")
m.addConstr(gp.quicksum(cost3[i]*x[i] for i in projects) <= budget[3], name="budget_y3")

# Personale
m.addConstr(gp.quicksum(personnel[i]*x[i] for i in projects) <= Pmax, name="personnel")

# Rischio
m.addConstr(gp.quicksum(risk[i]*x[i] for i in projects) <= Rmax, name="risk")

# Dipendenze
m.addConstr(x["G"] <= x["B"], name="G_requires_B")
m.addConstr(x["J"] <= x["E"], name="J_requires_E")
m.addConstr(x["K"] <= x["C"], name="K_requires_C")

# Incompatibilità
m.addConstr(x["D"] + x["H"] <= 1, name="incomp_DH")
m.addConstr(x["F"] + x["L"] <= 1, name="incomp_FL")

# Requisiti minimi
m.addConstr(gp.quicksum(x[i] for i in digital) >= 2, name="min_digital")
m.addConstr(gp.quicksum(x[i] for i in sustainable) >= 1, name="min_sostenibile")

# Numero massimo di progetti
m.addConstr(gp.quicksum(x[i] for i in projects) <= Nmax, name="max_progetti")

# Linearizzazione sinergie (AND logico)
m.addConstr(y_AC <= x["A"], name="syn_AC_1")
m.addConstr(y_AC <= x["C"], name="syn_AC_2")
m.addConstr(y_AC >= x["A"] + x["C"] - 1, name="syn_AC_3")

m.addConstr(y_EK <= x["E"], name="syn_EK_1")
m.addConstr(y_EK <= x["K"], name="syn_EK_2")
m.addConstr(y_EK >= x["E"] + x["K"] - 1, name="syn_EK_3")

m.optimize()

# --- Output ---
result = {"status": None, "objective": None, "variables": {}}

if m.status == GRB.OPTIMAL:
    result["status"] = "OPTIMAL"
    result["objective"] = round(m.objVal, 4)
    variables = {}
    for i in projects:
        variables[f"x_{i}"] = round(x[i].X, 4)
    variables["y_AC"] = round(y_AC.X, 4)
    variables["y_EK"] = round(y_EK.X, 4)
    result["variables"] = variables
else:
    result["status"] = str(m.status)

print("SOLUTION_JSON=" + json.dumps(result))
```

## 4. Sintesi della soluzione

Il modello IP binario seleziona il sottoinsieme di progetti che massimizza il VAN complessivo (comprese le sinergie A–C e E–K), rispettando simultaneamente i tre budget annuali, il limite di personale (28), il limite di rischio (32), i vincoli di dipendenza (G→B, J→E, K→C), le incompatibilità (D–H, F–L), i requisiti minimi su progetti digitali (≥2 tra A,C,G,J) e sostenibili (≥1 tra E,H,K), e il tetto massimo di 8 progetti selezionati. Il solver Gurobi risolve il problema all'ottimalità in tempi immediati (istanza di piccola taglia); l'output `SOLUTION_JSON` riporta lo stato "OPTIMAL", il valore del VAN complessivo ottenuto (incluse le sinergie attivate) e l'elenco completo dei progetti selezionati (variabili $x_i=1$) insieme all'indicazione di quali sinergie ($y_{AC}$, $y_{EK}$) risultano effettivamente attivate nella soluzione ottima.
