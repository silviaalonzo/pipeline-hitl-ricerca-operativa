# M03 — Assegnazione del personale ai turni

## 1. Insiemi, parametri e variabili decisionali

**Insiemi**
- $E = \{Ana, Bruno, Carla, Diego, Elena, Fabio\}$ — dipendenti
- $S = \{M1, M2, P1, P2, N1, N2\}$ — turni
- $N \subset S = \{N1, N2\}$ — turni notturni
- $A \subseteq E \times S$ — coppie (dipendente, turno) **disponibili** (escludendo le celle “—”)

**Parametri**
- $c_{e,s}$ = costo dell'assegnazione del dipendente $e$ al turno $s$, per $(e,s) \in A$
- Ogni turno $s \in S$ richiede esattamente 1 persona
- Ogni dipendente può fare al massimo 2 turni
- Ogni dipendente può fare al massimo 1 turno notturno

**Variabili decisionali**
$$x_{e,s} \in \{0,1\} \quad \forall (e,s) \in A$$
$x_{e,s} = 1$ se il dipendente $e$ è assegnato al turno $s$, 0 altrimenti.

## 2. Formulazione matematica

$$
\min \sum_{(e,s)\in A} c_{e,s}\, x_{e,s}
$$

soggetto a:

$$
\sum_{e:(e,s)\in A} x_{e,s} = 1 \qquad \forall s \in S \quad \text{(copertura turni)}
$$

$$
\sum_{s:(e,s)\in A} x_{e,s} \le 2 \qquad \forall e \in E \quad \text{(max 2 turni/dipendente)}
$$

$$
\sum_{s \in N:(e,s)\in A} x_{e,s} \le 1 \qquad \forall e \in E \quad \text{(max 1 notturno/dipendente)}
$$

$$
x_{e,s} \in \{0,1\} \qquad \forall (e,s)\in A
$$

## 3. Codice Python (gurobipy)

```python
import gurobipy as gp
from gurobipy import GRB
import json

# Insiemi
E = ['Ana', 'Bruno', 'Carla', 'Diego', 'Elena', 'Fabio']
S = ['M1', 'M2', 'P1', 'P2', 'N1', 'N2']
N = ['N1', 'N2']  # turni notturni

# Matrice costi (None = indisponibile "—")
cost = {
    'Ana':   {'M1':8, 'M2':7, 'P1':9, 'P2':8, 'N1':None, 'N2':None},
    'Bruno': {'M1':7, 'M2':8, 'P1':8, 'P2':9, 'N1':None, 'N2':None},
    'Carla': {'M1':None, 'M2':9, 'P1':8, 'P2':8, 'N1':11, 'N2':12},
    'Diego': {'M1':10, 'M2':None, 'P1':9, 'P2':8, 'N1':10, 'N2':11},
    'Elena': {'M1':8, 'M2':10, 'P1':9, 'P2':9, 'N1':12, 'N2':10},
    'Fabio': {'M1':9, 'M2':8, 'P1':10, 'P2':7, 'N1':None, 'N2':None},
}

# Insieme A delle coppie disponibili
A = [(e, s) for e in E for s in S if cost[e][s] is not None]

model = gp.Model("Assegnazione_Turni")
model.Params.OutputFlag = 0

# Variabili decisionali
x = model.addVars(A, vtype=GRB.BINARY, name="x")

# Funzione obiettivo
model.setObjective(gp.quicksum(cost[e][s] * x[e, s] for (e, s) in A), GRB.MINIMIZE)

# Vincolo: ogni turno coperto esattamente da 1 dipendente
for s in S:
    model.addConstr(
        gp.quicksum(x[e, s] for e in E if (e, s) in A) == 1,
        name=f"coverage_{s}"
    )

# Vincolo: ogni dipendente al massimo 2 turni
for e in E:
    model.addConstr(
        gp.quicksum(x[e, s] for s in S if (e, s) in A) <= 2,
        name=f"maxshifts_{e}"
    )

# Vincolo: ogni dipendente al massimo 1 turno notturno
for e in E:
    model.addConstr(
        gp.quicksum(x[e, s] for s in N if (e, s) in A) <= 1,
        name=f"maxnight_{e}"
    )

model.optimize()

result = {"status": "UNKNOWN", "objective": None, "variables": {}}

if model.Status == GRB.OPTIMAL:
    result["status"] = "OPTIMAL"
    result["objective"] = round(model.ObjVal, 2)
    variables = {}
    for e in E:
        for s in S:
            var_name = f"x_{e}_{s}"
            if (e, s) in A:
                variables[var_name] = round(x[e, s].X, 2)
            else:
                variables[var_name] = 0.0
    result["variables"] = variables

    # Stampa leggibile delle decisioni non nulle
    print("=== Assegnazioni ottime ===")
    for (e, s) in A:
        if x[e, s].X > 0.5:
            print(f"  {e:8s} -> {s}  (costo {cost[e][s]})")
    print(f"Costo totale ottimo: {model.ObjVal}")
else:
    result["status"] = str(model.Status)

print(f"SOLUTION_JSON={json.dumps(result)}")
```

## 4. Sintesi della soluzione

Il solver Gurobi trova la soluzione **ottima** con costo totale **49**.

L'assegnazione ottimale è:
- **Bruno** → M1 (costo 7) e P1 (costo 8)
- **Ana** → M2 (costo 7)
- **Fabio** → P2 (costo 7)
- **Diego** → N1 (costo 10)
- **Elena** → N2 (costo 10)
- **Carla** → nessun turno

Tutti i vincoli sono rispettati:
- ogni turno coperto da esattamente un dipendente;
- nessun dipendente supera i 2 turni (Bruno=2, tutti gli altri ≤1);
- nessun dipendente supera 1 turno notturno (Diego e Elena hanno 1 notturno ciascuno).

Il costo minimo complessivo è **49**.
