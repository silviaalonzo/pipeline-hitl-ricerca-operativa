# M03 — Assegnazione del personale ai turni

## 1. Insiemi, parametri e variabili decisionali

**Insiemi**
- $E = \{Ana, Bruno, Carla, Diego, Elena, Fabio\}$ — dipendenti
- $S = \{M1, M2, P1, P2, N1, N2\}$ — turni
- $N \subset S = \{N1, N2\}$ — turni notturni
- $A \subseteq E \times S$ — coppie (dipendente, turno) **disponibili** (esclude le celle "—")

**Parametri**
- $c_{e,s}$ = costo dell'assegnazione del dipendente $e$ al turno $s$, per $(e,s) \in A$

**Variabili decisionali**
- $x_{e,s} \in \{0,1\}$ per ogni $(e,s) \in A$: 1 se il dipendente $e$ è assegnato al turno $s$, 0 altrimenti

## 2. Formulazione matematica

$$
\min \sum_{(e,s)\in A} c_{e,s}\, x_{e,s}
$$

soggetto a:

**Copertura esatta di ogni turno**
$$
\sum_{e:(e,s)\in A} x_{e,s} = 1 \qquad \forall s \in S
$$

**Massimo due turni per dipendente**
$$
\sum_{s:(e,s)\in A} x_{e,s} \le 2 \qquad \forall e \in E
$$

**Massimo un turno notturno per dipendente**
$$
\sum_{s \in N:(e,s)\in A} x_{e,s} \le 1 \qquad \forall e \in E
$$

**Dominio**
$$
x_{e,s} \in \{0,1\} \qquad \forall (e,s) \in A
$$

## 3. Codice Python (gurobipy)

```python
import gurobipy as gp
from gurobipy import GRB
import json

# Insiemi
E = ["Ana", "Bruno", "Carla", "Diego", "Elena", "Fabio"]
S = ["M1", "M2", "P1", "P2", "N1", "N2"]
Night = {"N1", "N2"}

# Costi (None = indisponibile)
cost = {
    "Ana":   {"M1": 8, "M2": 7, "P1": 9, "P2": 8, "N1": None, "N2": None},
    "Bruno": {"M1": 7, "M2": 8, "P1": 8, "P2": 9, "N1": None, "N2": None},
    "Carla": {"M1": None, "M2": 9, "P1": 8, "P2": 8, "N1": 11, "N2": 12},
    "Diego": {"M1": 10, "M2": None, "P1": 9, "P2": 8, "N1": 10, "N2": 11},
    "Elena": {"M1": 8, "M2": 10, "P1": 9, "P2": 9, "N1": 12, "N2": 10},
    "Fabio": {"M1": 9, "M2": 8, "P1": 10, "P2": 7, "N1": None, "N2": None},
}

# Insieme A delle coppie disponibili
A = [(e, s) for e in E for s in S if cost[e][s] is not None]

# Modello
model = gp.Model("assegnazione_turni")
model.Params.OutputFlag = 0

# Variabili
x = model.addVars(A, vtype=GRB.BINARY, name="x")

# Funzione obiettivo
model.setObjective(gp.quicksum(cost[e][s] * x[e, s] for (e, s) in A), GRB.MINIMIZE)

# Vincolo: copertura esatta di ogni turno
for s in S:
    model.addConstr(
        gp.quicksum(x[e, s] for e in E if (e, s) in A) == 1,
        name=f"cover_{s}"
    )

# Vincolo: massimo due turni per dipendente
for e in E:
    model.addConstr(
        gp.quicksum(x[e, s] for s in S if (e, s) in A) <= 2,
        name=f"max2_{e}"
    )

# Vincolo: massimo un turno notturno per dipendente
for e in E:
    model.addConstr(
        gp.quicksum(x[e, s] for s in Night if (e, s) in A) <= 1,
        name=f"night_{e}"
    )

model.optimize()

status = model.Status
result = {"status": None, "objective": None, "variables": {}}

if status == GRB.OPTIMAL:
    result["status"] = "OPTIMAL"
    result["objective"] = round(model.ObjVal, 2)
    variables = {}
    for (e, s) in A:
        var_name = f"x_{e}_{s}"
        variables[var_name] = round(x[e, s].X, 2)
    result["variables"] = variables
else:
    result["status"] = str(status)

print("SOLUTION_JSON=" + json.dumps(result))
```

## 4. Sintesi della soluzione

Il solver Gurobi trova la soluzione ottima con **costo totale = 49**.

Assegnazioni non nulle ($x_{e,s}=1$):

| Dipendente | Turno | Costo |
|---|---|---|
| Bruno | M1 | 7 |
| Ana | M2 | 7 |
| Carla | P1 | 8 |
| Fabio | P2 | 7 |
| Diego | N1 | 10 |
| Elena | N2 | 10 |

Ogni turno è coperto esattamente da una persona, ogni dipendente lavora esattamente 1 turno (rispettando il vincolo di massimo 2), e Diego/Elena coprono un turno notturno ciascuno senza superare il limite di 1 notte a testa. Lo stato riportato dal solver è **OPTIMAL** con valore obiettivo **49**.
