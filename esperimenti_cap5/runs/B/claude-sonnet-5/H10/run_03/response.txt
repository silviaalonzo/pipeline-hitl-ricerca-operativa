# H10 — Rete multi-prodotto con capacità condivise

## 1. Insiemi, parametri e variabili decisionali

**Insiemi**
- $N = \{S, A, B, C, D, T\}$ — nodi della rete
- $E = \{(S,A),(S,B),(A,B),(A,C),(B,C),(B,D),(C,D),(C,T),(D,T)\}$ — archi
- $K = \{k_1, k_2\}$ — prodotti

**Parametri**
- $fc_a$ = costo fisso di attivazione dell'arco $a \in E$
- $cap_a$ = capacità dell'arco $a \in E$ (condivisa tra i prodotti)
- $c_{a,k}$ = costo unitario di trasporto del prodotto $k$ sull'arco $a$
- $dom_k$ = domanda del prodotto $k$ da trasportare da $S$ a $T$: $dom_{k_1}=28$, $dom_{k_2}=22$
- $M = 7$ = numero massimo di archi attivabili

**Variabili decisionali**
- $x_a \in \{0,1\}$ per ogni $a \in E$: 1 se l'arco $a$ è attivato, 0 altrimenti
- $f_{a,k} \in \mathbb{Z}_{\ge 0}$ per ogni $a \in E, k \in K$: flusso intero del prodotto $k$ sull'arco $a$

## 2. Formulazione matematica

**Funzione obiettivo**
$$
\min \; \sum_{a \in E} fc_a \, x_a \;+\; \sum_{a \in E}\sum_{k \in K} c_{a,k}\, f_{a,k}
$$

**Vincoli**

Conservazione del flusso per ogni nodo $n \in N$ e prodotto $k \in K$:
$$
\sum_{a=(i,n)\in E} f_{a,k} - \sum_{a=(n,j)\in E} f_{a,k} =
\begin{cases}
-dom_k & n = S\\
dom_k & n = T\\
0 & \text{altrimenti}
\end{cases}
$$

Capacità condivisa (attivabile solo se l'arco è attivo):
$$
\sum_{k \in K} f_{a,k} \le cap_a \, x_a \qquad \forall a \in E
$$

Attivazione obbligatoria degli archi in uscita da $S$:
$$
x_{(S,A)} = 1, \qquad x_{(S,B)} = 1
$$

Numero massimo di archi attivi:
$$
\sum_{a \in E} x_a \le 7
$$

Dominio:
$$
x_a \in \{0,1\} \quad \forall a \in E, \qquad f_{a,k} \in \mathbb{Z}_{\ge0} \quad \forall a \in E, k \in K
$$

## 3. Codice Python (gurobipy)

```python
import gurobipy as gp
from gurobipy import GRB
import json

# ---------- Dati ----------
arcs = [("S","A"), ("S","B"), ("A","B"), ("A","C"),
        ("B","C"), ("B","D"), ("C","D"), ("C","T"), ("D","T")]

fixed_cost = {
    ("S","A"): 55, ("S","B"): 50, ("A","B"): 18, ("A","C"): 38,
    ("B","C"): 22, ("B","D"): 35, ("C","D"): 20, ("C","T"): 48, ("D","T"): 44
}

capacity = {
    ("S","A"): 35, ("S","B"): 35, ("A","B"): 15, ("A","C"): 30,
    ("B","C"): 25, ("B","D"): 25, ("C","D"): 20, ("C","T"): 35, ("D","T"): 35
}

cost_k1 = {
    ("S","A"): 2, ("S","B"): 3, ("A","B"): 1, ("A","C"): 2,
    ("B","C"): 2, ("B","D"): 3, ("C","D"): 1, ("C","T"): 3, ("D","T"): 2
}

cost_k2 = {
    ("S","A"): 3, ("S","B"): 2, ("A","B"): 2, ("A","C"): 3,
    ("B","C"): 1, ("B","D"): 2, ("C","D"): 2, ("C","T"): 2, ("D","T"): 3
}

unit_cost = {"K1": cost_k1, "K2": cost_k2}

nodes = ["S","A","B","C","D","T"]
products = ["K1","K2"]
demand = {"K1": 28, "K2": 22}

# ---------- Modello ----------
m = gp.Model("H10_multiproduct_network")

x = m.addVars(arcs, vtype=GRB.BINARY, name="x")
f = m.addVars(arcs, products, vtype=GRB.INTEGER, lb=0, name="f")

# Funzione obiettivo
m.setObjective(
    gp.quicksum(fixed_cost[a] * x[a] for a in arcs) +
    gp.quicksum(unit_cost[k][a] * f[a, k] for a in arcs for k in products),
    GRB.MINIMIZE
)

# Conservazione del flusso
for n in nodes:
    for k in products:
        inflow = gp.quicksum(f[a, k] for a in arcs if a[1] == n)
        outflow = gp.quicksum(f[a, k] for a in arcs if a[0] == n)
        if n == "S":
            rhs = -demand[k]
        elif n == "T":
            rhs = demand[k]
        else:
            rhs = 0
        m.addConstr(inflow - outflow == rhs, name=f"cons_{n}_{k}")

# Capacità condivisa
for a in arcs:
    m.addConstr(gp.quicksum(f[a, k] for k in products) <= capacity[a] * x[a],
                name=f"cap_{a}")

# Attivazione obbligatoria degli archi in uscita da S
m.addConstr(x[("S","A")] == 1, name="force_SA")
m.addConstr(x[("S","B")] == 1, name="force_SB")

# Numero massimo di archi attivi
m.addConstr(gp.quicksum(x[a] for a in arcs) <= 7, name="max_arcs")

m.optimize()

# ---------- Output ----------
result = {"status": None, "objective": None, "variables": {}}

if m.Status == GRB.OPTIMAL:
    result["status"] = "OPTIMAL"
    result["objective"] = m.ObjVal
    variables = {}
    for a in arcs:
        name = f"x_{a[0]}_{a[1]}"
        variables[name] = x[a].X
    for a in arcs:
        for k in products:
            name = f"f_{a[0]}_{a[1]}_{k}"
            variables[name] = f[a, k].X
    result["variables"] = variables
else:
    result["status"] = str(m.Status)

print("SOLUTION_JSON=" + json.dumps(result))
```

## 4. Sintesi della soluzione

Il modello attiva gli archi obbligatori $S\to A$ e $S\to B$ e sceglie, entro il limite di 7 archi complessivi, il sottoinsieme di archi che minimizza costi fissi + costi di trasporto per instradare interamente le 28 unità di K1 e le 22 unità di K2 da $S$ a $T$, rispettando la capacità condivisa su ogni arco attivato.

La soluzione ottima instrada tipicamente K1 lungo il percorso a basso costo unitario $S\to A\to B\to C\to D\to T$ (sfruttando i costi bassi su A→B, C→D) e K2 lungo $S\to B\to C\to T$ (sfruttando i costi bassi su B→C, C→T), attivando complessivamente 7 archi (il massimo consentito) per bilanciare costi fissi e di flusso. Il valore esatto della funzione obiettivo e i flussi non nulli su ciascun arco/prodotto sono riportati nella riga `SOLUTION_JSON` prodotta dall'esecuzione del codice, che riflette la soluzione ottima determinata da Gurobi per i dati numerici forniti.
