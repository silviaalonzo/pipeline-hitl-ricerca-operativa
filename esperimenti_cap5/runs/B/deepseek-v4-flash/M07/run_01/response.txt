## 1. Insiemi, parametri e variabili decisionali

- Insieme dei fornitori: \(I=\{\text{A},\text{B},\text{C},\text{D}\}\).
- Parametri:
  - \(c_i\): costo variabile per unità;
  - \(f_i\): costo fisso di attivazione;
  - \(u_i\): capacità massima;
  - \(m_i\): ordine minimo;
  - \(q_i\): qualità;
  - \(e_i\): emissioni per unità.

Valori:  
\[
c=(11,10,12,9),\quad f=(80,95,60,120),
\]
\[
u=(80,100,70,90),\quad m=(20,25,15,20),
\]
\[
q=(96,90,98,88),\quad e=(3,4,2,5).
\]

Variabili decisionali:
- \(x_i \in \mathbb{Z}_+\): quantità acquistata dal fornitore \(i\);
- \(y_i \in \{0,1\}\): vale 1 se il fornitore \(i\) viene attivato, 0 altrimenti.

## 2. Formulazione matematica

\[
\min \sum_{i\in I} \left(c_i x_i + f_i y_i\right)
\]

soggetto a:

\[
\sum_{i\in I} x_i = 180
\]

\[
\sum_{i\in I} y_i \ge 2
\]

\[
m_i y_i \le x_i \le u_i y_i \quad \forall i \in I
\]

\[
\sum_{i\in I} q_i x_i \ge 92 \cdot 180
\]

\[
\sum_{i\in I} e_i x_i \le 650
\]

\[
x_i \in \mathbb{Z}_+,\quad y_i \in \{0,1\}
\]

## 3. Codice Python con Gurobi

```python
import gurobipy as gp
import json

fornitori = ["A", "B", "C", "D"]

costo = {"A": 11, "B": 10, "C": 12, "D": 9}
fisso = {"A": 80, "B": 95, "C": 60, "D": 120}
capacita = {"A": 80, "B": 100, "C": 70, "D": 90}
ordine_min = {"A": 20, "B": 25, "C": 15, "D": 20}
qualita = {"A": 96, "B": 90, "C": 98, "D": 88}
emissioni = {"A": 3, "B": 4, "C": 2, "D": 5}

m = gp.Model("M07")
m.Params.OutputFlag = 0

x = {i: m.addVar(vtype=gp.GRB.INTEGER, name=f"x_{i}") for i in fornitori}
y = {i: m.addVar(vtype=gp.GRB.BINARY, name=f"y_{i}") for i in fornitori}

m.setObjective(
    gp.quicksum(costo[i] * x[i] + fisso[i] * y[i] for i in fornitori),
    gp.GRB.MINIMIZE,
)

m.addConstr(gp.quicksum(x[i] for i in fornitori) == 180, "totale")
m.addConstr(gp.quicksum(y[i] for i in fornitori) >= 2, "almeno_due")

for i in fornitori:
    m.addConstr(x[i] >= ordine_min[i] * y[i], name=f"minimo_{i}")
    m.addConstr(x[i] <= capacita[i] * y[i], name=f"capacita_{i}")

m.addConstr(gp.quicksum(qualita[i] * x[i] for i in fornitori) >= 92 * 180, "qualita")
m.addConstr(gp.quicksum(emissioni[i] * x[i] for i in fornitori) <= 650, "emissioni")

m.optimize()

if m.Status == gp.GRB.OPTIMAL:
    variabili = {}
    for i in fornitori:
        variabili[f"x_{i}"] = x[i].X
    for i in fornitori:
        variabili[f"y_{i}"] = y[i].X

    risultato = {
        "status": "OPTIMAL",
        "objective": m.ObjVal,
        "variables": variabili,
    }
else:
    status_map = {
        gp.GRB.INFEASIBLE: "INFEASIBLE",
        gp.GRB.UNBOUNDED: "UNBOUNDED",
        gp.GRB.INF_OR_UNBD: "INF_OR_UNBD",
        gp.GRB.NUMERIC: "NUMERIC",
        gp.GRB.SUBOPTIMAL: "SUBOPTIMAL",
        gp.GRB.TIME_LIMIT: "TIME_LIMIT",
        gp.GRB.NODE_LIMIT: "NODE_LIMIT",
        gp.GRB.INTERRUPTED: "INTERRUPTED",
    }
    stato = status_map.get(m.Status, "UNKNOWN")
    risultato = {"status": stato, "objective": None, "variables": {}}

print("SOLUTION_JSON=" + json.dumps(risultato, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Il solver Gurobi termina con stato **OPTIMAL** e valore ottimo **2055.0**.  
La soluzione ottima acquista:

- 80 unità dal fornitore A;
- 100 unità dal fornitore B;
- 0 unità dai fornitori C e D.

Vengono quindi attivati solo i fornitori A e B.  
La qualità media è \(16680/180 = 92.67 \ge 92\), mentre le emissioni totali sono \(640 \le 650\).
