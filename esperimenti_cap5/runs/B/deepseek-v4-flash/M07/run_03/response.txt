### 1. Insiemi, parametri e variabili decisionali

- \(F=\{\text{A},\text{B},\text{C},\text{D}\}\) insieme dei fornitori.
- \(c_i\): costo variabile per unità del fornitore \(i\).
- \(f_i\): costo fisso di attivazione del fornitore \(i\).
- \(K_i\): capacità massima del fornitore \(i\).
- \(m_i\): ordine minimo del fornitore \(i\), se attivato.
- \(q_i\): qualità del fornitore \(i\).
- \(e_i\): emissioni per unità del fornitore \(i\).
- \(x_i \in \mathbb{Z}_{\ge 0}\): unità acquistate dal fornitore \(i\).
- \(y_i \in \{0,1\}\): vale 1 se il fornitore \(i\) è attivato, 0 altrimenti.

### 2. Formulazione matematica

\[
\min \sum_{i\in F} (c_i x_i + f_i y_i)
\]

vincoli:

\[
\sum_{i\in F} x_i = 180
\]

\[
\sum_{i\in F} y_i \ge 2
\]

\[
m_i y_i \le x_i \le K_i y_i \quad \forall i \in F
\]

\[
\sum_{i\in F} q_i x_i \ge 92 \cdot 180
\]

\[
\sum_{i\in F} e_i x_i \le 650
\]

\[
x_i \in \mathbb{Z}_{\ge 0}, \quad y_i \in \{0,1\}
\]

### 3. Codice Python con Gurobi

```python
import json
import gurobipy as gp
from gurobipy import GRB

fornitori = ["A", "B", "C", "D"]

costo = {"A": 11, "B": 10, "C": 12, "D": 9}
fisso = {"A": 80, "B": 95, "C": 60, "D": 120}
capacita = {"A": 80, "B": 100, "C": 70, "D": 90}
ordine_min = {"A": 20, "B": 25, "C": 15, "D": 20}
qualita = {"A": 96, "B": 90, "C": 98, "D": 88}
emissioni = {"A": 3, "B": 4, "C": 2, "D": 5}

model = gp.Model("M07_selezione_fornitori")
model.Params.OutputFlag = 0

x = model.addVars(fornitori, vtype=GRB.INTEGER, lb=0, name="x")
y = model.addVars(fornitori, vtype=GRB.BINARY, name="y")

# Vincolo sulla quantità totale
model.addConstr(gp.quicksum(x[i] for i in fornitori) == 180, "totale")

# Almeno due fornitori attivi
model.addConstr(gp.quicksum(y[i] for i in fornitori) >= 2, "almeno_due")

# Ordine minimo e capacità se il fornitore è attivo
for i in fornitori:
    model.addConstr(x[i] >= ordine_min[i] * y[i], f"ordine_min_{i}")
    model.addConstr(x[i] <= capacita[i] * y[i], f"capacita_{i}")

# Qualità media ponderata almeno 92
model.addConstr(gp.quicksum(qualita[i] * x[i] for i in fornitori) >= 92 * 180, "qualita")

# Emissioni totali massime
model.addConstr(gp.quicksum(emissioni[i] * x[i] for i in fornitori) <= 650, "emissioni")

# Funzione obiettivo
model.setObjective(
    gp.quicksum(fisso[i] * y[i] for i in fornitori) +
    gp.quicksum(costo[i] * x[i] for i in fornitori),
    GRB.MINIMIZE
)

model.optimize()

if model.Status == GRB.OPTIMAL:
    variabili = {f"x_{i}": x[i].X for i in fornitori}
    variabili.update({f"y_{i}": y[i].X for i in fornitori})
    result = {
        "status": "OPTIMAL",
        "objective": model.ObjVal,
        "variables": variabili
    }
else:
    result = {
        "status": "INFEASIBLE" if model.Status == GRB.INFEASIBLE else str(model.Status),
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

### 4. Sintesi della soluzione

Gurobi restituisce stato **OPTIMAL** con costo totale **2055.0**.

Decisioni ottime:

- \(x_A = 80\), \(x_B = 100\), \(x_C = 0\), \(x_D = 0\)
- \(y_A = 1\), \(y_B = 1\), \(y_C = 0\), \(y_D = 0\)

La soluzione attiva quindi solo i fornitori **A** e **B**.  
Costi fissi: \(80 + 95 = 175\).  
Costi variabili: \(80 \cdot 11 + 100 \cdot 10 = 1880\).  
Qualità media: \((96 \cdot 80 + 90 \cdot 100)/180 \approx 92.67 \ge 92\).  
Emissioni totali: \(3 \cdot 80 + 4 \cdot 100 = 640 \le 650\).
