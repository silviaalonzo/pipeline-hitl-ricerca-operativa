## 1. Insiemi, parametri e variabili decisionali

Insieme dei fornitori:

\[
I=\{A,B,C,D\}
\]

Parametri:

- \(c_i\): costo variabile per unità acquistata dal fornitore \(i\);
- \(f_i\): costo fisso di attivazione del fornitore \(i\);
- \(U_i\): capacità massima del fornitore \(i\);
- \(L_i\): ordine minimo del fornitore \(i\);
- \(q_i\): qualità del fornitore \(i\);
- \(e_i\): emissioni per unità del fornitore \(i\).

Variabili decisionali:

- \(x_i \in \mathbb{Z}_+\): quantità acquistata dal fornitore \(i\);
- \(y_i \in \{0,1\}\): indica se il fornitore \(i\) viene attivato.

## 2. Formulazione matematica

\[
\min \sum_{i\in I} \left(c_i x_i + f_i y_i\right)
\]

soggetto a:

\[
\sum_{i\in I} x_i = 180
\]

\[
L_i y_i \le x_i \le U_i y_i \qquad \forall i\in I
\]

\[
\sum_{i\in I} y_i \ge 2
\]

\[
\sum_{i\in I} q_i x_i \ge 92 \cdot 180
\]

\[
\sum_{i\in I} e_i x_i \le 650
\]

\[
x_i \in \mathbb{Z}_+, \quad y_i \in \{0,1\}
\]

## 3. Codice Python con Gurobi

```python
from gurobipy import Model, GRB, quicksum
import json

fornitori = ["A", "B", "C", "D"]

costo = {"A": 11, "B": 10, "C": 12, "D": 9}
fisso = {"A": 80, "B": 95, "C": 60, "D": 120}
capacita = {"A": 80, "B": 100, "C": 70, "D": 90}
minimo = {"A": 20, "B": 25, "C": 15, "D": 20}
qualita = {"A": 96, "B": 90, "C": 98, "D": 88}
emissioni = {"A": 3, "B": 4, "C": 2, "D": 5}

domanda = 180
qualita_minima = 92
emissioni_max = 650
fornitori_minimi = 2

m = Model("M07")
m.Params.OutputFlag = 0

x = {}
y = {}

for i in fornitori:
    x[i] = m.addVar(vtype=GRB.INTEGER, lb=0, ub=capacita[i], name=f"x_{i}")
    y[i] = m.addVar(vtype=GRB.BINARY, name=f"y_{i}")

m.addConstr(quicksum(x[i] for i in fornitori) == domanda, "domanda")
m.addConstr(quicksum(y[i] for i in fornitori) >= fornitori_minimi, "fornitori_minimi")
m.addConstr(quicksum(qualita[i] * x[i] for i in fornitori) >= qualita_minima * domanda, "qualita")
m.addConstr(quicksum(emissioni[i] * x[i] for i in fornitori) <= emissioni_max, "emissioni")

for i in fornitori:
    m.addConstr(x[i] >= minimo[i] * y[i], f"min_{i}")
    m.addConstr(x[i] <= capacita[i] * y[i], f"max_{i}")

m.setObjective(
    quicksum(costo[i] * x[i] + fisso[i] * y[i] for i in fornitori),
    GRB.MINIMIZE
)

m.optimize()

if m.Status == GRB.OPTIMAL:
    variabili = {}
    for i in fornitori:
        variabili[f"x_{i}"] = x[i].X
    for i in fornitori:
        variabili[f"y_{i}"] = y[i].X

    payload = {
        "status": "OPTIMAL",
        "objective": m.ObjVal,
        "variables": variabili
    }
else:
    payload = {
        "status": f"STATUS_{m.Status}",
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(payload, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Il solver restituisce stato **OPTIMAL** con valore ottimo **2055**.

Decisioni non nulle:

- \(x_A = 80\), \(y_A = 1\);
- \(x_B = 100\), \(y_B = 1\);
- \(x_C = 0\), \(y_C = 0\);
- \(x_D = 0\), \(y_D = 0\).

Vengono quindi attivati solo i fornitori A e B, acquistando 80 unità da A e 100 unità da B.  
La qualità media è:

\[
\frac{96\cdot80 + 90\cdot100}{180} = \frac{16680}{180} = 92{,}67
\]

Le emissioni totali sono:

\[
3\cdot80 + 4\cdot100 = 640 \le 650
\]
