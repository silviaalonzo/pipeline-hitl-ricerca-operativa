## 1. Insiemi, parametri e variabili decisionali

**Insiemi:**
- \(E = \{SA, SB, AB, AC, BC, BT, CT\}\): archi della rete.
- \(N = \{S, A, B, C, T\}\): nodi della rete.
- \(\delta^+(n)\): archi uscenti dal nodo \(n\).
- \(\delta^-(n)\): archi entranti nel nodo \(n\).

**Parametri:**
- \(F_a\): costo fisso di attivazione dell’arco \(a\).
- \(C_a\): costo per unità di flusso sull’arco \(a\).
- \(U_a\): capacità dell’arco \(a\).
- \(D = 40\): quantità da inviare da \(S\) a \(T\).

**Variabili decisionali:**
- \(x_a \in \mathbb{Z}_+\): flusso sull’arco \(a\).
- \(y_a \in \{0,1\}\): indica se l’arco \(a\) viene attivato.

## 2. Formulazione matematica

\[
\min \sum_{a \in E} \left( F_a y_a + C_a x_a \right)
\]

soggetto a:

\[
x_a \le U_a y_a \qquad \forall a \in E
\]

\[
\sum_{a \in \delta^+(n)} x_a - \sum_{a \in \delta^-(n)} x_a =
\begin{cases}
40 & \text{se } n = S \\
0 & \text{se } n \in \{A,B,C\} \\
-40 & \text{se } n = T
\end{cases}
\]

\[
x_a \in \mathbb{Z}_+, \quad y_a \in \{0,1\}
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

arcs = {
    "SA": {"tail": "S", "head": "A", "fisso": 40, "unitario": 2, "capacita": 30},
    "SB": {"tail": "S", "head": "B", "fisso": 35, "unitario": 3, "capacita": 35},
    "AB": {"tail": "A", "head": "B", "fisso": 15, "unitario": 1, "capacita": 15},
    "AC": {"tail": "A", "head": "C", "fisso": 30, "unitario": 2, "capacita": 25},
    "BC": {"tail": "B", "head": "C", "fisso": 18, "unitario": 2, "capacita": 20},
    "BT": {"tail": "B", "head": "T", "fisso": 45, "unitario": 4, "capacita": 25},
    "CT": {"tail": "C", "head": "T", "fisso": 38, "unitario": 2, "capacita": 35},
}

nodi = ["S", "A", "B", "C", "T"]
bilancio = {"S": 40, "A": 0, "B": 0, "C": 0, "T": -40}

model = gp.Model("rete_distributiva")
model.Params.OutputFlag = 0

x = {}
y = {}

for a in arcs:
    x[a] = model.addVar(lb=0, vtype=GRB.INTEGER, name=f"x_{a}")
    y[a] = model.addVar(lb=0, vtype=GRB.BINARY, name=f"y_{a}")

model.setObjective(
    gp.quicksum(arcs[a]["fisso"] * y[a] + arcs[a]["unitario"] * x[a] for a in arcs),
    GRB.MINIMIZE
)

# Capacità e attivazione
for a in arcs:
    model.addConstr(x[a] <= arcs[a]["capacita"] * y[a], name=f"cap_{a}")

# Conservazione del flusso
out_arcs = {n: [] for n in nodi}
in_arcs = {n: [] for n in nodi}

for a, d in arcs.items():
    out_arcs[d["tail"]].append(a)
    in_arcs[d["head"]].append(a)

for n in nodi:
    model.addConstr(
        gp.quicksum(x[a] for a in out_arcs[n]) - gp.quicksum(x[a] for a in in_arcs[n]) == bilancio[n],
        name=f"flow_{n}"
    )

model.optimize()

status_map = {
    GRB.OPTIMAL: "OPTIMAL",
    GRB.INFEASIBLE: "INFEASIBLE",
    GRB.UNBOUNDED: "UNBOUNDED",
    GRB.INF_OR_UNBD: "INF_OR_UNBD",
    GRB.TIME_LIMIT: "TIME_LIMIT",
}

status = status_map.get(model.status, str(model.status))

if model.status == GRB.OPTIMAL:
    obj = model.ObjVal
    vars_dict = {v.VarName: v.X for v in model.getVars()}
else:
    obj = None
    vars_dict = {}

print("SOLUTION_JSON=" + json.dumps(
    {"status": status, "objective": obj, "variables": vars_dict},
    separators=(",", ":")
))
```

## 4. Sintesi della soluzione

Il solver termina con stato **OPTIMAL** e costo ottimo **443**.

Flussi ottimi non nulli:
- \(x_{SA} = 25\)
- \(x_{SB} = 15\)
- \(x_{AC} = 25\)
- \(x_{BT} = 15\)
- \(x_{CT} = 25\)

Archi attivati:
- \(y_{SA} = y_{SB} = y_{AC} = y_{BT} = y_{CT} = 1\)

Gli archi \(AB\) e \(BC\) non vengono attivati e hanno flusso nullo.
