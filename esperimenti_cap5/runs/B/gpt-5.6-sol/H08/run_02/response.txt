## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Zone:
  \[
  I=\{\mathrm{Z1},\ldots,\mathrm{Z12}\}.
  \]
- Stazioni:
  \[
  J=\{\mathrm A,\mathrm B,\mathrm C,\mathrm D,\mathrm E,\mathrm F,\mathrm G,\mathrm H\}.
  \]
- Stazioni dell’area Ovest:
  \[
  J^W=\{\mathrm A,\mathrm B,\mathrm C,\mathrm D\}.
  \]
- Stazioni dell’area Est:
  \[
  J^E=\{\mathrm E,\mathrm F,\mathrm G,\mathrm H\}.
  \]
- Zone critiche:
  \[
  I^C=\{\mathrm{Z3},\mathrm{Z8},\mathrm{Z11}\}.
  \]
- \(R_i\subseteq J\): stazioni raggiungibili dalla zona \(i\).
- Archi di assegnazione ammissibili:
  \[
  \mathcal A=\{(i,j):i\in I,\ j\in R_i\}.
  \]

### Parametri

- Costi fissi \(f_j\):
  \[
  (35,32,40,30,38,33,36,31)
  \]
  rispettivamente per \(A,\ldots,H\).
- Capacità \(C_j\):
  \[
  (42,44,46,40,45,43,44,42)
  \]
  rispettivamente per \(A,\ldots,H\).
- Domande \(d_i\):
  \[
  (8,7,10,6,9,8,7,11,6,9,8,7)
  \]
  rispettivamente per \(\mathrm{Z1},\ldots,\mathrm{Z12}\).
- \(t_{ij}\): tempo di percorrenza tra la zona \(i\) e la stazione raggiungibile \(j\), come riportato nella traccia.

### Variabili decisionali

- Apertura delle stazioni:
  \[
  y_j=
  \begin{cases}
  1 & \text{se la stazione }j\text{ è aperta},\\
  0 & \text{altrimenti}.
  \end{cases}
  \]
- Assegnazione delle zone:
  \[
  x_{ij}=
  \begin{cases}
  1 & \text{se la zona }i\text{ è assegnata alla stazione }j,\\
  0 & \text{altrimenti},
  \end{cases}
  \qquad (i,j)\in\mathcal A.
  \]

## 2. Formulazione matematica completa

### Funzione obiettivo

Si minimizza la somma dei costi fissi e dei costi di percorrenza pesati per la domanda:

\[
\min \quad
\sum_{j\in J} f_j y_j+
\sum_{(i,j)\in\mathcal A} d_i t_{ij}x_{ij}.
\]

### Vincoli

Apertura di esattamente quattro stazioni:

\[
\sum_{j\in J}y_j=4.
\]

Assegnazione di ogni zona a una sola stazione raggiungibile:

\[
\sum_{j\in R_i}x_{ij}=1
\qquad \forall i\in I.
\]

Una zona può essere assegnata soltanto a una stazione aperta:

\[
x_{ij}\le y_j
\qquad \forall(i,j)\in\mathcal A.
\]

Rispetto della capacità di ogni stazione:

\[
\sum_{\substack{i\in I:\\j\in R_i}}d_i x_{ij}
\le C_jy_j
\qquad \forall j\in J.
\]

Apertura di almeno una stazione nell’area Ovest:

\[
\sum_{j\in J^W}y_j\ge 1.
\]

Apertura di almeno una stazione nell’area Est:

\[
\sum_{j\in J^E}y_j\ge 1.
\]

Backup per ciascuna zona critica:

\[
\sum_{j\in R_i}y_j\ge 2
\qquad \forall i\in I^C.
\]

Dominio:

\[
y_j\in\{0,1\}\qquad \forall j\in J,
\]

\[
x_{ij}\in\{0,1\}\qquad \forall(i,j)\in\mathcal A.
\]

## 3. Codice Python con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

stations = ["A", "B", "C", "D", "E", "F", "G", "H"]
zones = ["Z1", "Z2", "Z3", "Z4", "Z5", "Z6",
         "Z7", "Z8", "Z9", "Z10", "Z11", "Z12"]

fixed_cost = {
    "A": 35, "B": 32, "C": 40, "D": 30,
    "E": 38, "F": 33, "G": 36, "H": 31
}

capacity = {
    "A": 42, "B": 44, "C": 46, "D": 40,
    "E": 45, "F": 43, "G": 44, "H": 42
}

demand = {
    "Z1": 8, "Z2": 7, "Z3": 10, "Z4": 6,
    "Z5": 9, "Z6": 8, "Z7": 7, "Z8": 11,
    "Z9": 6, "Z10": 9, "Z11": 8, "Z12": 7
}

times = {
    "Z1": {"A": 3, "B": 5},
    "Z2": {"A": 6, "B": 8, "C": 10},
    "Z3": {"B": 11, "C": 4, "D": 6},
    "Z4": {"C": 7, "D": 9},
    "Z5": {"A": 6, "D": 3, "E": 5},
    "Z6": {"B": 11, "E": 8, "F": 10},
    "Z7": {"C": 7, "F": 4, "G": 6, "H": 8},
    "Z8": {"D": 3, "G": 9, "H": 11},
    "Z9": {"E": 8, "F": 10, "H": 5},
    "Z10": {"F": 4, "G": 6, "H": 8},
    "Z11": {"A": 6, "E": 5, "H": 11},
    "Z12": {"B": 11, "G": 3, "H": 5}
}

west = ["A", "B", "C", "D"]
east = ["E", "F", "G", "H"]
critical_zones = ["Z3", "Z8", "Z11"]

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("H08", env=env)
model.Params.MIPGap = 0.0

y = {
    j: model.addVar(vtype=GRB.BINARY, name="y_" + j)
    for j in stations
}

x = {
    (i, j): model.addVar(vtype=GRB.BINARY, name="x_" + i + "_" + j)
    for i in zones
    for j in times[i]
}

model.setObjective(
    gp.quicksum(fixed_cost[j] * y[j] for j in stations)
    + gp.quicksum(
        demand[i] * times[i][j] * x[i, j]
        for i in zones
        for j in times[i]
    ),
    GRB.MINIMIZE
)

model.addConstr(
    gp.quicksum(y[j] for j in stations) == 4,
    name="exactly_four_stations"
)

for i in zones:
    model.addConstr(
        gp.quicksum(x[i, j] for j in times[i]) == 1,
        name="assignment_" + i
    )

for i in zones:
    for j in times[i]:
        model.addConstr(
            x[i, j] <= y[j],
            name="link_" + i + "_" + j
        )

for j in stations:
    model.addConstr(
        gp.quicksum(
            demand[i] * x[i, j]
            for i in zones
            if (i, j) in x
        ) <= capacity[j] * y[j],
        name="capacity_" + j
    )

model.addConstr(
    gp.quicksum(y[j] for j in west) >= 1,
    name="west_station"
)

model.addConstr(
    gp.quicksum(y[j] for j in east) >= 1,
    name="east_station"
)

for i in critical_zones:
    model.addConstr(
        gp.quicksum(y[j] for j in times[i]) >= 2,
        name="backup_" + i
    )

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, "UNKNOWN")

if model.Status == GRB.OPTIMAL:
    variables = {}
    for j in stations:
        variables[y[j].VarName] = float(round(y[j].X))
    for i in zones:
        for j in times[i]:
            variables[x[i, j].VarName] = float(round(x[i, j].X))
    result = {
        "status": "OPTIMAL",
        "objective": float(round(model.ObjVal, 10)),
        "variables": variables
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {}
    }

model.dispose()
env.dispose()

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Lo stato è **OPTIMAL** e il valore ottimo è:

\[
z^*=697.
\]

Le stazioni aperte sono:

\[
y_A=y_B=y_D=y_H=1.
\]

Le assegnazioni non nulle sono:

\[
\begin{aligned}
&x_{\mathrm{Z1},A}=1,\quad x_{\mathrm{Z2},A}=1,\quad
x_{\mathrm{Z3},D}=1,\quad x_{\mathrm{Z4},D}=1,\\
&x_{\mathrm{Z5},D}=1,\quad x_{\mathrm{Z6},B}=1,\quad
x_{\mathrm{Z7},H}=1,\quad x_{\mathrm{Z8},D}=1,\\
&x_{\mathrm{Z9},H}=1,\quad x_{\mathrm{Z10},H}=1,\quad
x_{\mathrm{Z11},A}=1,\quad x_{\mathrm{Z12},H}=1.
\end{aligned}
\]

I carichi risultano \(23\) per A, \(8\) per B, \(36\) per D e \(29\) per H. Il costo fisso è \(128\), mentre il costo di percorrenza è \(569\). Le zone critiche hanno rispettivamente i backup aperti \(\{B,D\}\), \(\{D,H\}\) e \(\{A,H\}\).
