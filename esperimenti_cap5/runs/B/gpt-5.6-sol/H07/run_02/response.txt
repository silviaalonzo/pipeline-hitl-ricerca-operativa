## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Fornitori:
  \[
  I=\{A,B,C,D,E,F\}.
  \]
- Componenti:
  \[
  J=\{C1,C2,C3\}.
  \]
- Combinazioni fornitore–componente ammissibili:
  \[
  \begin{aligned}
  \Omega=\{&
  (A,C1),(A,C2),(A,C3),\\
  &(B,C1),(B,C2),(B,C3),\\
  &(C,C1),(C,C2),(C,C3),\\
  &(D,C2),(D,C3),\\
  &(E,C1),(E,C2),\\
  &(F,C1),(F,C3)\}.
  \end{aligned}
  \]

### Parametri

Domanda:

\[
d_{C1}=80,\qquad d_{C2}=70,\qquad d_{C3}=60.
\]

| \(i\) | Costo fisso \(f_i\) | Capacità \(K_i\) | Rischio \(r_i\) |
|---|---:|---:|---:|
| A | 120 | 100 | 2 |
| B | 140 | 110 | 3 |
| C | 100 | 90 | 1 |
| D | 150 | 120 | 4 |
| E | 90 | 80 | 2 |
| F | 110 | 95 | 3 |

Per ogni \((i,j)\in\Omega\), \(c_{ij}\) è il costo unitario e \(q_{ij}\) la qualità:

| \(i,j\) | \(c_{ij}\) | \(q_{ij}\) |
|---|---:|---:|
| A,C1 | 9 | 96 |
| A,C2 | 12 | 94 |
| A,C3 | 11 | 95 |
| B,C1 | 10 | 93 |
| B,C2 | 9 | 97 |
| B,C3 | 12 | 92 |
| C,C1 | 11 | 98 |
| C,C2 | 10 | 95 |
| C,C3 | 9 | 96 |
| D,C2 | 11 | 94 |
| D,C3 | 10 | 93 |
| E,C1 | 12 | 97 |
| E,C2 | 8 | 98 |
| F,C1 | 10 | 94 |
| F,C3 | 8 | 98 |

Ulteriori parametri:

\[
L=10,\qquad \bar q=95,\qquad R=580,\qquad P=4,
\]

dove \(L\) è il lotto minimo, \(\bar q\) la qualità media minima, \(R\) il rischio massimo e \(P\) il numero massimo di fornitori attivabili.

### Variabili decisionali

Per ogni \((i,j)\in\Omega\):

- \(x_{ij}\in\mathbb Z_+\): quantità intera del componente \(j\) acquistata dal fornitore \(i\);
- \(z_{ij}\in\{0,1\}\): vale 1 se la combinazione fornitore–componente è utilizzata.

Per ogni \(i\in I\):

- \(y_i\in\{0,1\}\): vale 1 se il fornitore \(i\) è attivato.

Nel codice e nell’output JSON tali variabili sono denominate rispettivamente `x_i_j`, `z_i_j` e `y_i`.

## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzare costi d’acquisto e costi fissi di attivazione:

\[
\min
\left[
\sum_{(i,j)\in\Omega} c_{ij}x_{ij}
+
\sum_{i\in I} f_i y_i
\right].
\]

### Soddisfacimento esatto della domanda

\[
\sum_{i:(i,j)\in\Omega}x_{ij}=d_j
\qquad \forall j\in J.
\]

### Capacità complessiva dei fornitori

\[
\sum_{j:(i,j)\in\Omega}x_{ij}\le K_i y_i
\qquad \forall i\in I.
\]

### Attivazione delle combinazioni e lotto minimo

\[
Lz_{ij}\le x_{ij}\le d_jz_{ij}
\qquad \forall(i,j)\in\Omega.
\]

### Collegamento fra utilizzo e attivazione del fornitore

\[
z_{ij}\le y_i
\qquad \forall(i,j)\in\Omega,
\]

\[
y_i\le \sum_{j:(i,j)\in\Omega}z_{ij}
\qquad \forall i\in I.
\]

### Multisourcing

Ogni componente deve essere acquistato da almeno due fornitori:

\[
\sum_{i:(i,j)\in\Omega}z_{ij}\ge 2
\qquad \forall j\in J.
\]

### Qualità media minima

Poiché la domanda è soddisfatta esattamente, il vincolo di qualità media può essere linearizzato come:

\[
\sum_{i:(i,j)\in\Omega}q_{ij}x_{ij}
\ge
\bar q\,d_j
\qquad \forall j\in J.
\]

### Limite sul rischio totale

\[
\sum_{(i,j)\in\Omega}r_i x_{ij}\le R.
\]

### Numero massimo di fornitori

\[
\sum_{i\in I}y_i\le P.
\]

### Attivazione di almeno uno fra A e B

\[
y_A+y_B\ge 1.
\]

### Domini

\[
x_{ij}\in\mathbb Z_+
\qquad \forall(i,j)\in\Omega,
\]

\[
z_{ij}\in\{0,1\}
\qquad \forall(i,j)\in\Omega,
\]

\[
y_i\in\{0,1\}
\qquad \forall i\in I.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

suppliers = ["A", "B", "C", "D", "E", "F"]
components = ["C1", "C2", "C3"]

demand = {
    "C1": 80,
    "C2": 70,
    "C3": 60
}

fixed_cost = {
    "A": 120,
    "B": 140,
    "C": 100,
    "D": 150,
    "E": 90,
    "F": 110
}

capacity = {
    "A": 100,
    "B": 110,
    "C": 90,
    "D": 120,
    "E": 80,
    "F": 95
}

risk = {
    "A": 2,
    "B": 3,
    "C": 1,
    "D": 4,
    "E": 2,
    "F": 3
}

unit_cost = {
    ("A", "C1"): 9,
    ("A", "C2"): 12,
    ("A", "C3"): 11,
    ("B", "C1"): 10,
    ("B", "C2"): 9,
    ("B", "C3"): 12,
    ("C", "C1"): 11,
    ("C", "C2"): 10,
    ("C", "C3"): 9,
    ("D", "C2"): 11,
    ("D", "C3"): 10,
    ("E", "C1"): 12,
    ("E", "C2"): 8,
    ("F", "C1"): 10,
    ("F", "C3"): 8
}

quality = {
    ("A", "C1"): 96,
    ("A", "C2"): 94,
    ("A", "C3"): 95,
    ("B", "C1"): 93,
    ("B", "C2"): 97,
    ("B", "C3"): 92,
    ("C", "C1"): 98,
    ("C", "C2"): 95,
    ("C", "C3"): 96,
    ("D", "C2"): 94,
    ("D", "C3"): 93,
    ("E", "C1"): 97,
    ("E", "C2"): 98,
    ("F", "C1"): 94,
    ("F", "C3"): 98
}

arcs = list(unit_cost.keys())
minimum_lot = 10
minimum_quality = 95
maximum_risk = 580
maximum_suppliers = 4

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("H07_sourcing", env=env)
model.Params.OutputFlag = 0
model.Params.MIPGap = 0.0

x = {
    (i, j): model.addVar(
        vtype=GRB.INTEGER,
        lb=0,
        name=f"x_{i}_{j}"
    )
    for i, j in arcs
}

z = {
    (i, j): model.addVar(
        vtype=GRB.BINARY,
        name=f"z_{i}_{j}"
    )
    for i, j in arcs
}

y = {
    i: model.addVar(
        vtype=GRB.BINARY,
        name=f"y_{i}"
    )
    for i in suppliers
}

model.setObjective(
    gp.quicksum(unit_cost[i, j] * x[i, j] for i, j in arcs)
    + gp.quicksum(fixed_cost[i] * y[i] for i in suppliers),
    GRB.MINIMIZE
)

for j in components:
    model.addConstr(
        gp.quicksum(x[i, j] for i in suppliers if (i, j) in x)
        == demand[j],
        name=f"demand_{j}"
    )

for i in suppliers:
    model.addConstr(
        gp.quicksum(x[i, j] for j in components if (i, j) in x)
        <= capacity[i] * y[i],
        name=f"capacity_{i}"
    )

for i, j in arcs:
    model.addConstr(
        x[i, j] >= minimum_lot * z[i, j],
        name=f"minimum_lot_{i}_{j}"
    )
    model.addConstr(
        x[i, j] <= demand[j] * z[i, j],
        name=f"usage_link_{i}_{j}"
    )
    model.addConstr(
        z[i, j] <= y[i],
        name=f"supplier_link_{i}_{j}"
    )

for i in suppliers:
    model.addConstr(
        y[i] <= gp.quicksum(z[i, j] for j in components if (i, j) in z),
        name=f"activation_definition_{i}"
    )

for j in components:
    model.addConstr(
        gp.quicksum(z[i, j] for i in suppliers if (i, j) in z) >= 2,
        name=f"multisourcing_{j}"
    )

for j in components:
    model.addConstr(
        gp.quicksum(
            quality[i, j] * x[i, j]
            for i in suppliers
            if (i, j) in x
        ) >= minimum_quality * demand[j],
        name=f"quality_{j}"
    )

model.addConstr(
    gp.quicksum(risk[i] * x[i, j] for i, j in arcs) <= maximum_risk,
    name="total_risk"
)

model.addConstr(
    gp.quicksum(y[i] for i in suppliers) <= maximum_suppliers,
    name="maximum_suppliers"
)

model.addConstr(
    y["A"] + y["B"] >= 1,
    name="at_least_A_or_B"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, "STATUS_" + str(model.Status))

def clean_value(value):
    rounded = round(value)
    if abs(value - rounded) <= 1e-6:
        return float(rounded)
    return float(value)

if model.Status == GRB.OPTIMAL:
    all_variables = (
        [x[i, j] for i, j in arcs]
        + [z[i, j] for i, j in arcs]
        + [y[i] for i in suppliers]
    )
    result = {
        "status": "OPTIMAL",
        "objective": clean_value(model.ObjVal),
        "variables": {
            variable.VarName: clean_value(variable.X)
            for variable in all_variables
        }
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Breve sintesi della soluzione

Gurobi restituisce stato **OPTIMAL** e valore obiettivo:

\[
\boxed{2160}.
\]

I fornitori attivati sono A, E e F. Le quantità non nulle sono:

\[
x_{A,C1}=70,\quad x_{A,C2}=10,\quad x_{A,C3}=10,
\]
\[
x_{E,C2}=60,
\]
\[
x_{F,C1}=10,\quad x_{F,C3}=50.
\]

Le corrispondenti variabili \(z_{ij}\) valgono 1, così come \(y_A,y_E,y_F\); tutte le altre variabili sono nulle. Il costo d’acquisto è 1840 e il costo fisso è 320. Il rischio totale è 480, inferiore al limite di 580.
