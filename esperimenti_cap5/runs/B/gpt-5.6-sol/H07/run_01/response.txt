## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Fornitori:
  \[
  I=\{A,B,C,D,E,F\}.
  \]
- Componenti:
  \[
  J=\{C1,C2,C3\}.
  \]
- Combinazioni fornitore–componente ammissibili:
  \[
  \begin{aligned}
  \mathcal E=\{&
  (A,C1),(A,C2),(A,C3),\\
  &(B,C1),(B,C2),(B,C3),\\
  &(C,C1),(C,C2),(C,C3),\\
  &(D,C2),(D,C3),\\
  &(E,C1),(E,C2),\\
  &(F,C1),(F,C3)\}.
  \end{aligned}
  \]
- Fornitori disponibili per il componente \(j\):
  \[
  I_j=\{i\in I:(i,j)\in\mathcal E\}.
  \]
- Componenti fornibili dal fornitore \(i\):
  \[
  J_i=\{j\in J:(i,j)\in\mathcal E\}.
  \]

### Parametri

- Domanda:
  \[
  d_{C1}=80,\qquad d_{C2}=70,\qquad d_{C3}=60.
  \]
- Lotto minimo: \(L=10\).
- Qualità minima media: \(Q=95\).
- Rischio massimo: \(R=580\).
- Numero massimo di fornitori attivabili: \(K=4\).
- Costi fissi:
  \[
  f_A=120,\ f_B=140,\ f_C=100,\ f_D=150,\ f_E=90,\ f_F=110.
  \]
- Capacità complessive:
  \[
  U_A=100,\ U_B=110,\ U_C=90,\ U_D=120,\ U_E=80,\ U_F=95.
  \]
- Coefficienti di rischio:
  \[
  r_A=2,\ r_B=3,\ r_C=1,\ r_D=4,\ r_E=2,\ r_F=3.
  \]
- \(c_{ij}\): costo unitario della combinazione \((i,j)\in\mathcal E\), secondo la tabella.
- \(q_{ij}\): qualità della combinazione \((i,j)\in\mathcal E\), secondo la tabella.

### Variabili decisionali

Per ogni \((i,j)\in\mathcal E\):

- \(x_{ij}\in\mathbb Z_+\): quantità intera del componente \(j\) acquistata dal fornitore \(i\);
- \(z_{ij}\in\{0,1\}\): vale 1 se la combinazione fornitore–componente è utilizzata.

Per ogni \(i\in I\):

- \(y_i\in\{0,1\}\): vale 1 se il fornitore \(i\) è attivato.

Nel codice i nomi sono rappresentati come `x_A_C1`, `z_A_C1`, `y_A`, ecc.

---

## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzare i costi di acquisto e di attivazione:

\[
\min\quad
\sum_{(i,j)\in\mathcal E} c_{ij}x_{ij}
+\sum_{i\in I} f_i y_i.
\]

### Soddisfacimento esatto della domanda

\[
\sum_{i\in I_j}x_{ij}=d_j
\qquad \forall j\in J.
\]

### Lotto minimo e collegamento con l’utilizzo

\[
x_{ij}\ge Lz_{ij}
\qquad \forall(i,j)\in\mathcal E,
\]

\[
x_{ij}\le d_jz_{ij}
\qquad \forall(i,j)\in\mathcal E.
\]

### Collegamento tra utilizzo e attivazione

\[
z_{ij}\le y_i
\qquad \forall(i,j)\in\mathcal E,
\]

\[
y_i\le\sum_{j\in J_i}z_{ij}
\qquad \forall i\in I.
\]

### Capacità complessiva dei fornitori

\[
\sum_{j\in J_i}x_{ij}\le U_i y_i
\qquad \forall i\in I.
\]

### Multisourcing

Ogni componente deve provenire da almeno due fornitori:

\[
\sum_{i\in I_j}z_{ij}\ge 2
\qquad \forall j\in J.
\]

### Qualità media minima

Poiché la quantità totale di ciascun componente è esattamente \(d_j\):

\[
\sum_{i\in I_j}q_{ij}x_{ij}\ge Qd_j
\qquad \forall j\in J.
\]

### Numero massimo di fornitori attivi

\[
\sum_{i\in I}y_i\le K.
\]

### Attivazione di almeno uno tra A e B

\[
y_A+y_B\ge 1.
\]

### Limite di rischio

\[
\sum_{i\in I}r_i\sum_{j\in J_i}x_{ij}\le R.
\]

### Domini

\[
x_{ij}\in\mathbb Z_+,\quad z_{ij}\in\{0,1\}
\qquad \forall(i,j)\in\mathcal E,
\]

\[
y_i\in\{0,1\}
\qquad \forall i\in I.
\]

## 3. Codice Python con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

suppliers = ["A", "B", "C", "D", "E", "F"]
components = ["C1", "C2", "C3"]

demand = {"C1": 80, "C2": 70, "C3": 60}

fixed_cost = {
    "A": 120,
    "B": 140,
    "C": 100,
    "D": 150,
    "E": 90,
    "F": 110,
}

capacity = {
    "A": 100,
    "B": 110,
    "C": 90,
    "D": 120,
    "E": 80,
    "F": 95,
}

risk = {
    "A": 2,
    "B": 3,
    "C": 1,
    "D": 4,
    "E": 2,
    "F": 3,
}

unit_cost = {
    ("A", "C1"): 9,  ("A", "C2"): 12, ("A", "C3"): 11,
    ("B", "C1"): 10, ("B", "C2"): 9,  ("B", "C3"): 12,
    ("C", "C1"): 11, ("C", "C2"): 10, ("C", "C3"): 9,
    ("D", "C2"): 11, ("D", "C3"): 10,
    ("E", "C1"): 12, ("E", "C2"): 8,
    ("F", "C1"): 10, ("F", "C3"): 8,
}

quality = {
    ("A", "C1"): 96, ("A", "C2"): 94, ("A", "C3"): 95,
    ("B", "C1"): 93, ("B", "C2"): 97, ("B", "C3"): 92,
    ("C", "C1"): 98, ("C", "C2"): 95, ("C", "C3"): 96,
    ("D", "C2"): 94, ("D", "C3"): 93,
    ("E", "C1"): 97, ("E", "C2"): 98,
    ("F", "C1"): 94, ("F", "C3"): 98,
}

arcs = list(unit_cost.keys())
min_lot = 10
min_quality = 95
max_risk = 580
max_suppliers = 4

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("H07_sourcing", env=env)

y = {
    i: model.addVar(vtype=GRB.BINARY, name=f"y_{i}")
    for i in suppliers
}

x = {
    (i, j): model.addVar(
        lb=0,
        vtype=GRB.INTEGER,
        name=f"x_{i}_{j}"
    )
    for i, j in arcs
}

z = {
    (i, j): model.addVar(
        vtype=GRB.BINARY,
        name=f"z_{i}_{j}"
    )
    for i, j in arcs
}

model.setObjective(
    gp.quicksum(fixed_cost[i] * y[i] for i in suppliers)
    + gp.quicksum(unit_cost[i, j] * x[i, j] for i, j in arcs),
    GRB.MINIMIZE
)

for j in components:
    model.addConstr(
        gp.quicksum(x[i, j] for i in suppliers if (i, j) in unit_cost)
        == demand[j],
        name=f"demand_{j}"
    )

for i, j in arcs:
    model.addConstr(
        x[i, j] >= min_lot * z[i, j],
        name=f"min_lot_{i}_{j}"
    )
    model.addConstr(
        x[i, j] <= demand[j] * z[i, j],
        name=f"usage_link_{i}_{j}"
    )
    model.addConstr(
        z[i, j] <= y[i],
        name=f"activation_link_{i}_{j}"
    )

for i in suppliers:
    available_components = [
        j for j in components if (i, j) in unit_cost
    ]
    model.addConstr(
        gp.quicksum(x[i, j] for j in available_components)
        <= capacity[i] * y[i],
        name=f"capacity_{i}"
    )
    model.addConstr(
        y[i] <= gp.quicksum(z[i, j] for j in available_components),
        name=f"active_only_if_used_{i}"
    )

for j in components:
    model.addConstr(
        gp.quicksum(z[i, j] for i in suppliers if (i, j) in unit_cost)
        >= 2,
        name=f"multisourcing_{j}"
    )
    model.addConstr(
        gp.quicksum(
            quality[i, j] * x[i, j]
            for i in suppliers
            if (i, j) in unit_cost
        ) >= min_quality * demand[j],
        name=f"quality_{j}"
    )

model.addConstr(
    gp.quicksum(y[i] for i in suppliers) <= max_suppliers,
    name="max_suppliers"
)

model.addConstr(
    y["A"] + y["B"] >= 1,
    name="at_least_A_or_B"
)

model.addConstr(
    gp.quicksum(
        risk[i] * x[i, j]
        for i, j in arcs
    ) <= max_risk,
    name="risk_limit"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT",
}

status = status_names.get(model.Status, f"STATUS_{model.Status}")

if model.Status == GRB.OPTIMAL:
    all_variables = (
        [y[i] for i in suppliers]
        + [x[i, j] for i, j in arcs]
        + [z[i, j] for i, j in arcs]
    )
    variable_values = {
        variable.VarName: float(round(variable.X))
        for variable in all_variables
    }
    result = {
        "status": status,
        "objective": float(round(model.ObjVal, 10)),
        "variables": variable_values,
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {},
    }

output_line = "SOLUTION_JSON=" + json.dumps(
    result,
    separators=(",", ":"),
    allow_nan=False
)

model.dispose()
env.dispose()

print(output_line)
```

## 4. Sintesi della soluzione

Il modello ha soluzione ottima con costo totale:

\[
\boxed{2160}
\]

di cui \(1840\) di acquisto e \(320\) di attivazione. I fornitori attivati sono \(A,E,F\).

Le quantità non nulle sono:

\[
x_{A,C1}=70,\quad x_{A,C2}=10,\quad x_{A,C3}=10,
\]

\[
x_{E,C2}=60,
\]

\[
x_{F,C1}=10,\quad x_{F,C3}=50.
\]

Pertanto, C1 proviene da A e F, C2 da A ed E, e C3 da A e F. Il rischio totale è \(480\), inferiore al limite di \(580\), e tutti i vincoli di capacità, qualità e multisourcing sono rispettati.
