## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Fornitori:
  \[
  I=\{A,B,C,D,E,F\}.
  \]
- Componenti:
  \[
  J=\{C1,C2,C3\}.
  \]
- Combinazioni fornitore–componente disponibili:
  \[
  \begin{aligned}
  E=\{&(A,C1),(A,C2),(A,C3),\\
      &(B,C1),(B,C2),(B,C3),\\
      &(C,C1),(C,C2),(C,C3),\\
      &(D,C2),(D,C3),\\
      &(E,C1),(E,C2),\\
      &(F,C1),(F,C3)\}.
  \end{aligned}
  \]

### Parametri

- Domanda:
  \[
  d_{C1}=80,\qquad d_{C2}=70,\qquad d_{C3}=60.
  \]
- Quantità minima per una combinazione utilizzata:
  \[
  L=10.
  \]
- Qualità media minima:
  \[
  \bar q=95.
  \]
- Numero massimo di fornitori:
  \[
  K=4.
  \]
- Limite di rischio:
  \[
  R=580.
  \]
- Costi fissi:
  \[
  f=(120,140,100,150,90,110).
  \]
- Capacità complessive:
  \[
  u=(100,110,90,120,80,95).
  \]
- Coefficienti di rischio:
  \[
  r=(2,3,1,4,2,3).
  \]
- \(c_{ij}\): costo unitario della combinazione \((i,j)\in E\), come da tabella.
- \(q_{ij}\): qualità della combinazione \((i,j)\in E\), come da tabella.
- Limite superiore per ciascun arco:
  \[
  M_{ij}=\min\{u_i,d_j\}.
  \]

### Variabili decisionali

Per ogni \((i,j)\in E\):

- \(x_{ij}\in\mathbb Z_+\): unità del componente \(j\) acquistate dal fornitore \(i\);
- \(z_{ij}\in\{0,1\}\): vale 1 se la combinazione fornitore–componente è utilizzata.

Per ogni \(i\in I\):

- \(y_i\in\{0,1\}\): vale 1 se il fornitore \(i\) è attivato.

---

## 2. Formulazione matematica completa

### Funzione obiettivo

\[
\min \quad
\sum_{(i,j)\in E} c_{ij}x_{ij}
+\sum_{i\in I}f_i y_i.
\]

### Soddisfacimento esatto della domanda

\[
\sum_{i:(i,j)\in E}x_{ij}=d_j
\qquad \forall j\in J.
\]

### Capacità complessiva dei fornitori

\[
\sum_{j:(i,j)\in E}x_{ij}\le u_i y_i
\qquad \forall i\in I.
\]

### Collegamento tra quantità e utilizzo della combinazione

\[
Lz_{ij}\le x_{ij}\le M_{ij}z_{ij}
\qquad \forall (i,j)\in E.
\]

### Collegamento tra combinazione e attivazione del fornitore

\[
z_{ij}\le y_i
\qquad \forall (i,j)\in E,
\]

\[
y_i\le \sum_{j:(i,j)\in E}z_{ij}
\qquad \forall i\in I.
\]

### Multisourcing

Ogni componente deve essere acquistato da almeno due fornitori:

\[
\sum_{i:(i,j)\in E}z_{ij}\ge 2
\qquad \forall j\in J.
\]

### Qualità media minima

\[
\sum_{i:(i,j)\in E}q_{ij}x_{ij}
\ge 95d_j
\qquad \forall j\in J.
\]

### Numero massimo di fornitori

\[
\sum_{i\in I}y_i\le 4.
\]

### Attivazione di almeno uno tra A e B

\[
y_A+y_B\ge 1.
\]

### Limite di rischio totale

\[
\sum_{(i,j)\in E}r_i x_{ij}\le 580.
\]

### Domini

\[
x_{ij}\in\mathbb Z_+
\qquad \forall(i,j)\in E,
\]

\[
z_{ij}\in\{0,1\}
\qquad \forall(i,j)\in E,
\]

\[
y_i\in\{0,1\}
\qquad \forall i\in I.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

suppliers = ["A", "B", "C", "D", "E", "F"]
components = ["C1", "C2", "C3"]

demand = {
    "C1": 80,
    "C2": 70,
    "C3": 60
}

fixed_cost = {
    "A": 120,
    "B": 140,
    "C": 100,
    "D": 150,
    "E": 90,
    "F": 110
}

capacity = {
    "A": 100,
    "B": 110,
    "C": 90,
    "D": 120,
    "E": 80,
    "F": 95
}

risk = {
    "A": 2,
    "B": 3,
    "C": 1,
    "D": 4,
    "E": 2,
    "F": 3
}

unit_cost = {
    ("A", "C1"): 9,  ("A", "C2"): 12, ("A", "C3"): 11,
    ("B", "C1"): 10, ("B", "C2"): 9,  ("B", "C3"): 12,
    ("C", "C1"): 11, ("C", "C2"): 10, ("C", "C3"): 9,
    ("D", "C2"): 11, ("D", "C3"): 10,
    ("E", "C1"): 12, ("E", "C2"): 8,
    ("F", "C1"): 10, ("F", "C3"): 8
}

quality = {
    ("A", "C1"): 96, ("A", "C2"): 94, ("A", "C3"): 95,
    ("B", "C1"): 93, ("B", "C2"): 97, ("B", "C3"): 92,
    ("C", "C1"): 98, ("C", "C2"): 95, ("C", "C3"): 96,
    ("D", "C2"): 94, ("D", "C3"): 93,
    ("E", "C1"): 97, ("E", "C2"): 98,
    ("F", "C1"): 94, ("F", "C3"): 98
}

arcs = [
    (i, j)
    for i in suppliers
    for j in components
    if (i, j) in unit_cost
]

minimum_order = 10
minimum_quality = 95
maximum_suppliers = 4
maximum_risk = 580

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.setParam("LogToConsole", 0)
env.start()

model = gp.Model("H07_sourcing", env=env)

y = {
    i: model.addVar(vtype=GRB.BINARY, name="y_" + i)
    for i in suppliers
}

z = {
    (i, j): model.addVar(vtype=GRB.BINARY, name="z_" + i + "_" + j)
    for i, j in arcs
}

x = {
    (i, j): model.addVar(vtype=GRB.INTEGER, lb=0, name="x_" + i + "_" + j)
    for i, j in arcs
}

model.setObjective(
    gp.quicksum(unit_cost[i, j] * x[i, j] for i, j in arcs)
    + gp.quicksum(fixed_cost[i] * y[i] for i in suppliers),
    GRB.MINIMIZE
)

for j in components:
    model.addConstr(
        gp.quicksum(x[i, j] for i in suppliers if (i, j) in x) == demand[j],
        name="demand_" + j
    )

for i in suppliers:
    model.addConstr(
        gp.quicksum(x[i, j] for j in components if (i, j) in x)
        <= capacity[i] * y[i],
        name="capacity_" + i
    )

for i, j in arcs:
    upper_bound = min(capacity[i], demand[j])
    model.addConstr(
        x[i, j] >= minimum_order * z[i, j],
        name="minimum_order_" + i + "_" + j
    )
    model.addConstr(
        x[i, j] <= upper_bound * z[i, j],
        name="maximum_order_" + i + "_" + j
    )
    model.addConstr(
        z[i, j] <= y[i],
        name="arc_activation_" + i + "_" + j
    )

for i in suppliers:
    model.addConstr(
        y[i] <= gp.quicksum(z[i, j] for j in components if (i, j) in z),
        name="supplier_usage_" + i
    )

for j in components:
    model.addConstr(
        gp.quicksum(z[i, j] for i in suppliers if (i, j) in z) >= 2,
        name="multisourcing_" + j
    )

for j in components:
    model.addConstr(
        gp.quicksum(
            quality[i, j] * x[i, j]
            for i in suppliers
            if (i, j) in x
        ) >= minimum_quality * demand[j],
        name="quality_" + j
    )

model.addConstr(
    gp.quicksum(y[i] for i in suppliers) <= maximum_suppliers,
    name="maximum_suppliers"
)

model.addConstr(
    y["A"] + y["B"] >= 1,
    name="at_least_A_or_B"
)

model.addConstr(
    gp.quicksum(risk[i] * x[i, j] for i, j in arcs) <= maximum_risk,
    name="risk_limit"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, "STATUS_" + str(model.Status))

if model.Status == GRB.OPTIMAL:
    ordered_variables = (
        [y[i] for i in suppliers]
        + [z[i, j] for i, j in arcs]
        + [x[i, j] for i, j in arcs]
    )
    variable_values = {
        variable.VarName: float(round(variable.X))
        for variable in ordered_variables
    }
    result = {
        "status": "OPTIMAL",
        "objective": float(round(model.ObjVal, 6)),
        "variables": variable_values
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Lo stato è **OPTIMAL** e il costo minimo è:

\[
\boxed{2160}.
\]

Sono attivati i fornitori \(A,E,F\). Le quantità non nulle sono:

\[
x_{A,C1}=70,\quad x_{F,C1}=10,
\]
\[
x_{A,C2}=10,\quad x_{E,C2}=60,
\]
\[
x_{A,C3}=10,\quad x_{F,C3}=50.
\]

Il costo di acquisto è \(1840\), mentre il costo fisso è \(320\). Il rischio totale è \(480\), tutte le capacità sono rispettate e ogni componente proviene esattamente da due fornitori.
