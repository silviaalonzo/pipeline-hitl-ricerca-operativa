## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- \(I=\{\text{Ana, Bruno, Carla, Diego, Elena, Fabio}\}\): dipendenti.
- \(S=\{\text{M1, M2, P1, P2, N1, N2}\}\): turni.
- \(N=\{\text{N1, N2}\}\subseteq S\): turni notturni.
- \(A\subseteq I\times S\): coppie dipendente-turno disponibili, ossia tutte le celle della tabella non contrassegnate da “—”.

### Parametri

- \(c_{is}\): costo di assegnazione del dipendente \(i\) al turno \(s\), definito per ogni \((i,s)\in A\).
- \(L=2\): numero massimo di turni assegnabili a ciascun dipendente.
- \(L_N=1\): numero massimo di turni notturni assegnabili a ciascun dipendente.

### Variabili decisionali

Per ogni \((i,s)\in A\):

\[
x_{is}=
\begin{cases}
1 & \text{se il dipendente }i\text{ è assegnato al turno }s,\\
0 & \text{altrimenti.}
\end{cases}
\]

---

## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzare il costo complessivo delle assegnazioni:

\[
\min \quad \sum_{(i,s)\in A} c_{is}x_{is}.
\]

### Copertura dei turni

Ogni turno deve essere coperto esattamente da un dipendente:

\[
\sum_{i:(i,s)\in A} x_{is}=1
\qquad \forall s\in S.
\]

### Numero massimo di turni per dipendente

Ogni dipendente può lavorare al massimo due turni:

\[
\sum_{s:(i,s)\in A}x_{is}\leq 2
\qquad \forall i\in I.
\]

### Numero massimo di turni notturni

Ogni dipendente può lavorare al massimo un turno notturno:

\[
\sum_{s\in N:(i,s)\in A}x_{is}\leq 1
\qquad \forall i\in I.
\]

### Dominio

\[
x_{is}\in\{0,1\}
\qquad \forall(i,s)\in A.
\]

---

## 3. Codice Python con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

employees = ["Ana", "Bruno", "Carla", "Diego", "Elena", "Fabio"]
shifts = ["M1", "M2", "P1", "P2", "N1", "N2"]
night_shifts = ["N1", "N2"]

cost = {
    ("Ana", "M1"): 8,
    ("Ana", "M2"): 7,
    ("Ana", "P1"): 9,
    ("Ana", "P2"): 8,

    ("Bruno", "M1"): 7,
    ("Bruno", "M2"): 8,
    ("Bruno", "P1"): 8,
    ("Bruno", "P2"): 9,

    ("Carla", "M2"): 9,
    ("Carla", "P1"): 8,
    ("Carla", "P2"): 8,
    ("Carla", "N1"): 11,
    ("Carla", "N2"): 12,

    ("Diego", "M1"): 10,
    ("Diego", "P1"): 9,
    ("Diego", "P2"): 8,
    ("Diego", "N1"): 10,
    ("Diego", "N2"): 11,

    ("Elena", "M1"): 8,
    ("Elena", "M2"): 10,
    ("Elena", "P1"): 9,
    ("Elena", "P2"): 9,
    ("Elena", "N1"): 12,
    ("Elena", "N2"): 10,

    ("Fabio", "M1"): 9,
    ("Fabio", "M2"): 8,
    ("Fabio", "P1"): 10,
    ("Fabio", "P2"): 7
}

available_pairs = list(cost.keys())

model = gp.Model("M03_Assegnazione_personale")
model.Params.OutputFlag = 0

x = {
    (i, s): model.addVar(vtype=GRB.BINARY, name=f"x_{i}_{s}")
    for i, s in available_pairs
}

model.setObjective(
    gp.quicksum(cost[i, s] * x[i, s] for i, s in available_pairs),
    GRB.MINIMIZE
)

for s in shifts:
    model.addConstr(
        gp.quicksum(x[i, s] for i in employees if (i, s) in x) == 1,
        name=f"copertura_{s}"
    )

for i in employees:
    model.addConstr(
        gp.quicksum(x[i, s] for s in shifts if (i, s) in x) <= 2,
        name=f"max_turni_{i}"
    )

for i in employees:
    model.addConstr(
        gp.quicksum(x[i, s] for s in night_shifts if (i, s) in x) <= 1,
        name=f"max_notturni_{i}"
    )

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, f"STATUS_{model.Status}")

if model.Status == GRB.OPTIMAL:
    variable_values = {
        f"x_{i}_{s}": float(round(x[i, s].X))
        for i, s in available_pairs
    }
    result = {
        "status": "OPTIMAL",
        "objective": float(model.ObjVal),
        "variables": variable_values
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Il costo ottimo è:

\[
z^*=49.
\]

Una soluzione ottima è:

- Ana: M2;
- Bruno: M1 e P1;
- Diego: N1;
- Elena: N2;
- Fabio: P2;
- Carla: nessun turno.

Il valore \(49\) è anche la somma dei costi minimi individuali dei sei turni, e tali minimi possono essere assegnati simultaneamente rispettando tutti i vincoli; pertanto la soluzione è ottima.
