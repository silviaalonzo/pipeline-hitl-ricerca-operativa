## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Dipendenti:
  \[
  I=\{\text{Ana, Bruno, Carla, Diego, Elena, Fabio}\}.
  \]

- Turni:
  \[
  T=\{\text{M1, M2, P1, P2, N1, N2}\}.
  \]

- Turni notturni:
  \[
  N=\{\text{N1, N2}\}.
  \]

- Coppie dipendente-turno disponibili:
  \[
  \begin{aligned}
  A=\{&
  (\text{Ana},\text{M1}),(\text{Ana},\text{M2}),(\text{Ana},\text{P1}),(\text{Ana},\text{P2}),\\
  &(\text{Bruno},\text{M1}),(\text{Bruno},\text{M2}),(\text{Bruno},\text{P1}),(\text{Bruno},\text{P2}),\\
  &(\text{Carla},\text{M2}),(\text{Carla},\text{P1}),(\text{Carla},\text{P2}),
    (\text{Carla},\text{N1}),(\text{Carla},\text{N2}),\\
  &(\text{Diego},\text{M1}),(\text{Diego},\text{P1}),(\text{Diego},\text{P2}),
    (\text{Diego},\text{N1}),(\text{Diego},\text{N2}),\\
  &(\text{Elena},\text{M1}),(\text{Elena},\text{M2}),(\text{Elena},\text{P1}),
    (\text{Elena},\text{P2}),(\text{Elena},\text{N1}),(\text{Elena},\text{N2}),\\
  &(\text{Fabio},\text{M1}),(\text{Fabio},\text{M2}),(\text{Fabio},\text{P1}),(\text{Fabio},\text{P2})
  \}.
  \end{aligned}
  \]

### Parametri

- \(c_{it}\): costo di assegnazione del dipendente \(i\) al turno \(t\), definito per ogni \((i,t)\in A\), secondo la tabella fornita.
- \(L=2\): numero massimo di turni assegnabili a ciascun dipendente.
- \(L^N=1\): numero massimo di turni notturni assegnabili a ciascun dipendente.

### Variabili decisionali

Per ogni \((i,t)\in A\):

\[
x_{it}=
\begin{cases}
1 & \text{se il dipendente }i\text{ viene assegnato al turno }t,\\
0 & \text{altrimenti.}
\end{cases}
\]

---

## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzare il costo complessivo:

\[
\min \quad \sum_{(i,t)\in A} c_{it}x_{it}.
\]

### Copertura dei turni

Ogni turno deve essere assegnato esattamente a un dipendente:

\[
\sum_{\substack{i\in I\\(i,t)\in A}}x_{it}=1
\qquad \forall t\in T.
\]

### Numero massimo di turni per dipendente

\[
\sum_{\substack{t\in T\\(i,t)\in A}}x_{it}\leq 2
\qquad \forall i\in I.
\]

### Numero massimo di turni notturni per dipendente

\[
\sum_{\substack{t\in N\\(i,t)\in A}}x_{it}\leq 1
\qquad \forall i\in I.
\]

### Dominio

\[
x_{it}\in\{0,1\}
\qquad \forall(i,t)\in A.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

employees = ["Ana", "Bruno", "Carla", "Diego", "Elena", "Fabio"]
shifts = ["M1", "M2", "P1", "P2", "N1", "N2"]
night_shifts = ["N1", "N2"]

costs = {
    ("Ana", "M1"): 8,
    ("Ana", "M2"): 7,
    ("Ana", "P1"): 9,
    ("Ana", "P2"): 8,

    ("Bruno", "M1"): 7,
    ("Bruno", "M2"): 8,
    ("Bruno", "P1"): 8,
    ("Bruno", "P2"): 9,

    ("Carla", "M2"): 9,
    ("Carla", "P1"): 8,
    ("Carla", "P2"): 8,
    ("Carla", "N1"): 11,
    ("Carla", "N2"): 12,

    ("Diego", "M1"): 10,
    ("Diego", "P1"): 9,
    ("Diego", "P2"): 8,
    ("Diego", "N1"): 10,
    ("Diego", "N2"): 11,

    ("Elena", "M1"): 8,
    ("Elena", "M2"): 10,
    ("Elena", "P1"): 9,
    ("Elena", "P2"): 9,
    ("Elena", "N1"): 12,
    ("Elena", "N2"): 10,

    ("Fabio", "M1"): 9,
    ("Fabio", "M2"): 8,
    ("Fabio", "P1"): 10,
    ("Fabio", "P2"): 7
}

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("assegnazione_personale_turni", env=env)

x = {
    (i, t): model.addVar(vtype=GRB.BINARY, name=f"x_{i}_{t}")
    for (i, t) in costs
}

total_cost = gp.quicksum(costs[i, t] * x[i, t] for (i, t) in costs)
model.setObjective(total_cost, GRB.MINIMIZE)

for t in shifts:
    model.addConstr(
        gp.quicksum(x[i, t] for i in employees if (i, t) in x) == 1,
        name=f"copertura_{t}"
    )

for i in employees:
    model.addConstr(
        gp.quicksum(x[i, t] for t in shifts if (i, t) in x) <= 2,
        name=f"massimo_due_turni_{i}"
    )

for i in employees:
    model.addConstr(
        gp.quicksum(x[i, t] for t in night_shifts if (i, t) in x) <= 1,
        name=f"massimo_un_notturno_{i}"
    )

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

if model.Status == GRB.OPTIMAL:
    result = {
        "status": "OPTIMAL",
        "objective": float(round(model.ObjVal, 10)),
        "variables": {
            x[i, t].VarName: 1.0 if x[i, t].X > 0.5 else 0.0
            for (i, t) in costs
        }
    }
else:
    result = {
        "status": status_names.get(model.Status, "STATUS_" + str(model.Status)),
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Lo stato è **OPTIMAL** e il costo minimo è:

\[
z^*=49.
\]

Una soluzione ottima ha le seguenti decisioni non nulle:

\[
x_{\text{Bruno,M1}}=
x_{\text{Ana,M2}}=
x_{\text{Carla,P1}}=
x_{\text{Fabio,P2}}=
x_{\text{Diego,N1}}=
x_{\text{Elena,N2}}=1.
\]

Tutte le altre variabili sono nulle. Esiste anche una soluzione ottima equivalente assegnando P1 a Bruno anziché a Carla; Gurobi può restituire una delle due.
