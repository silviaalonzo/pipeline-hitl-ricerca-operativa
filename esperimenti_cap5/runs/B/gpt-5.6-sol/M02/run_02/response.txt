## 1. Insiemi, parametri e variabili decisionali

### Insieme

\[
I=\{A,B,C,D\}
\]

è l’insieme dei prodotti.

### Parametri

Per ogni prodotto \(i\in I\):

| \(i\) | Margine \(p_i\) | Setup \(f_i\) | Macchina \(m_i\) | Lavoro \(h_i\) | Lotto minimo \(L_i\) | Domanda massima \(U_i\) |
|---|---:|---:|---:|---:|---:|---:|
| A | 42 | 80 | 3 | 2 | 4 | 20 |
| B | 36 | 65 | 2 | 3 | 5 | 25 |
| C | 50 | 90 | 4 | 2 | 3 | 16 |
| D | 31 | 50 | 1 | 2 | 6 | 30 |

Capacità disponibili:

\[
M=90 \quad\text{ore-macchina},\qquad H=100 \quad\text{ore di lavoro}.
\]

Numero minimo di articoli diversi da produrre:

\[
K=2.
\]

### Variabili decisionali

\[
x_i=\text{numero intero di unità prodotte dell’articolo }i,
\]

\[
y_i=
\begin{cases}
1 & \text{se l’articolo }i\text{ viene prodotto},\\
0 & \text{altrimenti}.
\end{cases}
\]

con:

\[
x_i\in\mathbb Z_{\ge 0},\qquad y_i\in\{0,1\}.
\]

---

## 2. Formulazione matematica completa

### Funzione obiettivo

Massimizzare il margine di produzione al netto dei costi fissi di setup:

\[
\max \quad
\sum_{i\in I} p_i x_i-\sum_{i\in I} f_i y_i.
\]

Esplicitamente:

\[
\max \quad
42x_A+36x_B+50x_C+31x_D
-80y_A-65y_B-90y_C-50y_D.
\]

### Vincoli di capacità

Ore-macchina:

\[
3x_A+2x_B+4x_C+x_D\le 90.
\]

Ore di lavoro:

\[
2x_A+3x_B+2x_C+2x_D\le 100.
\]

### Collegamento tra produzione e setup

Per ogni \(i\in I\):

\[
L_i y_i\le x_i\le U_i y_i.
\]

Esplicitamente:

\[
4y_A\le x_A\le 20y_A,
\]

\[
5y_B\le x_B\le 25y_B,
\]

\[
3y_C\le x_C\le 16y_C,
\]

\[
6y_D\le x_D\le 30y_D.
\]

### Numero minimo di articoli prodotti

\[
y_A+y_B+y_C+y_D\ge 2.
\]

### Domini

\[
x_A,x_B,x_C,x_D\in\mathbb Z_{\ge 0},
\]

\[
y_A,y_B,y_C,y_D\in\{0,1\}.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

products = ["A", "B", "C", "D"]

margin = {"A": 42, "B": 36, "C": 50, "D": 31}
setup = {"A": 80, "B": 65, "C": 90, "D": 50}
machine = {"A": 3, "B": 2, "C": 4, "D": 1}
labor = {"A": 2, "B": 3, "C": 2, "D": 2}
min_lot = {"A": 4, "B": 5, "C": 3, "D": 6}
max_demand = {"A": 20, "B": 25, "C": 16, "D": 30}

machine_capacity = 90
labor_capacity = 100
minimum_products = 2

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("M02_piano_produzione_setup", env=env)

x = model.addVars(
    products,
    vtype=GRB.INTEGER,
    lb=0,
    name="x"
)

y = model.addVars(
    products,
    vtype=GRB.BINARY,
    name="y"
)

model.setObjective(
    gp.quicksum(margin[i] * x[i] - setup[i] * y[i] for i in products),
    GRB.MAXIMIZE
)

model.addConstr(
    gp.quicksum(machine[i] * x[i] for i in products) <= machine_capacity,
    name="capacita_macchina"
)

model.addConstr(
    gp.quicksum(labor[i] * x[i] for i in products) <= labor_capacity,
    name="capacita_lavoro"
)

for i in products:
    model.addConstr(x[i] >= min_lot[i] * y[i], name=f"lotto_minimo_{i}")
    model.addConstr(x[i] <= max_demand[i] * y[i], name=f"domanda_massima_{i}")

model.addConstr(
    gp.quicksum(y[i] for i in products) >= minimum_products,
    name="numero_minimo_prodotti"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, str(model.Status))

if model.Status == GRB.OPTIMAL:
    def numeric_value(value):
        if abs(value - round(value)) <= 1e-6:
            return float(round(value))
        return float(value)

    variables = {}
    for i in products:
        variables[x[i].VarName] = numeric_value(x[i].X)
    for i in products:
        variables[y[i].VarName] = numeric_value(y[i].X)

    payload = {
        "status": status,
        "objective": numeric_value(model.ObjVal),
        "variables": variables
    }
else:
    payload = {
        "status": status,
        "objective": None,
        "variables": {}
    }

model.dispose()
env.dispose()

print("SOLUTION_JSON=" + json.dumps(payload, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Lo stato del solver è **OPTIMAL** e il valore ottimo è:

\[
z^*=1640.
\]

Le decisioni non nulle sono:

\[
x_A=20,\qquad x_D=30,\qquad y_A=1,\qquad y_D=1.
\]

Il piano utilizza integralmente entrambe le capacità:

\[
3(20)+1(30)=90 \text{ ore-macchina},
\]

\[
2(20)+2(30)=100 \text{ ore di lavoro}.
\]

Il margine lordo è \(1770\), mentre i setup di A e D costano \(130\), ottenendo il margine netto ottimo \(1770-130=1640\).
