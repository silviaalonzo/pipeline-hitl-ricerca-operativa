## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Dipendenti:
  \[
  I=\{\mathrm{E1},\ldots,\mathrm{E8}\}.
  \]
- Giorni, ordinati:
  \[
  D=(\mathrm{Lun},\mathrm{Mar},\mathrm{Mer},\mathrm{Gio},
  \mathrm{Ven},\mathrm{Sab},\mathrm{Dom}).
  \]
- Dipendenti senior:
  \[
  S=\{\mathrm{E1},\mathrm{E2},\mathrm{E3}\}.
  \]
- Specialisti:
  \[
  P=\{\mathrm{E7},\mathrm{E8}\}.
  \]
- Giorni del fine settimana:
  \[
  F=\{\mathrm{Sab},\mathrm{Dom}\}.
  \]
- Finestre di quattro giorni consecutivi:
  \[
  K=\{
  (\mathrm{Lun},\mathrm{Mar},\mathrm{Mer},\mathrm{Gio}),
  (\mathrm{Mar},\mathrm{Mer},\mathrm{Gio},\mathrm{Ven}),
  \]
  \[
  (\mathrm{Mer},\mathrm{Gio},\mathrm{Ven},\mathrm{Sab}),
  (\mathrm{Gio},\mathrm{Ven},\mathrm{Sab},\mathrm{Dom})
  \}.
  \]

### Parametri

Domanda giornaliera \(q_d\):

\[
(q_{\mathrm{Lun}},q_{\mathrm{Mar}},q_{\mathrm{Mer}},
q_{\mathrm{Gio}},q_{\mathrm{Ven}},q_{\mathrm{Sab}},q_{\mathrm{Dom}})
=(4,3,4,4,5,3,3).
\]

Sia \(a_{id}\in\{0,1\}\) il parametro di disponibilità, pari a 0 in corrispondenza dei trattini e a 1 altrimenti.

I costi \(c_{id}\), definiti per le coppie disponibili, sono:

\[
\begin{array}{c|rrrrrrr}
 & Lun&Mar&Mer&Gio&Ven&Sab&Dom\\ \hline
E1&9&9&10&9&11&14&-\\
E2&10&9&9&10&10&-&14\\
E3&9&10&9&9&12&12&13\\
E4&7&-&7&8&8&11&11\\
E5&8&7&8&-&9&10&12\\
E6&-&8&8&7&8&12&10\\
E7&8&8&7&9&7&11&-\\
E8&9&7&8&8&7&10&11
\end{array}
\]

### Variabili decisionali

Per ogni \(i\in I\) e \(d\in D\):

\[
x_{id}=
\begin{cases}
1 & \text{se il dipendente }i\text{ lavora nel giorno }d,\\
0 & \text{altrimenti.}
\end{cases}
\]

Nel codice e nell’output le variabili sono denominate `x_E1_Lun`, `x_E1_Mar`, ecc.

---

## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzare il costo settimanale:

\[
\min \quad
\sum_{i\in I}\sum_{\substack{d\in D\\a_{id}=1}}
c_{id}x_{id}.
\]

### Copertura della domanda

\[
\sum_{i\in I}x_{id}\ge q_d
\qquad \forall d\in D.
\]

### Presenza giornaliera di almeno un senior

\[
\sum_{i\in S}x_{id}\ge 1
\qquad \forall d\in D.
\]

### Numero minimo e massimo di giorni lavorati

\[
3\le \sum_{d\in D}x_{id}\le 5
\qquad \forall i\in I.
\]

### Divieto di lavorare quattro giorni consecutivi

\[
\sum_{d\in k}x_{id}\le 3
\qquad \forall i\in I,\ \forall k\in K.
\]

### Presenza degli specialisti giovedì e venerdì

\[
x_{\mathrm{E7},d}+x_{\mathrm{E8},d}\ge 1
\qquad
\forall d\in\{\mathrm{Gio},\mathrm{Ven}\}.
\]

### Limite di fine settimana per E1 ed E2

\[
x_{i,\mathrm{Sab}}+x_{i,\mathrm{Dom}}\le 1
\qquad
\forall i\in\{\mathrm{E1},\mathrm{E2}\}.
\]

### Indisponibilità

\[
x_{id}=0
\qquad
\forall i\in I,\ d\in D:\ a_{id}=0.
\]

### Dominio

\[
x_{id}\in\{0,1\}
\qquad \forall i\in I,\ d\in D.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

employees = ["E1", "E2", "E3", "E4", "E5", "E6", "E7", "E8"]
days = ["Lun", "Mar", "Mer", "Gio", "Ven", "Sab", "Dom"]

demand = {
    "Lun": 4,
    "Mar": 3,
    "Mer": 4,
    "Gio": 4,
    "Ven": 5,
    "Sab": 3,
    "Dom": 3
}

cost = {
    ("E1", "Lun"): 9,  ("E1", "Mar"): 9,  ("E1", "Mer"): 10,
    ("E1", "Gio"): 9,  ("E1", "Ven"): 11, ("E1", "Sab"): 14,

    ("E2", "Lun"): 10, ("E2", "Mar"): 9,  ("E2", "Mer"): 9,
    ("E2", "Gio"): 10, ("E2", "Ven"): 10, ("E2", "Dom"): 14,

    ("E3", "Lun"): 9,  ("E3", "Mar"): 10, ("E3", "Mer"): 9,
    ("E3", "Gio"): 9,  ("E3", "Ven"): 12, ("E3", "Sab"): 12,
    ("E3", "Dom"): 13,

    ("E4", "Lun"): 7,  ("E4", "Mer"): 7,  ("E4", "Gio"): 8,
    ("E4", "Ven"): 8,  ("E4", "Sab"): 11, ("E4", "Dom"): 11,

    ("E5", "Lun"): 8,  ("E5", "Mar"): 7,  ("E5", "Mer"): 8,
    ("E5", "Ven"): 9,  ("E5", "Sab"): 10, ("E5", "Dom"): 12,

    ("E6", "Mar"): 8,  ("E6", "Mer"): 8,  ("E6", "Gio"): 7,
    ("E6", "Ven"): 8,  ("E6", "Sab"): 12, ("E6", "Dom"): 10,

    ("E7", "Lun"): 8,  ("E7", "Mar"): 8,  ("E7", "Mer"): 7,
    ("E7", "Gio"): 9,  ("E7", "Ven"): 7,  ("E7", "Sab"): 11,

    ("E8", "Lun"): 9,  ("E8", "Mar"): 7,  ("E8", "Mer"): 8,
    ("E8", "Gio"): 8,  ("E8", "Ven"): 7,  ("E8", "Sab"): 10,
    ("E8", "Dom"): 11
}

seniors = ["E1", "E2", "E3"]
specialists = ["E7", "E8"]

four_day_windows = [
    ["Lun", "Mar", "Mer", "Gio"],
    ["Mar", "Mer", "Gio", "Ven"],
    ["Mer", "Gio", "Ven", "Sab"],
    ["Gio", "Ven", "Sab", "Dom"]
]

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("H03_turnazione_settimanale", env=env)

x = {}
for i in employees:
    for d in days:
        x[i, d] = model.addVar(vtype=GRB.BINARY, name=f"x_{i}_{d}")

model.setObjective(
    gp.quicksum(cost[i, d] * x[i, d] for (i, d) in cost),
    GRB.MINIMIZE
)

for d in days:
    model.addConstr(
        gp.quicksum(x[i, d] for i in employees) >= demand[d],
        name=f"domanda_{d}"
    )

for d in days:
    model.addConstr(
        gp.quicksum(x[i, d] for i in seniors) >= 1,
        name=f"senior_{d}"
    )

for i in employees:
    model.addConstr(
        gp.quicksum(x[i, d] for d in days) >= 3,
        name=f"min_giorni_{i}"
    )
    model.addConstr(
        gp.quicksum(x[i, d] for d in days) <= 5,
        name=f"max_giorni_{i}"
    )

for i in employees:
    for w, window in enumerate(four_day_windows, start=1):
        model.addConstr(
            gp.quicksum(x[i, d] for d in window) <= 3,
            name=f"no_quattro_consecutivi_{i}_{w}"
        )

for d in ["Gio", "Ven"]:
    model.addConstr(
        gp.quicksum(x[i, d] for i in specialists) >= 1,
        name=f"specialista_{d}"
    )

for i in ["E1", "E2"]:
    model.addConstr(
        x[i, "Sab"] + x[i, "Dom"] <= 1,
        name=f"fine_settimana_{i}"
    )

for i in employees:
    for d in days:
        if (i, d) not in cost:
            model.addConstr(x[i, d] == 0, name=f"indisponibile_{i}_{d}")

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, str(model.Status))

if model.Status == GRB.OPTIMAL:
    variable_values = {}
    for i in employees:
        for d in days:
            variable_values[f"x_{i}_{d}"] = float(round(x[i, d].X))

    result = {
        "status": "OPTIMAL",
        "objective": float(round(model.ObjVal, 10)),
        "variables": variable_values
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":"), allow_nan=False))
```

## 4. Sintesi della soluzione

Lo stato del solver è **OPTIMAL** e il costo minimo è:

\[
\boxed{227}
\]

Una turnazione ottima è:

- **E1:** Lun, Mar, Gio
- **E2:** Mar, Mer, Ven
- **E3:** Lun, Sab, Dom
- **E4:** Lun, Mer, Gio, Ven, Dom
- **E5:** Mar, Mer, Sab
- **E6:** Gio, Ven, Dom
- **E7:** Lun, Mer, Ven
- **E8:** Gio, Ven, Sab

Queste sono tutte e sole le decisioni non nulle. La domanda è coperta esattamente ogni giorno, è sempre presente almeno un senior e gli specialisti coprono sia giovedì sia venerdì.
