## 1. Insiemi, parametri e variabili decisionali

### Insiemi
- Tipi di veicolo:
  \[
  V=\{\text{Piccolo},\text{Medio},\text{Grande}\}.
  \]
- Rotte:
  \[
  R=\{\text{R1},\text{R2},\text{R3},\text{R4}\}.
  \]

### Parametri
- Domanda \(d_r\):
  \[
  (d_{\mathrm{R1}},d_{\mathrm{R2}},d_{\mathrm{R3}},d_{\mathrm{R4}})
  =(42,55,38,64).
  \]
- Capacità per viaggio \(q_v\):
  \[
  q_{\text{Piccolo}}=8,\quad q_{\text{Medio}}=14,\quad q_{\text{Grande}}=20.
  \]
- Disponibilità \(a_v\):
  \[
  a_{\text{Piccolo}}=10,\quad a_{\text{Medio}}=9,\quad a_{\text{Grande}}=6.
  \]
- Emissioni per viaggio \(e_v\):
  \[
  e_{\text{Piccolo}}=5,\quad e_{\text{Medio}}=8,\quad e_{\text{Grande}}=11.
  \]
- Limite totale di emissioni:
  \[
  E^{\max}=145.
  \]
- Costo \(c_{vr}\) di un viaggio:
  \[
  \begin{array}{c|rrrr}
   & \mathrm{R1} & \mathrm{R2} & \mathrm{R3} & \mathrm{R4}\\ \hline
  \text{Piccolo} &45&52&40&60\\
  \text{Medio}   &62&68&58&77\\
  \text{Grande}  &82&88&79&96
  \end{array}
  \]

### Variabili decisionali
- \(x_{vr}\in\mathbb Z_+\): numero di viaggi del tipo \(v\) assegnati alla rotta \(r\).
- \(y_{vr}\in\{0,1\}\): vale 1 se il tipo \(v\) è utilizzato sulla rotta \(r\), 0 altrimenti.

---

## 2. Formulazione matematica completa

### Funzione obiettivo
\[
\min \quad \sum_{v\in V}\sum_{r\in R} c_{vr}x_{vr}.
\]

### Copertura della domanda
\[
\sum_{v\in V}q_vx_{vr}\ge d_r
\qquad \forall r\in R.
\]

### Disponibilità condivisa della flotta
\[
\sum_{r\in R}x_{vr}\le a_v
\qquad \forall v\in V.
\]

### Collegamento tra assegnazione e utilizzo del tipo
\[
x_{vr}\le a_vy_{vr}
\qquad \forall v\in V,\ r\in R,
\]
\[
x_{vr}\ge y_{vr}
\qquad \forall v\in V,\ r\in R.
\]

### Massimo due tipi di veicolo per rotta
\[
\sum_{v\in V}y_{vr}\le 2
\qquad \forall r\in R.
\]

### Presenza di almeno un veicolo grande sulla rotta R4
\[
x_{\text{Grande},\mathrm{R4}}\ge 1.
\]

### Limite totale di emissioni
\[
\sum_{v\in V}\sum_{r\in R}e_vx_{vr}\le 145.
\]

### Dominio
\[
x_{vr}\in\mathbb Z_+,\qquad
y_{vr}\in\{0,1\}
\qquad \forall v\in V,\ r\in R.
\]

---

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

veicoli = ["Piccolo", "Medio", "Grande"]
rotte = ["R1", "R2", "R3", "R4"]

domanda = {
    "R1": 42,
    "R2": 55,
    "R3": 38,
    "R4": 64
}

capacita = {
    "Piccolo": 8,
    "Medio": 14,
    "Grande": 20
}

disponibilita = {
    "Piccolo": 10,
    "Medio": 9,
    "Grande": 6
}

emissioni = {
    "Piccolo": 5,
    "Medio": 8,
    "Grande": 11
}

costi = {
    ("Piccolo", "R1"): 45,
    ("Piccolo", "R2"): 52,
    ("Piccolo", "R3"): 40,
    ("Piccolo", "R4"): 60,
    ("Medio", "R1"): 62,
    ("Medio", "R2"): 68,
    ("Medio", "R3"): 58,
    ("Medio", "R4"): 77,
    ("Grande", "R1"): 82,
    ("Grande", "R2"): 88,
    ("Grande", "R3"): 79,
    ("Grande", "R4"): 96
}

limite_emissioni = 145

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("H04_allocazione_flotta", env=env)
model.Params.MIPGap = 0.0

x = model.addVars(
    veicoli,
    rotte,
    vtype=GRB.INTEGER,
    lb=0,
    name="x"
)

y = model.addVars(
    veicoli,
    rotte,
    vtype=GRB.BINARY,
    name="y"
)

model.setObjective(
    gp.quicksum(costi[v, r] * x[v, r] for v in veicoli for r in rotte),
    GRB.MINIMIZE
)

for r in rotte:
    model.addConstr(
        gp.quicksum(capacita[v] * x[v, r] for v in veicoli) >= domanda[r],
        name="domanda_" + r
    )

for v in veicoli:
    model.addConstr(
        gp.quicksum(x[v, r] for r in rotte) <= disponibilita[v],
        name="disponibilita_" + v
    )

for v in veicoli:
    for r in rotte:
        model.addConstr(
            x[v, r] <= disponibilita[v] * y[v, r],
            name="link_superiore_" + v + "_" + r
        )
        model.addConstr(
            x[v, r] >= y[v, r],
            name="link_inferiore_" + v + "_" + r
        )

for r in rotte:
    model.addConstr(
        gp.quicksum(y[v, r] for v in veicoli) <= 2,
        name="massimo_due_tipi_" + r
    )

model.addConstr(
    x["Grande", "R4"] >= 1,
    name="grande_obbligatorio_R4"
)

model.addConstr(
    gp.quicksum(
        emissioni[v] * x[v, r]
        for v in veicoli
        for r in rotte
    ) <= limite_emissioni,
    name="limite_emissioni"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, "STATUS_" + str(model.Status))

if model.Status == GRB.OPTIMAL:
    valori = {}
    for v in veicoli:
        for r in rotte:
            valori[x[v, r].VarName] = float(round(x[v, r].X))
    for v in veicoli:
        for r in rotte:
            valori[y[v, r].VarName] = float(round(y[v, r].X))

    risultato = {
        "status": status,
        "objective": float(round(model.ObjVal, 10)),
        "variables": valori
    }
else:
    risultato = {
        "status": status,
        "objective": None,
        "variables": {}
    }

model.dispose()
env.dispose()

print("SOLUTION_JSON=" + json.dumps(risultato, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Il solver restituisce lo stato **OPTIMAL** e un costo minimo pari a:

\[
z^*=962.
\]

Le decisioni non nulle sono:

\[
x_{\text{Medio},\mathrm{R1}}=3,\qquad
x_{\text{Medio},\mathrm{R2}}=4,
\]
\[
x_{\text{Grande},\mathrm{R3}}=2,\qquad
x_{\text{Medio},\mathrm{R4}}=2,\qquad
x_{\text{Grande},\mathrm{R4}}=2.
\]

I corrispondenti \(y_{vr}\) valgono 1; tutti gli altri \(x_{vr}\) e \(y_{vr}\) valgono 0. Le emissioni totali sono \(116\), inferiori al limite di \(145\).
