## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Rotte:
  \[
  R=\{\mathrm{R1},\mathrm{R2},\mathrm{R3},\mathrm{R4}\}.
  \]
- Tipi di veicolo:
  \[
  V=\{\mathrm{Piccolo},\mathrm{Medio},\mathrm{Grande}\}.
  \]

### Parametri

- Domanda della rotta \(r\), \(d_r\):
  \[
  (d_{\mathrm{R1}},d_{\mathrm{R2}},d_{\mathrm{R3}},d_{\mathrm{R4}})
  =(42,55,38,64).
  \]

- Capacità per viaggio \(q_v\):
  \[
  q_{\mathrm{Piccolo}}=8,\quad
  q_{\mathrm{Medio}}=14,\quad
  q_{\mathrm{Grande}}=20.
  \]

- Disponibilità complessiva \(A_v\):
  \[
  A_{\mathrm{Piccolo}}=10,\quad
  A_{\mathrm{Medio}}=9,\quad
  A_{\mathrm{Grande}}=6.
  \]

- Emissioni per viaggio \(e_v\):
  \[
  e_{\mathrm{Piccolo}}=5,\quad
  e_{\mathrm{Medio}}=8,\quad
  e_{\mathrm{Grande}}=11.
  \]

- Costo \(c_{vr}\) di un viaggio del tipo \(v\) sulla rotta \(r\), come indicato nella tabella della traccia.

- Limite complessivo di emissioni:
  \[
  E^{\max}=145.
  \]

- Numero massimo di tipi utilizzabili su ogni rotta:
  \[
  K=2.
  \]

### Variabili decisionali

- \(x_{vr}\in\mathbb Z_+\): numero di viaggi del tipo \(v\) assegnati alla rotta \(r\).
- \(y_{vr}\in\{0,1\}\): vale 1 se il tipo \(v\) è utilizzato sulla rotta \(r\), 0 altrimenti.

Nel codice, ad esempio, \(x_{\mathrm{Medio},\mathrm{R1}}\) è denominata `x[Medio,R1]`.

---

## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzare il costo totale dei viaggi:

\[
\min \quad
\sum_{v\in V}\sum_{r\in R} c_{vr}x_{vr}.
\]

### Copertura della domanda

Per ogni rotta, la capacità assegnata deve coprire la domanda:

\[
\sum_{v\in V}q_vx_{vr}\ge d_r
\qquad \forall r\in R.
\]

### Disponibilità condivisa della flotta

\[
\sum_{r\in R}x_{vr}\le A_v
\qquad \forall v\in V.
\]

### Collegamento tra viaggi e utilizzo del tipo

\[
y_{vr}\le x_{vr}\le A_vy_{vr}
\qquad \forall v\in V,\;r\in R.
\]

Questi vincoli impongono \(y_{vr}=1\) se e solo se viene effettuato almeno un viaggio del tipo \(v\) sulla rotta \(r\).

### Massimo due tipi per rotta

\[
\sum_{v\in V}y_{vr}\le 2
\qquad \forall r\in R.
\]

### Presenza di almeno un veicolo grande sulla rotta R4

\[
x_{\mathrm{Grande},\mathrm{R4}}\ge 1.
\]

### Limite complessivo di emissioni

\[
\sum_{v\in V}\sum_{r\in R}e_vx_{vr}\le 145.
\]

### Dominio

\[
x_{vr}\in\mathbb Z_+,
\qquad
y_{vr}\in\{0,1\}
\qquad \forall v\in V,\;r\in R.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

V = ["Piccolo", "Medio", "Grande"]
R = ["R1", "R2", "R3", "R4"]

demand = {
    "R1": 42,
    "R2": 55,
    "R3": 38,
    "R4": 64
}

capacity = {
    "Piccolo": 8,
    "Medio": 14,
    "Grande": 20
}

availability = {
    "Piccolo": 10,
    "Medio": 9,
    "Grande": 6
}

emission = {
    "Piccolo": 5,
    "Medio": 8,
    "Grande": 11
}

cost = {
    ("Piccolo", "R1"): 45,
    ("Medio", "R1"): 62,
    ("Grande", "R1"): 82,
    ("Piccolo", "R2"): 52,
    ("Medio", "R2"): 68,
    ("Grande", "R2"): 88,
    ("Piccolo", "R3"): 40,
    ("Medio", "R3"): 58,
    ("Grande", "R3"): 79,
    ("Piccolo", "R4"): 60,
    ("Medio", "R4"): 77,
    ("Grande", "R4"): 96
}

emission_limit = 145
max_types_per_route = 2

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("Allocazione_flotta", env=env)

x = model.addVars(V, R, vtype=GRB.INTEGER, lb=0, name="x")
y = model.addVars(V, R, vtype=GRB.BINARY, name="y")

model.setObjective(
    gp.quicksum(cost[v, r] * x[v, r] for v in V for r in R),
    GRB.MINIMIZE
)

model.addConstrs(
    (
        gp.quicksum(capacity[v] * x[v, r] for v in V) >= demand[r]
        for r in R
    ),
    name="copertura_domanda"
)

model.addConstrs(
    (
        gp.quicksum(x[v, r] for r in R) <= availability[v]
        for v in V
    ),
    name="disponibilita"
)

model.addConstrs(
    (
        x[v, r] <= availability[v] * y[v, r]
        for v in V for r in R
    ),
    name="attivazione_superiore"
)

model.addConstrs(
    (
        x[v, r] >= y[v, r]
        for v in V for r in R
    ),
    name="attivazione_inferiore"
)

model.addConstrs(
    (
        gp.quicksum(y[v, r] for v in V) <= max_types_per_route
        for r in R
    ),
    name="massimo_due_tipi"
)

model.addConstr(
    x["Grande", "R4"] >= 1,
    name="grande_su_R4"
)

model.addConstr(
    gp.quicksum(
        emission[v] * x[v, r]
        for v in V for r in R
    ) <= emission_limit,
    name="limite_emissioni"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status_code = int(model.Status)
status = status_names.get(status_code, "STATUS_" + str(status_code))

if status_code == GRB.OPTIMAL:
    variables = {}
    for v in V:
        for r in R:
            variables[x[v, r].VarName] = float(round(x[v, r].X))
    for v in V:
        for r in R:
            variables[y[v, r].VarName] = float(round(y[v, r].X))

    payload = {
        "status": "OPTIMAL",
        "objective": float(round(model.ObjVal, 10)),
        "variables": variables
    }
else:
    payload = {
        "status": status,
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(payload, separators=(",", ":")))
```

## 4. Breve sintesi della soluzione

Lo stato è **OPTIMAL** e il costo minimo è:

\[
z^*=962.
\]

Le decisioni non nulle sono:

\[
x_{\mathrm{Medio},\mathrm{R1}}=3,\qquad
x_{\mathrm{Medio},\mathrm{R2}}=4,
\]
\[
x_{\mathrm{Grande},\mathrm{R3}}=2,\qquad
x_{\mathrm{Medio},\mathrm{R4}}=2,\qquad
x_{\mathrm{Grande},\mathrm{R4}}=2.
\]

Le corrispondenti variabili \(y_{vr}\) valgono 1. Sono utilizzati complessivamente 9 viaggi medi e 4 grandi, con emissioni totali pari a:

\[
9\cdot 8+4\cdot 11=116\le145.
\]

Le capacità assegnate a R1, R2, R3 e R4 sono rispettivamente \(42,56,40,68\), quindi tutte le domande sono coperte.
