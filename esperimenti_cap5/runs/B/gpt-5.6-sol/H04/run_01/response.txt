## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Rotte:
  \[
  R=\{\mathrm{R1},\mathrm{R2},\mathrm{R3},\mathrm{R4}\}.
  \]
- Tipi di veicolo:
  \[
  T=\{\mathrm{Piccolo},\mathrm{Medio},\mathrm{Grande}\}.
  \]

### Parametri

- Domanda \(d_r\):
  \[
  d=(42,55,38,64).
  \]
- Capacità per viaggio \(q_t\):
  \[
  q_{\mathrm{Piccolo}}=8,\quad
  q_{\mathrm{Medio}}=14,\quad
  q_{\mathrm{Grande}}=20.
  \]
- Disponibilità complessiva \(a_t\):
  \[
  a_{\mathrm{Piccolo}}=10,\quad
  a_{\mathrm{Medio}}=9,\quad
  a_{\mathrm{Grande}}=6.
  \]
- Emissioni per viaggio \(e_t\):
  \[
  e_{\mathrm{Piccolo}}=5,\quad
  e_{\mathrm{Medio}}=8,\quad
  e_{\mathrm{Grande}}=11.
  \]
- Limite totale di emissioni:
  \[
  E^{\max}=145.
  \]
- Costo \(c_{rt}\) di un viaggio del tipo \(t\) sulla rotta \(r\):

  \[
  \begin{array}{c|ccc}
  &\mathrm{Piccolo}&\mathrm{Medio}&\mathrm{Grande}\\ \hline
  \mathrm{R1}&45&62&82\\
  \mathrm{R2}&52&68&88\\
  \mathrm{R3}&40&58&79\\
  \mathrm{R4}&60&77&96
  \end{array}
  \]

### Variabili decisionali

- \(x_{rt}\in\mathbb Z_+\): numero di viaggi del tipo \(t\) assegnati alla rotta \(r\).
- \(y_{rt}\in\{0,1\}\): vale 1 se il tipo \(t\) è utilizzato sulla rotta \(r\), 0 altrimenti.

Nel codice le variabili sono denominate `x_rotta_tipo` e `y_rotta_tipo`.

## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzare il costo complessivo:

\[
\min \quad
\sum_{r\in R}\sum_{t\in T} c_{rt}x_{rt}.
\]

### Copertura della domanda

Per ogni rotta, la capacità assegnata deve coprire la domanda:

\[
\sum_{t\in T} q_t x_{rt}\ge d_r
\qquad \forall r\in R.
\]

### Disponibilità condivisa della flotta

\[
\sum_{r\in R}x_{rt}\le a_t
\qquad \forall t\in T.
\]

### Collegamento tra assegnazione e utilizzo del tipo

\[
x_{rt}\le a_t y_{rt}
\qquad \forall r\in R,\ t\in T,
\]

\[
x_{rt}\ge y_{rt}
\qquad \forall r\in R,\ t\in T.
\]

Questi vincoli impongono \(y_{rt}=1\) se e solo se è assegnato almeno un viaggio del tipo \(t\) alla rotta \(r\).

### Al massimo due tipi per rotta

\[
\sum_{t\in T}y_{rt}\le 2
\qquad \forall r\in R.
\]

### Presenza di almeno un veicolo grande su R4

\[
x_{\mathrm{R4},\mathrm{Grande}}\ge 1.
\]

### Limite sulle emissioni

\[
\sum_{r\in R}\sum_{t\in T}e_t x_{rt}\le 145.
\]

### Dominio

\[
x_{rt}\in\mathbb Z_+,\qquad
y_{rt}\in\{0,1\}
\qquad \forall r\in R,\ t\in T.
\]

## 3. Codice Python con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

routes = ["R1", "R2", "R3", "R4"]
types = ["Piccolo", "Medio", "Grande"]

demand = {
    "R1": 42,
    "R2": 55,
    "R3": 38,
    "R4": 64
}

capacity = {
    "Piccolo": 8,
    "Medio": 14,
    "Grande": 20
}

availability = {
    "Piccolo": 10,
    "Medio": 9,
    "Grande": 6
}

emissions = {
    "Piccolo": 5,
    "Medio": 8,
    "Grande": 11
}

cost = {
    ("R1", "Piccolo"): 45,
    ("R1", "Medio"): 62,
    ("R1", "Grande"): 82,
    ("R2", "Piccolo"): 52,
    ("R2", "Medio"): 68,
    ("R2", "Grande"): 88,
    ("R3", "Piccolo"): 40,
    ("R3", "Medio"): 58,
    ("R3", "Grande"): 79,
    ("R4", "Piccolo"): 60,
    ("R4", "Medio"): 77,
    ("R4", "Grande"): 96
}

emission_limit = 145

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("H04_allocazione_flotta", env=env)

x = {}
y = {}

for r in routes:
    for t in types:
        x[r, t] = model.addVar(
            lb=0,
            vtype=GRB.INTEGER,
            name=f"x_{r}_{t}"
        )
        y[r, t] = model.addVar(
            vtype=GRB.BINARY,
            name=f"y_{r}_{t}"
        )

model.setObjective(
    gp.quicksum(cost[r, t] * x[r, t] for r in routes for t in types),
    GRB.MINIMIZE
)

for r in routes:
    model.addConstr(
        gp.quicksum(capacity[t] * x[r, t] for t in types) >= demand[r],
        name=f"domanda_{r}"
    )

for t in types:
    model.addConstr(
        gp.quicksum(x[r, t] for r in routes) <= availability[t],
        name=f"disponibilita_{t}"
    )

for r in routes:
    for t in types:
        model.addConstr(
            x[r, t] <= availability[t] * y[r, t],
            name=f"link_superiore_{r}_{t}"
        )
        model.addConstr(
            x[r, t] >= y[r, t],
            name=f"link_inferiore_{r}_{t}"
        )

for r in routes:
    model.addConstr(
        gp.quicksum(y[r, t] for t in types) <= 2,
        name=f"massimo_due_tipi_{r}"
    )

model.addConstr(
    x["R4", "Grande"] >= 1,
    name="grande_obbligatorio_R4"
)

model.addConstr(
    gp.quicksum(
        emissions[t] * x[r, t]
        for r in routes
        for t in types
    ) <= emission_limit,
    name="limite_emissioni"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, f"STATUS_{model.Status}")

if model.Status == GRB.OPTIMAL:
    variable_values = {}

    for r in routes:
        for t in types:
            variable_values[f"x_{r}_{t}"] = float(round(x[r, t].X))

    for r in routes:
        for t in types:
            variable_values[f"y_{r}_{t}"] = float(round(y[r, t].X))

    result = {
        "status": status,
        "objective": float(round(model.ObjVal, 10)),
        "variables": variable_values
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {}
    }

model.dispose()
env.dispose()

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Il modello restituisce stato **OPTIMAL** e costo minimo:

\[
z^*=962.
\]

Viaggi non nulli:

- \(x_{\mathrm{R1},\mathrm{Medio}}=3\);
- \(x_{\mathrm{R2},\mathrm{Medio}}=4\);
- \(x_{\mathrm{R3},\mathrm{Grande}}=2\);
- \(x_{\mathrm{R4},\mathrm{Medio}}=2\);
- \(x_{\mathrm{R4},\mathrm{Grande}}=2\).

Le corrispondenti variabili \(y\) valgono 1; tutte le altre variabili valgono 0. Sono impiegati complessivamente 9 viaggi medi e 4 grandi. Le emissioni totali sono:

\[
9\cdot 8+4\cdot 11=116\le145.
\]
