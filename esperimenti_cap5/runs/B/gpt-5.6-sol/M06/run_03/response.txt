## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Lavori:
  \[
  J=\{\mathrm{J1},\mathrm{J2},\mathrm{J3},\mathrm{J4},\mathrm{J5},\mathrm{J6},\mathrm{J7}\}.
  \]

- Macchine:
  \[
  M=\{\mathrm{A},\mathrm{B}\}.
  \]

- Coppie lavoro-macchina compatibili:
  \[
  \mathcal C=(J\times M)\setminus\{(\mathrm{J7},\mathrm{A})\}.
  \]

### Parametri

Per ogni \((j,m)\in\mathcal C\), \(p_{jm}\) è il tempo di lavorazione:

\[
\begin{array}{c|cc}
 & A & B\\ \hline
J1&7&9\\
J2&6&5\\
J3&8&7\\
J4&5&8\\
J5&9&6\\
J6&4&7\\
J7&-&5
\end{array}
\]

### Variabili decisionali

- \(x_{jm}\in\{0,1\}\), per \(j\in J\), \(m\in M\):
  \[
  x_{jm}=
  \begin{cases}
  1 & \text{se il lavoro }j\text{ è assegnato alla macchina }m,\\
  0 & \text{altrimenti.}
  \end{cases}
  \]

  Nel codice la variabile è denominata `x_j_m`.

- \(C_{\max}\ge 0\): makespan, denominato `C_max` nel codice.

L’ordine dei lavori su ciascuna macchina non deve essere modellato: poiché tutti i lavori sono disponibili all’inizio e non vi sono altri vincoli di sequenziamento, il tempo di completamento di una macchina coincide con il suo carico totale.

## 2. Formulazione matematica completa

\[
\min \quad C_{\max}
\]

soggetto a:

### Assegnazione univoca

\[
\sum_{m\in M}x_{jm}=1
\qquad \forall j\in J.
\]

### Incompatibilità di J7 con la macchina A

\[
x_{\mathrm{J7},\mathrm{A}}=0.
\]

### Definizione del makespan

\[
\sum_{j:(j,m)\in\mathcal C}p_{jm}x_{jm}\le C_{\max}
\qquad \forall m\in M.
\]

Esplicitamente:

\[
7x_{\mathrm{J1},A}
+6x_{\mathrm{J2},A}
+8x_{\mathrm{J3},A}
+5x_{\mathrm{J4},A}
+9x_{\mathrm{J5},A}
+4x_{\mathrm{J6},A}
\le C_{\max},
\]

\[
9x_{\mathrm{J1},B}
+5x_{\mathrm{J2},B}
+7x_{\mathrm{J3},B}
+8x_{\mathrm{J4},B}
+6x_{\mathrm{J5},B}
+7x_{\mathrm{J6},B}
+5x_{\mathrm{J7},B}
\le C_{\max}.
\]

### Domini

\[
x_{jm}\in\{0,1\}
\qquad \forall j\in J,\ m\in M,
\]

\[
C_{\max}\in\mathbb R_{\ge 0}.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

jobs = ["J1", "J2", "J3", "J4", "J5", "J6", "J7"]
machines = ["A", "B"]

processing_time = {
    ("J1", "A"): 7, ("J1", "B"): 9,
    ("J2", "A"): 6, ("J2", "B"): 5,
    ("J3", "A"): 8, ("J3", "B"): 7,
    ("J4", "A"): 5, ("J4", "B"): 8,
    ("J5", "A"): 9, ("J5", "B"): 6,
    ("J6", "A"): 4, ("J6", "B"): 7,
    ("J7", "B"): 5
}

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("M06_bilanciamento_due_macchine", env=env)
model.Params.OutputFlag = 0

x = {
    (j, m): model.addVar(vtype=GRB.BINARY, name=f"x_{j}_{m}")
    for j in jobs
    for m in machines
}
C_max = model.addVar(lb=0.0, vtype=GRB.CONTINUOUS, name="C_max")

model.setObjective(C_max, GRB.MINIMIZE)

for j in jobs:
    model.addConstr(
        gp.quicksum(x[j, m] for m in machines) == 1,
        name=f"assegnazione_{j}"
    )

model.addConstr(x["J7", "A"] == 0, name="incompatibilita_J7_A")

for m in machines:
    model.addConstr(
        gp.quicksum(
            processing_time[j, m] * x[j, m]
            for j in jobs
            if (j, m) in processing_time
        ) <= C_max,
        name=f"makespan_{m}"
    )

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

solver_status = status_names.get(int(model.Status), f"STATUS_{int(model.Status)}")

def clean_value(value):
    value = float(value)
    if abs(value) < 1e-9:
        return 0.0
    if abs(value - round(value)) < 1e-9:
        return float(round(value))
    return value

if model.Status == GRB.OPTIMAL:
    variable_values = {}
    for j in jobs:
        for m in machines:
            variable_values[f"x_{j}_{m}"] = clean_value(x[j, m].X)
    variable_values["C_max"] = clean_value(C_max.X)

    result = {
        "status": solver_status,
        "objective": clean_value(model.ObjVal),
        "variables": variable_values
    }
else:
    result = {
        "status": solver_status,
        "objective": None,
        "variables": {}
    }

model.dispose()
env.dispose()

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Lo stato è **OPTIMAL** e il makespan minimo è:

\[
C_{\max}^*=22.
\]

Decisioni non nulle:

\[
x_{\mathrm{J1},A}
=x_{\mathrm{J2},A}
=x_{\mathrm{J4},A}
=x_{\mathrm{J6},A}=1,
\]

\[
x_{\mathrm{J3},B}
=x_{\mathrm{J5},B}
=x_{\mathrm{J7},B}=1.
\]

I carichi risultano:

\[
L_A=7+6+5+4=22,
\qquad
L_B=7+6+5=18.
\]

La soluzione è ottima: per ottenere un makespan inferiore a 22 sarebbe necessario assegnare almeno quattro lavori tra J1–J6 alla macchina A, ma i quattro tempi più piccoli su A sommano già a \(4+5+6+7=22\).
