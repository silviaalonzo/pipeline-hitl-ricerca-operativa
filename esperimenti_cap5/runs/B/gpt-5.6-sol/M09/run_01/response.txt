## 1. Insiemi, parametri e variabili decisionali

### Insiemi
- \(T=\{1,2,3,4,5,6\}\): insieme dei periodi.

### Parametri
- \(d_t\): domanda nel periodo \(t\):
  \[
  (d_1,\ldots,d_6)=(20,30,15,35,25,20).
  \]
- \(c_t\): costo unitario di acquisto:
  \[
  (c_1,\ldots,c_6)=(9,8,11,7,10,9).
  \]
- \(U_t\): capacità massima dell’ordine:
  \[
  (U_1,\ldots,U_6)=(50,50,45,55,45,50).
  \]
- \(I_0=10\): scorta iniziale.
- \(I^{\min}=5\): scorta finale minima.
- \(L=10\): quantità minima di un ordine attivato.
- \(F=40\): costo fisso di attivazione di un ordine.
- \(h=2\): costo unitario di mantenimento per periodo.

### Variabili decisionali
Per ogni \(t\in T\):

- \(q_t\in\mathbb Z_+\): quantità ordinata nel periodo \(t\);
- \(I_t\in\mathbb Z_+\): scorta alla fine del periodo \(t\);
- \(y_t\in\{0,1\}\): vale 1 se viene attivato un ordine nel periodo \(t\), 0 altrimenti.

Nel codice le variabili sono denominate `q_t`, `I_t` e `y_t`, con \(t=1,\ldots,6\).

## 2. Formulazione matematica completa

La funzione obiettivo minimizza costi di acquisto, costi fissi degli ordini e costi di mantenimento:

\[
\min z=
\sum_{t\in T}
\left(c_tq_t+Fy_t+hI_t\right).
\]

Vincoli di bilancio delle scorte:

\[
I_t=I_{t-1}+q_t-d_t
\qquad \forall t\in T,
\]

dove \(I_0=10\).

Collegamento tra quantità ordinata e attivazione dell’ordine:

\[
q_t\ge Ly_t
\qquad \forall t\in T,
\]

\[
q_t\le U_ty_t
\qquad \forall t\in T.
\]

Scorta finale minima:

\[
I_6\ge 5.
\]

Domini:

\[
q_t\in\mathbb Z_+,\qquad
I_t\in\mathbb Z_+,\qquad
y_t\in\{0,1\}
\qquad \forall t\in T.
\]

La non negatività di \(I_t\) impedisce implicitamente gli arretrati.

## 3. Codice Python con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

T = range(1, 7)

demand = {
    1: 20,
    2: 30,
    3: 15,
    4: 35,
    5: 25,
    6: 20
}

purchase_cost = {
    1: 9,
    2: 8,
    3: 11,
    4: 7,
    5: 10,
    6: 9
}

capacity = {
    1: 50,
    2: 50,
    3: 45,
    4: 55,
    5: 45,
    6: 50
}

initial_inventory = 10
minimum_final_inventory = 5
minimum_order = 10
fixed_order_cost = 40
holding_cost = 2

model = gp.Model("M09_piano_riordino")
model.Params.OutputFlag = 0

q = {
    t: model.addVar(
        lb=0,
        vtype=GRB.INTEGER,
        name=f"q_{t}"
    )
    for t in T
}

I = {
    t: model.addVar(
        lb=0,
        vtype=GRB.INTEGER,
        name=f"I_{t}"
    )
    for t in T
}

y = {
    t: model.addVar(
        vtype=GRB.BINARY,
        name=f"y_{t}"
    )
    for t in T
}

model.setObjective(
    gp.quicksum(
        purchase_cost[t] * q[t]
        + fixed_order_cost * y[t]
        + holding_cost * I[t]
        for t in T
    ),
    GRB.MINIMIZE
)

for t in T:
    previous_inventory = initial_inventory if t == 1 else I[t - 1]
    model.addConstr(
        I[t] == previous_inventory + q[t] - demand[t],
        name=f"balance_{t}"
    )
    model.addConstr(
        q[t] >= minimum_order * y[t],
        name=f"minimum_order_{t}"
    )
    model.addConstr(
        q[t] <= capacity[t] * y[t],
        name=f"capacity_{t}"
    )

model.addConstr(
    I[6] >= minimum_final_inventory,
    name="minimum_final_inventory"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, f"STATUS_{model.Status}")

if model.Status == GRB.OPTIMAL:
    variables = {}
    for variable_group in (q, I, y):
        for t in T:
            value = variable_group[t].X
            rounded_value = round(value)
            variables[variable_group[t].VarName] = (
                float(rounded_value)
                if abs(value - rounded_value) <= 1e-6
                else float(value)
            )

    objective_value = float(round(model.ObjVal, 10))
    result = {
        "status": status,
        "objective": objective_value,
        "variables": variables
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Breve sintesi della soluzione

Lo stato è **OPTIMAL** e il costo minimo è:

\[
z^*=1370.
\]

Le decisioni non nulle sono:

- ordini: \(q_1=10,\ q_2=50,\ q_4=55,\ q_6=25\);
- attivazioni: \(y_1=y_2=y_4=y_6=1\);
- scorte: \(I_2=20,\ I_3=5,\ I_4=25,\ I_6=5\).

Il costo è composto da 1100 di acquisto, 160 di costi fissi e 110 di mantenimento.
