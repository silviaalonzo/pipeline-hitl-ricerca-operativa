### Variabili decisionali

Per ogni \(i\in P\):

\[

\begin{cases}

\[

## 2. Formulazione matematica completa

### Funzione obiettivo

\[
\max\quad
\sum_{i\in P} v_i x_i+12y_{AC}+10y_{EK}.
\]

### Budget annuali

\[
\sum_{i\in P}c_{i1}x_i\leq 110,
\]

\[
\sum_{i\in P}c_{i2}x_i\leq 100,
\]

\[
\sum_{i\in P}c_{i3}x_i\leq 90.
\]

### Personale e rischio

\[
\sum_{i\in P}p_i x_i\leq 28,
\]

\[
\sum_{i\in P}r_i x_i\leq 32.
\]

### Requisiti tra progetti

\[
x_G\leq x_B,
\]

\[
x_J\leq x_E,
\]

\[
x_K\leq x_C.
\]

### Incompatibilità

\[
x_D+x_H\leq 1,
\]

\[
x_F+x_L\leq 1.
\]

### Requisiti strategici

Almeno due progetti digitali:

\[
x_A+x_C+x_G+x_J\geq 2.
\]

Almeno un progetto sostenibile:

\[
x_E+x_H+x_K\geq 1.
\]

Al massimo otto progetti:

\[
\sum_{i\in P}x_i\leq 8.
\]

### Linearizzazione delle sinergie

Per la coppia \(A-C\):

\[
y_{AC}\leq x_A,
\qquad
y_{AC}\leq x_C,
\qquad
y_{AC}\geq x_A+x_C-1.
\]

Per la coppia \(E-K\):

\[
y_{EK}\leq x_E,
\qquad
y_{EK}\leq x_K,
\qquad
y_{EK}\geq x_E+x_K-1.
\]

### Dominio

\[
x_i\in\{0,1\}\quad\forall i\in P,
\]

\[
y_{AC},y_{EK}\in\{0,1\}.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

P = ["A", "B", "C", "D", "E", "F", "G", "H", "I", "J", "K", "L"]
T = [1, 2, 3]

van = {
    "A": 42, "B": 35, "C": 48, "D": 31,
    "E": 40, "F": 28, "G": 55, "H": 37,
    "I": 33, "J": 50, "K": 46, "L": 29
}

cost = {
    "A": {1: 18, 2: 12, 3: 10},
    "B": {1: 20, 2: 18, 3: 14},
    "C": {1: 25, 2: 20, 3: 18},
    "D": {1: 15, 2: 14, 3: 12},
    "E": {1: 22, 2: 16, 3: 15},
    "F": {1: 14, 2: 12, 3: 10},
    "G": {1: 30, 2: 25, 3: 22},
    "H": {1: 20, 2: 18, 3: 16},
    "I": {1: 17, 2: 15, 3: 12},
    "J": {1: 27, 2: 21, 3: 18},
    "K": {1: 24, 2: 19, 3: 17},
    "L": {1: 16, 2: 13, 3: 11}
}

personnel = {
    "A": 4, "B": 4, "C": 5, "D": 3,
    "E": 4, "F": 3, "G": 6, "H": 4,
    "I": 3, "J": 5, "K": 5, "L": 3
}

risk = {
    "A": 5, "B": 4, "C": 6, "D": 3,
    "E": 4, "F": 2, "G": 7, "H": 5,
    "I": 3, "J": 6, "K": 5, "L": 3
}

budget = {1: 110, 2: 100, 3: 90}
digital = ["A", "C", "G", "J"]
sustainable = ["E", "H", "K"]
requirements = [("G", "B"), ("J", "E"), ("K", "C")]
incompatibilities = [("D", "H"), ("F", "L")]
synergies = {("A", "C"): 12, ("E", "K"): 10}

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("H05_portafoglio_pluriennale", env=env)

x = {
    i: model.addVar(vtype=GRB.BINARY, name="x_" + i)
    for i in P
}

y = {
    pair: model.addVar(
        vtype=GRB.BINARY,
        name="y_" + pair[0] + pair[1]
    )
    for pair in synergies
}

model.setObjective(
    gp.quicksum(van[i] * x[i] for i in P)
    + gp.quicksum(synergies[pair] * y[pair] for pair in synergies),
    GRB.MAXIMIZE
)

for t in T:
    model.addConstr(
        gp.quicksum(cost[i][t] * x[i] for i in P) <= budget[t],
        name="budget_A" + str(t)
    )

model.addConstr(
    gp.quicksum(personnel[i] * x[i] for i in P) <= 28,
    name="personale"
)

model.addConstr(
    gp.quicksum(risk[i] * x[i] for i in P) <= 32,
    name="rischio"
)

for project, prerequisite in requirements:
    model.addConstr(
        x[project] <= x[prerequisite],
        name="requisito_" + project + "_" + prerequisite
    )

for i, j in incompatibilities:
    model.addConstr(
        x[i] + x[j] <= 1,
        name="incompatibilita_" + i + "_" + j
    )

model.addConstr(
    gp.quicksum(x[i] for i in digital) >= 2,
    name="minimo_digitali"
)

model.addConstr(
    gp.quicksum(x[i] for i in sustainable) >= 1,
    name="minimo_sostenibili"
)

model.addConstr(
    gp.quicksum(x[i] for i in P) <= 8,
    name="massimo_progetti"
)

for i, j in synergies:
    model.addConstr(y[(i, j)] <= x[i], name="sinergia_up1_" + i + j)
    model.addConstr(y[(i, j)] <= x[j], name="sinergia_up2_" + i + j)
    model.addConstr(
        y[(i, j)] >= x[i] + x[j] - 1,
        name="sinergia_low_" + i + j
    )

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status_code = int(model.Status)
status_name = status_names.get(status_code, str(status_code))

if status_code == GRB.OPTIMAL:
    variables = {}
    for i in P:
        variables[x[i].VarName] = float(round(x[i].X))
    for pair in synergies:
        variables[y[pair].VarName] = float(round(y[pair].X))

    payload = {
        "status": "OPTIMAL",
        "objective": float(round(model.ObjVal, 10)),
        "variables": variables
    }
else:
    payload = {
        "status": status_name,
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(payload, separators=(",", ":")))
```

## 4. Breve sintesi della soluzione

Lo stato è **OPTIMAL** e il VAN complessivo massimo è:

\[
z^*=235.
\]

I progetti selezionati sono:

\[
A,\ C,\ E,\ H,\ K.
\]

Sono attive entrambe le sinergie:

\[
y_{AC}=1,\qquad y_{EK}=1.
\]

Il VAN base è \(213\), a cui si aggiungono \(12+10=22\) di sinergie. I consumi sono: budget \(109,85,76\), personale \(22\) e rischio \(25\).
