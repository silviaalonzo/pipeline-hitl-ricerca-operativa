## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Lavori:
  \[
  I=\{J1,J2,J3,J4,J5,J6,J7\}.
  \]
- Coppie non ordinate di lavori:
  \[
  P=\{(i,j)\in I\times I:i<j\}.
  \]
- Precedenze:
  \[
  A=\{(J1,J2),(J3,J5)\}.
  \]

### Parametri

| \(i\) | \(p_i\) durata | \(r_i\) disponibilità | \(d_i\) scadenza | \(w_i\) peso |
|---|---:|---:|---:|---:|
| J1 | 5 | 0 | 9 | 4 |
| J2 | 7 | 0 | 17 | 3 |
| J3 | 4 | 2 | 12 | 5 |
| J4 | 6 | 3 | 22 | 2 |
| J5 | 3 | 5 | 15 | 6 |
| J6 | 8 | 0 | 28 | 2 |
| J7 | 5 | 6 | 25 | 4 |

Si considera l’orizzonte:
\[
H=\max_{i\in I}r_i+\sum_{i\in I}p_i=6+38=44.
\]

Poiché la funzione obiettivo è non decrescente nei tempi di completamento, esiste una soluzione ottima senza tempi morti non necessari che termina entro \(H\). Imponendo \(C_i\le H\), la scelta
\[
M=H=44
\]
è valida: quando un vincolo di ordinamento è disattivato, il suo lato destro è al più zero, mentre tutti i tempi di inizio sono non negativi.

### Variabili decisionali

- \(S_i\ge 0\): istante di inizio del lavoro \(i\);
- \(C_i\ge 0\): istante di completamento del lavoro \(i\);
- \(T_i\ge 0\): ritardo del lavoro \(i\);
- \(y_{ij}\in\{0,1\}\), per \((i,j)\in P\):
  \[
  y_{ij}=
  \begin{cases}
  1 & \text{se }i\text{ precede }j,\\
  0 & \text{se }j\text{ precede }i.
  \end{cases}
  \]

## 2. Formulazione matematica completa

\[
\min \quad \sum_{i\in I} w_iT_i
\]

soggetto a:

### Disponibilità e completamento

\[
S_i\ge r_i \qquad \forall i\in I,
\]

\[
C_i=S_i+p_i \qquad \forall i\in I,
\]

\[
C_i\le H \qquad \forall i\in I.
\]

### Definizione del ritardo

\[
T_i\ge C_i-d_i \qquad \forall i\in I,
\]

\[
T_i\ge 0 \qquad \forall i\in I.
\]

### Non sovrapposizione

Per ogni \((i,j)\in P\):

\[
S_j\ge C_i-M(1-y_{ij}),
\]

\[
S_i\ge C_j-My_{ij}.
\]

Se \(y_{ij}=1\), il primo vincolo impone che \(i\) termini prima dell’inizio di \(j\); se \(y_{ij}=0\), il secondo impone l’ordine opposto.

### Precedenze obbligatorie

\[
C_{J1}\le S_{J2},
\]

\[
C_{J3}\le S_{J5}.
\]

Come rafforzamento equivalente:

\[
y_{J1,J2}=1,\qquad y_{J3,J5}=1.
\]

### Domini

\[
0\le S_i,\qquad 0\le C_i\le H,\qquad T_i\ge0
\qquad \forall i\in I,
\]

\[
y_{ij}\in\{0,1\}\qquad \forall(i,j)\in P.
\]

## 3. Codice Python con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

jobs = ["J1", "J2", "J3", "J4", "J5", "J6", "J7"]

p = {
    "J1": 5, "J2": 7, "J3": 4, "J4": 6,
    "J5": 3, "J6": 8, "J7": 5
}
r = {
    "J1": 0, "J2": 0, "J3": 2, "J4": 3,
    "J5": 5, "J6": 0, "J7": 6
}
d = {
    "J1": 9, "J2": 17, "J3": 12, "J4": 22,
    "J5": 15, "J6": 28, "J7": 25
}
w = {
    "J1": 4, "J2": 3, "J3": 5, "J4": 2,
    "J5": 6, "J6": 2, "J7": 4
}

precedences = [("J1", "J2"), ("J3", "J5")]
pairs = [(jobs[a], jobs[b])
         for a in range(len(jobs))
         for b in range(a + 1, len(jobs))]

H = max(r.values()) + sum(p.values())
M = H

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.setParam("LogToConsole", 0)
env.start()

model = gp.Model("H06_sequenziamento", env=env)
model.Params.OutputFlag = 0
model.Params.MIPGap = 0.0

S = model.addVars(jobs, lb=0.0, vtype=GRB.CONTINUOUS, name="S")
C = model.addVars(jobs, lb=0.0, ub=H, vtype=GRB.CONTINUOUS, name="C")
T = model.addVars(jobs, lb=0.0, vtype=GRB.CONTINUOUS, name="T")
y = model.addVars(pairs, vtype=GRB.BINARY, name="y")

model.setObjective(
    gp.quicksum(w[j] * T[j] for j in jobs),
    GRB.MINIMIZE
)

for j in jobs:
    model.addConstr(S[j] >= r[j], name="availability_" + j)
    model.addConstr(C[j] == S[j] + p[j], name="completion_" + j)
    model.addConstr(T[j] >= C[j] - d[j], name="tardiness_" + j)

for i, j in pairs:
    model.addConstr(
        S[j] >= C[i] - M * (1 - y[i, j]),
        name="order_forward_" + i + "_" + j
    )
    model.addConstr(
        S[i] >= C[j] - M * y[i, j],
        name="order_reverse_" + i + "_" + j
    )

for i, j in precedences:
    model.addConstr(C[i] <= S[j], name="precedence_" + i + "_" + j)
    model.addConstr(y[i, j] == 1, name="fix_order_" + i + "_" + j)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

def clean_number(value):
    value = float(value)
    if abs(value) <= 1e-8:
        return 0.0
    nearest_integer = round(value)
    if abs(value - nearest_integer) <= 1e-7:
        return float(nearest_integer)
    return float(round(value, 10))

status = status_names.get(model.Status, "STATUS_" + str(model.Status))

if model.Status == GRB.OPTIMAL:
    all_variables = (
        [S[j] for j in jobs]
        + [C[j] for j in jobs]
        + [T[j] for j in jobs]
        + [y[i, j] for i, j in pairs]
    )
    payload = {
        "status": "OPTIMAL",
        "objective": clean_number(model.ObjVal),
        "variables": {
            variable.VarName: clean_number(variable.X)
            for variable in all_variables
        }
    }
else:
    payload = {
        "status": status,
        "objective": None,
        "variables": {}
    }

model.dispose()
env.dispose()

print("SOLUTION_JSON=" + json.dumps(payload, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Lo stato è **OPTIMAL** e il valore ottimo è:

\[
z^*=42.
\]

La sequenza ottima è:

\[
J1\rightarrow J3\rightarrow J5\rightarrow J2\rightarrow J7
\rightarrow J4\rightarrow J6.
\]

| Lavoro | Inizio \(S_i\) | Completamento \(C_i\) | Ritardo \(T_i\) |
|---|---:|---:|---:|
| J1 | 0 | 5 | 0 |
| J3 | 5 | 9 | 0 |
| J5 | 9 | 12 | 0 |
| J2 | 12 | 19 | 2 |
| J7 | 19 | 24 | 0 |
| J4 | 24 | 30 | 8 |
| J6 | 30 | 38 | 10 |

Il costo è:

\[
3(2)+2(8)+2(10)=6+16+20=42.
\]

Le variabili binarie non nulle sono:

\[
\begin{aligned}
&y_{J1,J2},y_{J1,J3},y_{J1,J4},y_{J1,J5},y_{J1,J6},y_{J1,J7},\\
&y_{J2,J4},y_{J2,J6},y_{J2,J7},\\
&y_{J3,J4},y_{J3,J5},y_{J3,J6},y_{J3,J7},\\
&y_{J4,J6},y_{J5,J6},y_{J5,J7},
\end{aligned}
\]
tutte uguali a \(1\); le restanti variabili di ordinamento valgono \(0\).
