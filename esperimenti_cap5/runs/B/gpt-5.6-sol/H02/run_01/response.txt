## 1. Insiemi, parametri e variabili decisionali

### Insiemi

- Prodotti:  
  \[
  P=\{A,B,C\}
  \]
- Periodi:  
  \[
  T=\{1,2,3,4\}
  \]

### Parametri

- Domanda \(d_{pt}\):

\[
d=
\begin{array}{c|rrrr}
 &1&2&3&4\\ \hline
A&8&12&10&14\\
B&10&8&14&12\\
C&6&9&7&11
\end{array}
\]

- Costo unitario di produzione \(c_{pt}\):

\[
c=
\begin{array}{c|rrrr}
 &1&2&3&4\\ \hline
A&9&11&10&12\\
B&8&9&11&10\\
C&13&12&14&11
\end{array}
\]

- Costo di setup \(f_p\):
  \[
  f_A=45,\quad f_B=40,\quad f_C=50
  \]
- Costo unitario di mantenimento \(h_p\):
  \[
  h_A=2,\quad h_B=3,\quad h_C=2
  \]
- Ore necessarie per unità \(a_p\):
  \[
  a_A=2,\quad a_B=3,\quad a_C=4
  \]
- Lotto minimo \(L_p\):
  \[
  L_A=4,\quad L_B=4,\quad L_C=3
  \]
- Capacità in ore \(K_t\):
  \[
  (K_1,K_2,K_3,K_4)=(90,95,90,100)
  \]
- Scorte iniziali:
  \[
  I_{A0}=0,\quad I_{B0}=0,\quad I_{C0}=6
  \]
- Scorta totale massima:
  \[
  S=20
  \]
- Numero massimo di articoli attivati per periodo:
  \[
  R=2
  \]
- Costante Big-\(M\), definita in modo valido e rafforzato:
  \[
  M_{pt}=\min\left\{\sum_{\tau=t}^{4}d_{p\tau},
  \left\lfloor\frac{K_t}{a_p}\right\rfloor\right\}.
  \]

### Variabili decisionali

Per ogni \(p\in P\), \(t\in T\):

- \(x_{pt}\in\mathbb Z_+\): quantità prodotta del prodotto \(p\) nel periodo \(t\);
- \(I_{pt}\in\mathbb Z_+\): scorta del prodotto \(p\) alla fine del periodo \(t\);
- \(y_{pt}\in\{0,1\}\): vale 1 se il prodotto \(p\) viene attivato nel periodo \(t\).

---

## 2. Formulazione matematica completa

### Funzione obiettivo

Si minimizzano costi di produzione, setup e mantenimento delle scorte finali di periodo:

\[
\min Z=
\sum_{p\in P}\sum_{t\in T}
\left(c_{pt}x_{pt}+f_py_{pt}+h_pI_{pt}\right).
\]

### Bilanci di produzione e scorta

Per ogni prodotto e periodo:

\[
I_{p,t-1}+x_{pt}=d_{pt}+I_{pt}
\qquad \forall p\in P,\ t\in T,
\]

dove \(I_{p0}\) è la scorta iniziale assegnata.

### Capacità produttiva

\[
\sum_{p\in P}a_px_{pt}\le K_t
\qquad \forall t\in T.
\]

### Collegamento tra produzione e setup

\[
x_{pt}\le M_{pt}y_{pt}
\qquad \forall p\in P,\ t\in T,
\]

\[
x_{pt}\ge L_py_{pt}
\qquad \forall p\in P,\ t\in T.
\]

### Numero massimo di articoli attivati

\[
\sum_{p\in P}y_{pt}\le 2
\qquad \forall t\in T.
\]

### Limite sulla scorta totale

\[
\sum_{p\in P}I_{pt}\le 20
\qquad \forall t\in T.
\]

### Scorte finali nulle

\[
I_{p4}=0
\qquad \forall p\in P.
\]

### Domini

\[
x_{pt}\in\mathbb Z_+,\qquad
I_{pt}\in\mathbb Z_+,\qquad
y_{pt}\in\{0,1\}
\qquad \forall p\in P,\ t\in T.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

products = ["A", "B", "C"]
periods = ["T1", "T2", "T3", "T4"]

demand = {
    ("A", "T1"): 8,  ("A", "T2"): 12, ("A", "T3"): 10, ("A", "T4"): 14,
    ("B", "T1"): 10, ("B", "T2"): 8,  ("B", "T3"): 14, ("B", "T4"): 12,
    ("C", "T1"): 6,  ("C", "T2"): 9,  ("C", "T3"): 7,  ("C", "T4"): 11
}

production_cost = {
    ("A", "T1"): 9,  ("A", "T2"): 11, ("A", "T3"): 10, ("A", "T4"): 12,
    ("B", "T1"): 8,  ("B", "T2"): 9,  ("B", "T3"): 11, ("B", "T4"): 10,
    ("C", "T1"): 13, ("C", "T2"): 12, ("C", "T3"): 14, ("C", "T4"): 11
}

setup_cost = {"A": 45, "B": 40, "C": 50}
holding_cost = {"A": 2, "B": 3, "C": 2}
hours_per_unit = {"A": 2, "B": 3, "C": 4}
minimum_lot = {"A": 4, "B": 4, "C": 3}
capacity = {"T1": 90, "T2": 95, "T3": 90, "T4": 100}
initial_inventory = {"A": 0, "B": 0, "C": 6}
maximum_total_inventory = 20
maximum_setups = 2

big_m = {}
for p in products:
    for t_index, t in enumerate(periods):
        remaining_demand = sum(demand[p, tau] for tau in periods[t_index:])
        capacity_bound = capacity[t] // hours_per_unit[p]
        big_m[p, t] = min(remaining_demand, capacity_bound)

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("H02_produzione_multi_periodo", env=env)
model.Params.OutputFlag = 0
model.Params.MIPGap = 0.0

x = {
    (p, t): model.addVar(
        vtype=GRB.INTEGER,
        lb=0,
        name=f"x_{p}_{t}"
    )
    for p in products for t in periods
}

I = {
    (p, t): model.addVar(
        vtype=GRB.INTEGER,
        lb=0,
        name=f"I_{p}_{t}"
    )
    for p in products for t in periods
}

y = {
    (p, t): model.addVar(
        vtype=GRB.BINARY,
        name=f"y_{p}_{t}"
    )
    for p in products for t in periods
}

model.setObjective(
    gp.quicksum(
        production_cost[p, t] * x[p, t]
        + setup_cost[p] * y[p, t]
        + holding_cost[p] * I[p, t]
        for p in products for t in periods
    ),
    GRB.MINIMIZE
)

for p in products:
    for t_index, t in enumerate(periods):
        previous_inventory = (
            initial_inventory[p] if t_index == 0 else I[p, periods[t_index - 1]]
        )
        model.addConstr(
            previous_inventory + x[p, t] == demand[p, t] + I[p, t],
            name=f"balance_{p}_{t}"
        )

for t in periods:
    model.addConstr(
        gp.quicksum(hours_per_unit[p] * x[p, t] for p in products)
        <= capacity[t],
        name=f"capacity_{t}"
    )

for p in products:
    for t in periods:
        model.addConstr(
            x[p, t] <= big_m[p, t] * y[p, t],
            name=f"setup_upper_{p}_{t}"
        )
        model.addConstr(
            x[p, t] >= minimum_lot[p] * y[p, t],
            name=f"minimum_lot_{p}_{t}"
        )

for t in periods:
    model.addConstr(
        gp.quicksum(y[p, t] for p in products) <= maximum_setups,
        name=f"maximum_setups_{t}"
    )
    model.addConstr(
        gp.quicksum(I[p, t] for p in products) <= maximum_total_inventory,
        name=f"maximum_inventory_{t}"
    )

for p in products:
    model.addConstr(I[p, "T4"] == 0, name=f"final_inventory_{p}")

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

def clean_number(value):
    if abs(value) < 1e-6:
        return 0.0
    nearest_integer = round(value)
    if abs(value - nearest_integer) < 1e-6:
        return float(nearest_integer)
    return float(value)

if model.Status == GRB.OPTIMAL:
    all_variables = (
        [x[p, t] for p in products for t in periods]
        + [I[p, t] for p in products for t in periods]
        + [y[p, t] for p in products for t in periods]
    )
    result = {
        "status": "OPTIMAL",
        "objective": clean_number(model.ObjVal),
        "variables": {
            variable.VarName: clean_number(variable.X)
            for variable in all_variables
        }
    }
else:
    result = {
        "status": status_names.get(model.Status, "STATUS_" + str(model.Status)),
        "objective": None,
        "variables": {}
    }

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Lo stato è **OPTIMAL** e il costo minimo è:

\[
Z^*=1575.
\]

Le decisioni non nulle sono:

- Produzione:
  \[
  x_{A1}=20,\quad x_{A3}=24;
  \]
  \[
  x_{B1}=10,\quad x_{B2}=8,\quad x_{B3}=14,\quad x_{B4}=12;
  \]
  \[
  x_{C2}=16,\quad x_{C4}=11.
  \]

- Scorte:
  \[
  I_{A1}=12,\quad I_{C2}=7,\quad I_{A3}=14.
  \]

- Setup:
  \[
  y_{A1}=y_{A3}=1,
  \]
  \[
  y_{B1}=y_{B2}=y_{B3}=y_{B4}=1,
  \]
  \[
  y_{C2}=y_{C4}=1.
  \]

Il costo è composto da 1159 di produzione, 350 di setup e 66 di mantenimento.
