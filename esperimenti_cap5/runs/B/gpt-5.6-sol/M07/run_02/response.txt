## 1. Insiemi, parametri e variabili decisionali

### Insieme

\[
I=\{A,B,C,D\}
\]

insieme dei fornitori.

### Parametri

- Domanda totale: \(Q=180\)
- Qualità media minima: \(\bar q=92\)
- Emissioni massime: \(E^{\max}=650\)
- Numero minimo di fornitori: \(K=2\)

Per ogni \(i\in I\):

| \(i\) | \(c_i\) costo unitario | \(f_i\) costo fisso | \(u_i\) capacità | \(m_i\) ordine minimo | \(q_i\) qualità | \(e_i\) emissioni |
|---|---:|---:|---:|---:|---:|---:|
| A | 11 | 80 | 80 | 20 | 96 | 3 |
| B | 10 | 95 | 100 | 25 | 90 | 4 |
| C | 12 | 60 | 70 | 15 | 98 | 2 |
| D | 9 | 120 | 90 | 20 | 88 | 5 |

### Variabili decisionali

Per ogni \(i\in I\):

\[
x_i=\text{numero intero di unità acquistate dal fornitore }i
\]

\[
y_i=
\begin{cases}
1 & \text{se il fornitore }i\text{ è attivato},\\
0 & \text{altrimenti}.
\end{cases}
\]

Nel modello e nel codice le componenti sono denominate \(x_A,x_B,x_C,x_D\) e \(y_A,y_B,y_C,y_D\).

---

## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzare la somma dei costi variabili e dei costi fissi:

\[
\min \quad
\sum_{i\in I}\left(c_i x_i+f_i y_i\right)
\]

ossia:

\[
\min \quad
11x_A+10x_B+12x_C+9x_D
+80y_A+95y_B+60y_C+120y_D.
\]

### Vincolo di domanda

\[
\sum_{i\in I}x_i=180.
\]

### Numero minimo di fornitori

\[
\sum_{i\in I}y_i\ge 2.
\]

### Ordini minimi e capacità

Per ogni \(i\in I\):

\[
m_i y_i\le x_i\le u_i y_i.
\]

Esplicitamente:

\[
20y_A\le x_A\le80y_A,
\]

\[
25y_B\le x_B\le100y_B,
\]

\[
15y_C\le x_C\le70y_C,
\]

\[
20y_D\le x_D\le90y_D.
\]

### Qualità media minima

Poiché vengono acquistate esattamente 180 unità:

\[
\frac{\sum_{i\in I}q_i x_i}{180}\ge92,
\]

equivalentemente:

\[
96x_A+90x_B+98x_C+88x_D\ge92\cdot180.
\]

### Limite alle emissioni

\[
3x_A+4x_B+2x_C+5x_D\le650.
\]

### Dominio

\[
x_i\in\mathbb Z_{\ge0}
\qquad \forall i\in I,
\]

\[
y_i\in\{0,1\}
\qquad \forall i\in I.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

suppliers = ["A", "B", "C", "D"]

unit_cost = {"A": 11, "B": 10, "C": 12, "D": 9}
fixed_cost = {"A": 80, "B": 95, "C": 60, "D": 120}
capacity = {"A": 80, "B": 100, "C": 70, "D": 90}
minimum_order = {"A": 20, "B": 25, "C": 15, "D": 20}
quality = {"A": 96, "B": 90, "C": 98, "D": 88}
emissions = {"A": 3, "B": 4, "C": 2, "D": 5}

demand = 180
minimum_quality = 92
maximum_emissions = 650
minimum_suppliers = 2

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.start()

model = gp.Model("supplier_selection", env=env)

x = {
    i: model.addVar(vtype=GRB.INTEGER, lb=0, name=f"x_{i}")
    for i in suppliers
}
y = {
    i: model.addVar(vtype=GRB.BINARY, name=f"y_{i}")
    for i in suppliers
}

model.setObjective(
    gp.quicksum(
        unit_cost[i] * x[i] + fixed_cost[i] * y[i]
        for i in suppliers
    ),
    GRB.MINIMIZE
)

model.addConstr(
    gp.quicksum(x[i] for i in suppliers) == demand,
    name="demand"
)

model.addConstr(
    gp.quicksum(y[i] for i in suppliers) >= minimum_suppliers,
    name="minimum_number_of_suppliers"
)

for i in suppliers:
    model.addConstr(
        x[i] >= minimum_order[i] * y[i],
        name=f"minimum_order_{i}"
    )
    model.addConstr(
        x[i] <= capacity[i] * y[i],
        name=f"capacity_{i}"
    )

model.addConstr(
    gp.quicksum(quality[i] * x[i] for i in suppliers)
    >= minimum_quality * demand,
    name="minimum_weighted_quality"
)

model.addConstr(
    gp.quicksum(emissions[i] * x[i] for i in suppliers)
    <= maximum_emissions,
    name="maximum_emissions"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, f"STATUS_{model.Status}")

if model.Status == GRB.OPTIMAL:
    variable_values = {}
    for i in suppliers:
        variable_values[f"x_{i}"] = float(round(x[i].X))
    for i in suppliers:
        variable_values[f"y_{i}"] = float(round(y[i].X))

    result = {
        "status": "OPTIMAL",
        "objective": float(round(model.ObjVal, 10)),
        "variables": variable_values
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {}
    }

model.dispose()
env.dispose()

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Sintesi della soluzione

Lo stato è **OPTIMAL** e il costo minimo è:

\[
z^*=2055.
\]

La soluzione attiva i fornitori A e B:

\[
x_A=80,\qquad x_B=100,\qquad y_A=y_B=1,
\]

mentre C e D non sono utilizzati. La qualità media è \(92{,}67\) e le emissioni totali sono \(640\), quindi entrambi i requisiti sono rispettati.
