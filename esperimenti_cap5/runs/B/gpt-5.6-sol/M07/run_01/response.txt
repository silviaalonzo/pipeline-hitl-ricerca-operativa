## 1. Insiemi, parametri e variabili decisionali

### Insieme

\[
I=\{A,B,C,D\}
\]

insieme dei fornitori.

### Parametri

| \(i\) | \(c_i\) costo unitario | \(f_i\) costo fisso | \(U_i\) capacità | \(L_i\) ordine minimo | \(q_i\) qualità | \(e_i\) emissioni |
|---|---:|---:|---:|---:|---:|---:|
| A | 11 | 80 | 80 | 20 | 96 | 3 |
| B | 10 | 95 | 100 | 25 | 90 | 4 |
| C | 12 | 60 | 70 | 15 | 98 | 2 |
| D | 9 | 120 | 90 | 20 | 88 | 5 |

Ulteriori parametri:

- \(D=180\): domanda totale;
- \(\bar q=92\): qualità media minima;
- \(E^{\max}=650\): emissioni massime;
- \(K=2\): numero minimo di fornitori attivati.

### Variabili decisionali

Per ogni \(i\in I\):

\[
x_i \in \mathbb Z_+
\]

quantità ordinata dal fornitore \(i\), implementata con i nomi `x_A`, `x_B`, `x_C`, `x_D`;

\[
y_i\in\{0,1\}
\]

pari a 1 se il fornitore \(i\) è attivato, implementata con i nomi `y_A`, `y_B`, `y_C`, `y_D`.

---

## 2. Formulazione matematica completa

### Funzione obiettivo

Minimizzazione dei costi variabili e fissi:

\[
\min \quad
\sum_{i\in I} c_i x_i+\sum_{i\in I} f_i y_i
\]

ossia:

\[
\min\;
11x_A+10x_B+12x_C+9x_D
+80y_A+95y_B+60y_C+120y_D.
\]

### Soddisfacimento della domanda

\[
\sum_{i\in I}x_i=180.
\]

### Attivazione, capacità e ordine minimo

Per ogni \(i\in I\):

\[
L_i y_i\le x_i\le U_i y_i.
\]

Esplicitamente:

\[
20y_A\le x_A\le80y_A,
\]

\[
25y_B\le x_B\le100y_B,
\]

\[
15y_C\le x_C\le70y_C,
\]

\[
20y_D\le x_D\le90y_D.
\]

### Numero minimo di fornitori

\[
\sum_{i\in I}y_i\ge2.
\]

### Qualità media minima

Poiché la quantità totale è esattamente 180:

\[
\frac{\sum_{i\in I}q_i x_i}{180}\ge92,
\]

equivalentemente:

\[
96x_A+90x_B+98x_C+88x_D\ge92\cdot180.
\]

### Limite sulle emissioni

\[
3x_A+4x_B+2x_C+5x_D\le650.
\]

### Dominio

\[
x_i\in\mathbb Z_+,\qquad y_i\in\{0,1\}
\qquad \forall i\in I.
\]

## 3. Codice Python eseguibile con Gurobi

```python
import gurobipy as gp
from gurobipy import GRB
import json

suppliers = ["A", "B", "C", "D"]

unit_cost = {"A": 11, "B": 10, "C": 12, "D": 9}
fixed_cost = {"A": 80, "B": 95, "C": 60, "D": 120}
capacity = {"A": 80, "B": 100, "C": 70, "D": 90}
min_order = {"A": 20, "B": 25, "C": 15, "D": 20}
quality = {"A": 96, "B": 90, "C": 98, "D": 88}
emissions = {"A": 3, "B": 4, "C": 2, "D": 5}

demand = 180
min_quality = 92
max_emissions = 650
min_suppliers = 2

env = gp.Env(empty=True)
env.setParam("OutputFlag", 0)
env.setParam("LogToConsole", 0)
env.start()

model = gp.Model("M07_selezione_fornitori", env=env)
model.Params.OutputFlag = 0

x = {
    i: model.addVar(
        vtype=GRB.INTEGER,
        lb=0,
        ub=capacity[i],
        name=f"x_{i}"
    )
    for i in suppliers
}

y = {
    i: model.addVar(
        vtype=GRB.BINARY,
        name=f"y_{i}"
    )
    for i in suppliers
}

model.setObjective(
    gp.quicksum(unit_cost[i] * x[i] + fixed_cost[i] * y[i]
                for i in suppliers),
    GRB.MINIMIZE
)

model.addConstr(
    gp.quicksum(x[i] for i in suppliers) == demand,
    name="domanda"
)

for i in suppliers:
    model.addConstr(
        x[i] >= min_order[i] * y[i],
        name=f"ordine_minimo_{i}"
    )
    model.addConstr(
        x[i] <= capacity[i] * y[i],
        name=f"capacita_{i}"
    )

model.addConstr(
    gp.quicksum(y[i] for i in suppliers) >= min_suppliers,
    name="numero_minimo_fornitori"
)

model.addConstr(
    gp.quicksum(quality[i] * x[i] for i in suppliers)
    >= min_quality * demand,
    name="qualita_minima"
)

model.addConstr(
    gp.quicksum(emissions[i] * x[i] for i in suppliers)
    <= max_emissions,
    name="emissioni_massime"
)

model.optimize()

status_names = {
    1: "LOADED",
    2: "OPTIMAL",
    3: "INFEASIBLE",
    4: "INF_OR_UNBD",
    5: "UNBOUNDED",
    6: "CUTOFF",
    7: "ITERATION_LIMIT",
    8: "NODE_LIMIT",
    9: "TIME_LIMIT",
    10: "SOLUTION_LIMIT",
    11: "INTERRUPTED",
    12: "NUMERIC",
    13: "SUBOPTIMAL",
    14: "INPROGRESS",
    15: "USER_OBJ_LIMIT",
    16: "WORK_LIMIT",
    17: "MEM_LIMIT"
}

status = status_names.get(model.Status, "STATUS_" + str(model.Status))

def clean_value(value):
    value = round(float(value), 10)
    return 0.0 if abs(value) < 1e-9 else value

if model.Status == GRB.OPTIMAL:
    result = {
        "status": "OPTIMAL",
        "objective": clean_value(model.ObjVal),
        "variables": {
            **{f"x_{i}": clean_value(x[i].X) for i in suppliers},
            **{f"y_{i}": clean_value(y[i].X) for i in suppliers}
        }
    }
else:
    result = {
        "status": status,
        "objective": None,
        "variables": {}
    }

model.dispose()
env.dispose()

print("SOLUTION_JSON=" + json.dumps(result, separators=(",", ":")))
```

## 4. Breve sintesi della soluzione

Lo stato è **OPTIMAL** e il costo minimo è:

\[
z^*=2055.
\]

Le decisioni non nulle sono:

\[
x_A=80,\qquad x_B=100,\qquad y_A=y_B=1.
\]

Il costo variabile è \(1880\), mentre il costo fisso è \(175\). La qualità media è circa \(92{,}67\) e le emissioni totali sono \(640\), quindi entrambi i limiti sono rispettati.
